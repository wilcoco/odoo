## 4. 🔴 신규 발견 — 이중 lot 구조 (시리얼 협의에 증거로 추가)
main 코드 기준, 실물 1개에 **stock.lot이 2개** 생길 수 있음:
1. `production_record.create` → **10자리** 실제 lot(prefix 1) + 임시(2, 기록에만) 발행 (기존 체계)
2. 단위 MO 완료(`action_complete_unit_mo`) → **14자리** `inj_serial_full`을 lot_producing_id 로 생성 (tracking=serial 필수화 대응)
→ 10자리 lot(레코드 연결용)과 14자리 lot(재고 시리얼)이 병존. 재고·추적이 14자리로 가면 10자리 lot은 유령화.
**권고**: 시리얼 표준 협의(§구조도 14자리 확정) 시 함께 결정 — production_record 의 lot 발행을 **단위 MO의 14자리 lot 재사용**으로 바꾸면 단일화됨(코드 소폭 수정, 협의 후 우리가 가능).
