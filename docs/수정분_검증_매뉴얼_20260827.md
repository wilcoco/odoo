소요: 전체 40~50분 · **배포 완료 후** 진행하세요 (배포 전에는 항목이 그대로 재현됩니다)

## 1. 매입계산서가 "수정/마이너스분"으로 오판되지 않는가 ★가장 중요

**왜**: 정상 최초 계산서가 전부 수정분 처리되어 원본번호 입력을 강요당하던 문제.

1. 【회계 › 공급자 청구서】 → 새로 만들기 → 거래처·일자·금액 입력 후 저장
2. 확인:
   - [ ] **"수정/마이너스분" 체크가 꺼져 있다**
   - [ ] 원본 세금계산서 번호를 요구하지 않는다
3. 반대 경우도 확인: 환불 전표(대변전표)를 만들면 **수정분으로 표시**된다

## 2. 마감 체크리스트의 "음수 금액 청구서"가 정상인가

**왜**: 1번과 같은 원인으로 매입분 전건이 오탐되던 문제.

1. 【회계 › 회계 점검·조회(K) › 마감 전 체크리스트】 열기
2. 확인:
   - [ ] **"음수 금액 일반 청구서" 건수가 0**(또는 실제 음수 건수만)
   - [ ] 숫자를 클릭하면 나오는 목록에 **정상 매입계산서가 섞여 있지 않다**

## 3. 실입고 0인 발주가 [납품 완료] 되지 않는가

**왜**: 물건이 안 왔는데 완료 처리되던 문제.

1. 입고 전표를 확정하지 않은 발주 1건을 연다
2. [납품 완료] 클릭
3. 확인:
   - [ ] **"입고 수량이 0입니다…" 메시지로 차단**된다
   - [ ] 입고 전표를 확정한 뒤 다시 누르면 정상 처리된다 (부분 입고도 허용)

## 4. 사일로 충전율이 정상 표시되는가

**왜**: 800/5,000kg이 **1600%** 로 보이던 문제.

1. 【사일로】 목록·상세 열기
2. 확인:
   - [ ] 충전율이 **16%** 로 표시된다 (잔량÷용량)
   - [ ] 목록·상세·카드(진행바) 모두 같은 값

## 5. 계약단가 없는 부품에 경고가 뜨는가

**왜**: 무계약 부품이 표준단가로 조용히 적립되던 문제.

1. 계약단가(가단가)가 없는 부품이 BOM에 든 완제품으로 MO를 완료 처리
2. 확인:
   - [ ] MO **채터에 "⚠ 계약단가 미등록 → 회계 표준단가로 적립됨"** 안내가 뜬다
   - [ ] 품목·공급사·적용 단가가 함께 보인다
   - [ ] 계약단가가 있는 부품은 경고가 뜨지 않는다

## 6. 정단가 확정 후 화면 오류가 없는가

**왜**: 서버 처리는 성공했는데 화면에 `Cannot read properties of undefined (reading 'map')` 가 뜨던 문제.

1. 가단가 품목에서 [정단가 확정] → 새 단가·합의근거 입력 → 확정
2. 확인:
   - [ ] **오류 메시지 없이** 완료 알림이 뜬다 (소급전표 건수·합계 안내)
   - [ ] 알림을 닫으면 해당 단가 화면으로 정상 이동한다
   - [ ] 소급전표가 **초안**으로 생성돼 있다 (회계 검토 후 게시)

## 7. 원재료 발주가 협력사 포털에 보이는가

**왜**: 원재료 발주가 포털에 뜨지 않아 협력사가 확인할 수 없던 문제.

1. 【생산계획】에서 원재료 부족분 [발주] 실행 (공급사는 **포털 사용 협력사**여야 함)
2. 협력사 토큰 URL을 새 창으로 열어 새로고침
3. 확인:
   - [ ] 발주 목록에 방금 건이 **보인다**
   - [ ] 대시보드 **알림 배지 +1**
   - [ ] 포털 사용이 아닌 협력사 발주는 종전과 동일(포털 미노출)

> ※ **배포 전에 만든 발주는 소급 노출되지 않습니다.** 발주를 새로 만들어 확인하세요.

## 8. [신규] 세금계산서 파일을 그대로 올릴 수 있는가

**무엇**: 홈택스·스마트빌에서 내려받은 파일을 **컬럼 정리 없이** 올리면 전표가 만들어집니다.

메뉴: 【회계 › 회계 점검·조회(K) › **세금계산서 파일 반입(홈택스·스마트빌)**】

1. 구분(매입/매출) 선택 → 내려받은 파일 그대로 업로드 → [가져오기]
2. 확인:
   - [ ] 결과창에 **인식된 컬럼** 목록과 생성/중복/미등록/오류 건수가 나온다
   - [ ] 생성된 전표의 **공급가액·세액이 파일과 정확히 일치**한다
   - [ ] **같은 파일을 한 번 더** 올리면 전부 "중복(건너뜀)" 으로 나오고 전표가 늘지 않는다
   - [ ] 미등록 거래처는 만들어지지 않고 **목록으로 안내**된다
   - [ ] 전표는 **초안**으로 생성된다 (검토 후 게시)

**실패했을 때**: "헤더를 인식하지 못했습니다" 가 뜨면 **그 파일을 그대로 개발에 전달**해 주세요.
헤더 문구를 사전에 추가하면 다음부터 인식됩니다. (파일 형식이 업체마다 달라 미리 다 넣을 수 없습니다)

## 알아두실 것 — 단가 칸에는 **부가세 포함 금액**

한국 부가세 세목은 오두에서 **내부포함(price included)** 방식으로 설정돼 있습니다.
따라서 청구서 라인의 단가에는 **공급가액이 아니라 부가세가 포함된 금액**을 넣어야
공급가액·세액이 의도대로 나뉩니다.

- 예: 공급가 1,000,000 / 세액 100,000 짜리 → 단가에 **1,100,000** 입력
  → 화면에서 공급가액 1,000,000 · 세액 100,000 으로 분리 표시됩니다
- 공급가액을 그대로 넣으면 909,091 + 90,909 로 쪼개집니다 (금액 불일치의 흔한 원인)
