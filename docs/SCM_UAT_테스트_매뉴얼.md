## 0단계. 마스터 준비 (구매)

1. 품목 2개 생성: `TEST-외주브라켓`(외주 체크 + 협력사 A + 리드타임 3일), `TEST-외주캡`(협력사 B + 2일)
2. BOM 있는 완제품의 BOM에 위 외주 부품 추가 (또는 TEST- 완제품·BOM 신규)
3. 거래처 `TEST-협력사A`, `TEST-협력사B` 생성 → **포탈 사용 체크 → 토큰 발급** 확인
4. 【외주 조달 설정】에서 자동 발주 생성 ON, 버퍼 일수 확인

- [ ] 토큰 URL로 시크릿 창 접속 → 협력사 대시보드 표시 (로그인 요구 없음)
- [ ] 토큰 없는 `/supplier/portal` 접속 → 접근 거부

## 1단계. 외주 조달 계획 → 자동 발주 (구매)

1. 테스트 수요 입력(생산계획 UAT 매뉴얼 1단계 방식)으로 해당 완제품 수요 생성
2. 【구매 › 외주 관리 › 외주 조달 계획】 → 기간 입력 → [수요 로드] → [계산 실행]
3. [확정] → [발주 생성]

- [ ] 계획 라인에 외주 부품별 소요 표시, **발주일 = 필요일 − 리드타임 − 버퍼**
- [ ] 협력사 A·B 각각 PO 생성, 자동 생성 표시 + 포털 상태 "신규"
- [ ] 협력사 포털 대시보드에 "응답 필요" 배지 +1 (토큰 URL 새로고침)
- [ ] 외주 체크 **없는** 부품은 PO 미생성 (의도된 동작인지 실무 관점 확인)

## 2단계. 협력사 포털 응답 3종 (자재 — 협력사 역할)

협력사 A 토큰 URL에서 발주 상세 열기. 3가지 유형을 각각 1건씩:

1. **전체 승인** → 제출 → 상태 "검토중"
2. **조건부 승인** — 확정수량을 요청보다 줄이고 납기 +1일 → 제출
3. **납품 불가** — 사유 입력 → 제출 (사유 없이 제출 시도 → 차단 확인)

- [ ] 제출 후 협력사 화면은 읽기 전용(검토중), 사내 【협력사 응답】에 3건 등록
- [ ] ⏳ 수량 0 행을 섞어 제출 → **전체 거부** + 몇 번째 행인지 안내 (#9)
- [ ] ⏳ 포털 대시보드 상태별 숫자 = 발주 목록 필터 건수 (#3)

## 3단계. 응답 검토 (구매)

【구매 › 외주 관리 › 협력사 응답】:

1. 전체 승인 건 → [승인] → 포털 상태 "승인"
2. 조건부 건 → 품목별 차이(−수량/+납기)와 **생산 영향도(🟢🟡🔴)** 표시 확인 → [반려] + 사유 입력
3. 협력사 화면 새로고침 → **반려 사유가 그대로 표시** → [재응답] → 사내 재검토 목록 재등장 → [승인]

- [ ] 반려 사유 문구가 협력사에게 보여도 되는 표현인지 (실무 관점)
- [ ] 영향도 판정이 실제 생산 일정 감각과 맞는지

## 4단계. 협력사 간 발주 — 1차→2차 (자재 2인 1조: 갑=협력사A, 을=협력사B)

1. 갑: A 포털 【발주 생성】 → 공급업체 B, `TEST-외주캡` 500개, 납기 지정 → 발주
2. 을: B 포털 【받은 발주】 → 해당 건 [확정] → [출하]
3. 갑: A 포털 【입고 현황】 → 입고 대기 확인 → [입고확인]

- [ ] 각 단계마다 상대 포털에 알림 배지
- [ ] ⏳ [확정] 처리된 건을 뒤로가기로 재제출 → 오류 안내, 상태 안 꼬임 (#6)
- [ ] ⏳ 출하 완료 건 [취소] 시도 → 차단 (#6)
- [ ] ⏳ 수량 0·과거 납기 입력 → 차단 메시지 (#9)

## 5단계. ASN 납품 → QR 무지입고 → IQC → 인수증

**「발주없는매입 UAT 순서서」 5단계와 동일** — 그쪽에서 완료했으면 생략.
이 흐름만 추가 확인:

- [ ] 1단계에서 만든 **자동 발주 건**으로 ASN 등록 → QR → 스캔 → 전표 프리필
- [ ] ⏳ 같은 품목 2줄(LOT 다르게) ASN → 전표 라인 2줄·LOT 정확 (#5)
- [ ] ⏳ ASN 번호 `ASN-26-####` 연번 (#1)

## 6단계. 입고 확정 → 재고·포털 상태 (자재 + 구매)

1. 입고전표 확정 → 【재고 › 제품】에서 TEST- 외주 부품 재고 증가 확인
2. ⏳ 협력사 포털 새로고침 → 발주 상태 **"납품완료"**, 대시보드 완료 숫자 +1 (#4)
3. ⏳ 【구매】 공급망 경로 → **[공급 단계 보기]** 버튼 → 단계 목록 정상 (#2)
4. 🔒 일반 사무 계정으로 사내 ASN 열기 → 조회만 가능 (역할 계정 확보 후)

## 자주 걸리는 함정 (버그처럼 보이는 정상 동작)

1. **알림 이메일이 안 옴** — 알림은 포털 배지가 정본, 이메일은 보조
2. **PO가 안 생김** — 품목의 외주 체크·기본 협력사 누락이 대부분 (0단계 재확인)
3. **토큰 URL은 계정과 무관** — 브라우저를 바꿔도 같은 URL이면 같은 협력사. 역할 구분은 URL로
4. 응답 제출 후 협력사 화면 잠김 — 정상 (반려돼야 재응답 가능)
5. 이상 입력 시 폼 전체 거부 — 정상 (부분 등록 방지 설계)
6. 발주·전표 번호는 실번호 — TEST- 데이터라도 번호는 소비됨 (양산 개시 시 컷오프 정리)
