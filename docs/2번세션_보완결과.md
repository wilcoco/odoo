  재고 불변·단위 MO done 유지·일반 MO 미간섭.

  것을 검증에서 적발(override loaded=False)하고 기존 메서드에 병합함.

### 4. 결재선 기본값 — **템플릿 자동 구성** ✅

  고액 500만→모델+금액 3단 / 수동 우선 / 무템플릿 기존 오류+안내.
- **운영 필요 입력**: 실제 결재선 템플릿 데이터(부서·금액 구간·결재자)는 현업 확정 필요.
