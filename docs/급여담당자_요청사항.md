# 급여 담당자님께 요청드리는 자료 목록

작성: 2026-07-21 (개발팀) · 함께 드리는 문서: 「급여시스템 사용메뉴얼」
급여 계산 시스템(4대보험·소득세·상여·OT·퇴직급여·근태 연동)은 구축이 끝났습니다.
계산식은 시스템에 있고, 아래 **수치·규정만 주시면** 바로 운영 가능합니다.

---

## 1. 4대보험 확정 요율 — 가장 급합니다
현재 골격 요율이 들어 있고 "확정 필요" 표시 상태입니다. 고지서 기준으로:
- 국민연금 기준소득월액 **상한·하한**
- 고용보험 **회사부담 요율** (기업 규모별 상이)
- **산재보험 업종 요율** (근로복지공단 고지서의 %)
- 건강·장기요양은 공표 요율로 입력되어 있으니 고지서와 대조만 해주세요.

입력 위치: 급여 > 기준정보 입력 > 4대보험 요율 (직접 수정 가능, 방법은 매뉴얼 1-1)

## 2. 간이세액표 파일
국세청 홈택스의 근로소득 간이세액표(엑셀) — 파일만 주시면 저희가 변환해서 올려드립니다.
(미적재 상태에서는 소득세가 0으로 계산됩니다)

## 3. EDI 고지내역서 실물 파일 각 1부
건강보험 EDI·국민연금 EDI에서 매월 내려받는 고지내역서(엑셀) 원본 — 주민번호는 가려주세요.
일괄 업로드 기능이 준비되어 있어, 실물 양식을 받으면 **그 양식 그대로 올리면 되게** 맞춰드립니다.
(그 전까지 잠정 양식: 사번/보험구분/적용월/고지액 4개 컬럼)

## 4. 수당 구성 목록
매뉴얼 기준으로 통상수당/기타수당 입력란은 준비되어 있습니다. 실제 운영 중인:
- **통상수당 목록**: 근속·직책(주임8/반장5/조장3만 확인)·공정·사출·도장·파견·근무형태변경지원금·보전수당2,3·조정·복지 — 각 금액 기준
- **기타수당**: 가족수당(1인 1만·4인 한도로 반영됨)·자격수당 등
- 식대 지급액 (비과세 20만 한도는 자동 처리)

## 5. 회사 규정 확인 3가지 (한 줄 답이면 됩니다)
1. **중도 입퇴사 일할 방식**: 30일 고정 나누기(매뉴얼 기준, 현재 설정) vs 그 달 실제 일수 나누기?
2. **퇴직금 평균임금에 상여·연차수당 포함 여부** (취업규칙 조항)
3. **상여 지급율**: 연 650% 매월 분할(현재 설정) 유지 여부, 노사 협의로 변경 이력 있는지

## 6. 직원별 기초 정보
- 직원 명단: 사번/성명/부서/직책/**월급제·일급제 구분**/기본급(또는 기본일급)/수습 여부
- 직원별 **퇴직급여 제도** (퇴직금/DB형/DC형) — DC형은 납입 이력 엑셀
- 공제대상 가족수(소득세용) — 없으면 본인 1인으로 계산됩니다

## 7. 근태 운영 정보
- 근무시간표: 주간조/야간조(2교대) 출퇴근 시각, 휴게시간
- 올해 회사 휴무일(공휴일 외 자체 휴일 포함) 목록 — 캘린더에 등록하면 그날 근무는 자동 특근 처리
- 특별 인정 OT 규칙 재확인: 사출반 휴게근무 10+10(+15)분, 도장반 청소 20분, 보전·자재반 관행,
  조합원 교육 분기 1시간 — 현재는 근태 집계에서 보정 입력하는 방식입니다

## 8. 급여 처리 방식 확인
현재 급여를 노무사 위탁인지 직접 계산인지 알려주세요.
- 직접 계산이면: 위 1~7이 오는 대로 바로 운영 시작 가능
- 위탁이면: 오두는 명세서 보관·급여 전표만 받는 구성으로 단순화 가능 (연말정산도 위탁 유지)

> 급여 전표의 **계정 매핑**(급여비용/예수금/미지급금 계정 지정)은 회계 담당자 요청 문서
> J-5 항목과 겹치므로 회계 담당자와 함께 정해주시면 됩니다.

## 우선순위
1. **1 (확정 요율)** + **6 (직원 명단)** — 시험 가동 조건
2. **2 (간이세액표)** + **3 (EDI 파일)** — 실액 계산 조건
3. 4·5·7·8 — 운영 정착 단계

## 제공 방법
쓰시던 엑셀 그대로 주시면 됩니다. 주민번호 등 민감정보는 가려주세요.
