## 1. 추출 대상 (마스터·관계만, `--data-only`)
```bash
set -euo pipefail
out=/db/backup/uat_master_$(date +%Y%m%d)
mkdir -p "$out"
T="-t product_category -t uom_category -t uom_uom -t product_template -t product_product -t product_supplierinfo
   -t mrp_bom -t mrp_bom_line -t mrp_routing_workcenter -t escon_bom_management_number -t escon_bom_version
   -t car_info_model -t escon_color_code -t csrt_model
   -t res_partner -t res_partner_category
   -t vendor_part_price -t material_ton_price
   -t mrp_workcenter -t injection_mold -t injection_machine_mold_capability -t injection_stock_silo
   -t stock_warehouse -t stock_location -t stock_picking_type
   -t hr_department -t hr_employee -t hr_job
   -t account_account -t account_tax -t account_journal -t account_fiscal_position"
# 존재하지 않는 테이블은 pg_dump 가 오류를 내므로, 먼저 목록을 확인해 없는 것은 빼 주세요.
docker exec postgresdb pg_dump -U odoo -Fc --data-only $T odoo18 > "$out/uat_master.dump"
docker exec postgresdb pg_dump -U odoo --schema-only odoo18 > "$out/schema_reference.sql"   # 컬럼 대조용(비밀 없음)
ls -la "$out"
```
활성/비활성 구분과 구버전 BOM 제외는 **적재 쪽(개발)** 에서 합니다. 추출은 테이블 통째가 단순하고 안전합니다.
