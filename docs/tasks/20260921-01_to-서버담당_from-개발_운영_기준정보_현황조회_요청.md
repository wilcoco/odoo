# 운영 기준정보 현황 조회 요청 (2026-09-21, 저자: Claude 개발)

수신: 서버 담당(원도영) · 참조: 홍정수
목적: 10월 7일 보고서를 위한 사내 테스트(UAT) 준비. 운영에 기준정보가 얼마나·어떤 모양으로 들어 있는지 알아야 "운영 마스터를 중립화해 UAT 에 넣을지, 합성으로 만들지"를 정할 수 있습니다.
조건: **읽기 전용**(지난번과 같이 `PGOPTIONS='-c default_transaction_read_only=on -c statement_timeout=15000'`). 개인정보·비밀값은 조회하지 않습니다(이름·연락처 컬럼 없음, 건수와 코드 분포만). 결과는 원문 그대로 이 큐에 파일로 올려 주세요.

## 1. 실행 (한 번에)
```bash
docker exec -e PGOPTIONS='-c default_transaction_read_only=on -c statement_timeout=15000' postgresdb \
  psql -U odoo -d odoo18 -P pager=off -Atc "
select '품목 전체', count(*) from product_template where active
union all select '품목 사출품(is_injection_part)', count(*) from product_template where active and is_injection_part
union all select '품목 카테고리별|'||coalesce(c.complete_name,'-'), count(*) from product_template t left join product_category c on c.id=t.categ_id where t.active group by c.complete_name
union all select 'BOM 분류|'||coalesce(bom_purpose,'-')||'|'||coalesce(bom_state,'-')||'|active='||active, count(*) from mrp_bom group by bom_purpose,bom_state,active
union all select 'BOM 관리번호 수', count(*) from escon_bom_management_number
union all select 'BOM 관리번호|부서 지정', count(*) from escon_bom_management_number where department_id is not null
union all select 'BOM 배치(Batch)|'||coalesce(state,'-'), count(*) from escon_bom_version group by state
union all select 'BOM 라인 수', count(*) from mrp_bom_line
union all select '차종연결(car.info.model)', count(*) from car_info_model
union all select 'ALC 목록', count(*) from (select distinct alc from mrp_bom where alc is not null) a
union all select '컬러코드', count(*) from escon_color_code
union all select '협력사(공급사)', count(*) from res_partner where supplier_rank>0 and active
union all select '고객(원청)', count(*) from res_partner where customer_rank>0 and active
union all select '계약 단가(vendor.part.price)|'||coalesce(state,'-'), count(*) from vendor_part_price group by state
union all select '톤 단가(material.ton.price)', count(*) from material_ton_price
union all select '작업장 전체', count(*) from mrp_workcenter where active
union all select '작업장 사출기(x_is_injection)', count(*) from mrp_workcenter where active and x_is_injection
union all select '금형', count(*) from injection_mold
union all select '설비능력(사출기×금형×품목)', count(*) from injection_machine_mold_capability
union all select '사일로', count(*) from injection_stock_silo
union all select '원재료(수지) 품목', count(*) from product_template t where active and exists (select 1 from injection_stock_silo s where s.product_id in (select id from product_product where product_tmpl_id=t.id))
union all select '창고', count(*) from stock_warehouse where active
union all select '재고 위치(내부)', count(*) from stock_location where usage='internal' and active
union all select '재고 수량 행(quant, qty>0)', count(*) from stock_quant where quantity>0
union all select 'LOT/시리얼', count(*) from stock_lot
union all select '임직원(활성)', count(*) from hr_employee where active
union all select '부서', count(*) from hr_department
union all select '사용자(내부 활성)', count(*) from res_users where active and not share
union all select '관리계획|'||coalesce(state,'-'), count(*) from iatf_control_plan group by state
union all select '입고검사', count(*) from iatf_incoming_inspection
union all select '공정검사', count(*) from iatf_process_inspection
union all select '부적합', count(*) from iatf_nonconformity
union all select 'MO 전체|'||state, count(*) from mrp_production group by state
union all select 'MO 사출(is_injection_mo)', count(*) from mrp_production where is_injection_mo
union all select '사출 계획 실행', count(*) from injection_planning_run
union all select 'BR 접수', count(*) from br_intake
union all select 'BR 지시(br_work)', count(*) from br_work_model
union all select '정산 원장(accrual)', count(*) from vendor_mrp_accrual
union all select '청구서(공급사 인보이스)|'||state, count(*) from account_move where move_type='in_invoice' group by state
union all select '전표(전기)', count(*) from account_move where state='posted'
union all select '결재 템플릿', count(*) from iatf_approval_template
union all select '결재 요청|'||state, count(*) from iatf_approval_request group by state
order by 1;"
```
테이블이 없어 오류가 나는 줄은 그 줄만 빼고 다시 돌려 주세요(모듈 미설치 표시로 기록).

## 2. 추가로 (파일 없이 건수만)
```bash
docker exec -e PGOPTIONS='-c default_transaction_read_only=on' postgresdb psql -U odoo -d odoo18 -P pager=off -Atc "
select '품목 코드 예시(사출품 5개)', string_agg(default_code, ', ') from (select p.default_code from product_product p join product_template t on t.id=p.product_tmpl_id where t.is_injection_part limit 5) x
union all select '직서열 BOM 품목 코드 예시 5개', string_agg(default_code, ', ') from (select distinct p.default_code from mrp_bom b join product_product p on p.product_tmpl_id=b.product_tmpl_id where b.bom_purpose='vehicle_batch' and b.active limit 5) y
union all select '작업장 코드', string_agg(code, ', ') from mrp_workcenter where active
union all select '사일로 이름', string_agg(name, ', ') from injection_stock_silo;"
```

## 3. 왜 필요한가
- 사내 테스트에서 담당자가 실제 품번·설비·협력사로 결과를 판단하려면 UAT 에 운영 마스터가 있어야 합니다. 어느 테이블에 얼마나 있는지 알아야 추출 범위(마스터만, 거래·개인정보 제외)와 소요를 정할 수 있습니다.
- 결정은 사용자가 합니다. 이 조회는 근거 수집입니다.
