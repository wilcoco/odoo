## 검토 우선순위와 변경 내용

### 중요도 5 — 회계

- `account_kr_reports`: KR 영업이익을 `KR_GRP - KR_EXP`로, 기본 손익계산서 영업이익을
  `REV - COS - EXP`로 보정한다. 법인세 집계, 영업외수익 `42xxxx`, 판관비 감가상각
  `61xxxx`, 기본 보고서 `TAX` 반영을 포함한다. 영업이익과 당기순이익 모두 알려진
  결함 수식과 정확히 일치할 때만 고쳐 사용자 정의 수식을 보존한다.
- `account_kr_plus_patch`: 전표번호·역분개·소급 변경, 결제일·예정일, 계정 설정과 KRW 금액
  표시를 정리한다.
- PR #36의 최신 보정 코드를 충돌 해결 기준으로 채택하고, `9d92ec15`의 세금계산서 반입
  행 단위 롤백과 건별 게시 격리를 보존한다.
- 회계 보고서 수식과 계정 유형은 표시 금액·분류에 영향을 준다. 실제 전표 잔액 자체를
  재작성하지 않지만 마이그레이션의 계정 유형 변경은 코드 revert만으로 되돌아가지 않는다.
