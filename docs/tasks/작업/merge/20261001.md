- 보류 버전·과거 승인 재사용 금지: lot_hold_release의 hold_revision, 원본/첨부 fingerprint, 서로 다른 품질·생산 승인과 명시적 해제를 유지한다. 과거 해제 모델은 추가하지 않는다.

## 적용과 남은 경계

- 이 작업은 개발 PR 준비다. 운영 DB 변경, 서비스 갱신, 자동 병합은 수행하지 않는다.
- 신규 차입금/자산 모듈은 관련 Enterprise 의존 앱이 설치되어 있을 때 자동 설치될 수 있다. kr_manage_only 기본값 True가 기존 차입금에 영향을 준다. 자산 재분류는 초안만 만들며 사람이 전기한다.
