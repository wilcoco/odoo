## 통합 시험 중 확인한 보완

- 과거 품의 시험은 위조한 기본값을 조용히 제거하거나 AccessError로 차단하는 계약이었다. 현재 엔진의 더 엄격한 UserError 차단을 유지하고 시험을 해당 계약으로 갱신했다.
- 회계 시험의 전역 채번 설정을 Odoo 기본값으로 명시하고, 실제 전기를 시험하는 청구서에는 필수 청구일을 지정했다. 초안 번호는 코어가 False 또는 '/'로 나타낼 수 있으므로 사용자 표시와 전기 후 번호를 검증한다.
- 보관 저널을 기본 검색에 포함해도 Many2many 조회에서 active_test 필터로 다시 빠지는 기존 결함을 확인했다. 번호 정리 마법사의 journal_ids 자체에 active_test=False를 지정해 명시된 활성·보관 저널 범위를 유지한다. 기존 보관 저널 회귀시험으로 검증한다.
- 복제 시험 DB의 조립 연계 스키마와 실행 코드 사이에 열 불일치가 있어 시험 DB에서만 해당 연계 모듈을 업그레이드했다. 실행 서비스는 변경하지 않았다.
