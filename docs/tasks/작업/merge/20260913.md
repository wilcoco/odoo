## 변경과 영향

- 문제 발생 조건과 이전 동작: 검증 완료 브랜치들이 `18.0`에 분산되어 있었고 배포 복제본이 브랜치별 최신 상태를 부분적으로 선반영한 상태였다.
- 변경 후 동작: 검증 통합점, 회계 순번·역분개, 회계 보고서 보정, IATF 검토 수정, 세금계산서 행 롤백, 개발 인계 문서를 단일 통합 이력으로 연결한다.
- 변경 모듈/연계 모듈 및 원본·복제본 구분: `account_kr_plus_patch`, `account_kr_reports`, `escon_eapproval`, `escon_mainmenu`, `iatf_equipment`, `iatf_menu`, `iatf_mold`, `iatf_ppap`, `iatf_process_inspection`, `iatf_spc`, `iatf_work_environment`, `mrp_plus_patch`, `pumui_approval`, `supplier_portal_purchase`. 원본은 `addons_custom`, 복제본은 `odoo_gh/iatf_plugins`이다.
- 권한·BOM·재고·품질·회계·외부 연동 중 영향받는 부분: 회계 전표 순번·역분개·세금계산서 반입·재무보고, 전자결재, IATF 설비·금형·PPAP·공정검사·SPC·작업환경, 협력사 포털.
- 모듈 버전, 업그레이드·마이그레이션·설정 변경 여부: manifest 변경 모듈은 배포 시 `-u` 대상이며 `account_kr_reports`와 `iatf_work_environment`에 마이그레이션이 포함된다.
- 사용자 메뉴/작업 방법 변경 또는 관련 매뉴얼 경로: 각 모듈 README/HANDOVER 및 `docs/` 통합 인계 문서 참조.
- 별도 발견 사항과 사용자 보고 여부: 등록된 소스 worktree 세 곳은 모두 clean이라 새로 커밋할 미커밋 작업은 없었다. `handoff`는 큐 규칙에 따라 통합에서 제외했다.
