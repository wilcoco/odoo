- 브랜치: `account/20260911-report-adjust`
- 기준 브랜치/커밋: `18.0 / 17e9fac0eeeb`
- 요청: 사용자 직접 요청 및 `handoff/docs/tasks/README.md`
- 담당: `서버`
- 상태: `진행`

## 목적과 범위

- Codex와 Claude가 작업 시작 시 같은 handoff·브랜치·워크트리·문서화 규칙을 발견하게 한다.
- 현재 회계 보고서 조정 코드와 병합 단위 문서를 **같은 브랜치**에서 검토하도록 루트 지침, 템플릿,
  PR 체크리스트를 연결한다.
- 이번 문서 반영 단계에서는 기존 `addons_custom/account_kr_reports` 작업 파일을 수정하거나 stage하지
  않는다. 회계 변경의 실제 범위와 검증 결과는 PR 전에 이 문서에 이어서 기록한다.

## 통합 영향

매뉴얼 자체에는 런타임 영향이 없다. 현재 브랜치의 회계 보고서 조정은 전표·기간잠금·회사 분리와
관련될 수 있으므로 구현 담당자가 실제 영향, DB, 실행 명령, 결과 로그를 PR 전에 추가해야 한다.

## 변경 내용

- `AGENTS.md`, `CLAUDE.md`: 에이전트의 필수 시작 컨텍스트
- `docs/tasks/AGENT_MERGE_WORKFLOW.md`: 두 저장소 공통 운영 매뉴얼
- `docs/tasks/작업/`: 브랜치별 기록 규칙과 템플릿
- `.github/PULL_REQUEST_TEMPLATE.md`: PR 시 작업 문서와 정본·미러·검증 확인

## 정본·미러 대응

- `escon-odoo/odoo_gh`에는 별도 `update/agent-merge-workflow` 브랜치로 같은 매뉴얼을 준비했다.
- 현재 회계 변경의 `odoo_gh` 미러 대상·경로·정본 커밋은 구현 완료 후 이 절에 추가한다.

## 검증 증거

- 문서 커밋: 이 문서를 포함한 브랜치 커밋
- DB/환경: 문서 전용 변경으로 해당 없음
- 실행 명령: `git diff --check`, 필수 파일·링크·브랜치명 수동 대조
- 결과 및 로그/산출물: 문서 커밋 전 검사 결과를 기록
- 미실행 검증과 이유: 매뉴얼 반영에는 서버/DB 검증이 필요하지 않다. 회계 코드 검증은 기존 작업
  담당자가 별도로 완료하고 이 문서를 갱신해야 한다.

## 배포·롤백

- 모듈 업그레이드/마이그레이션: 매뉴얼은 없음. 회계 변경분은 구현 완료 후 기재
- 재기동 및 확인: 매뉴얼은 없음. 회계 변경분은 구현 완료 후 기재
- 롤백 조건/방법: 문서가 실제 개발 흐름을 방해하면 해당 문서 커밋 revert
- 사람 승인: PR 머지로 승인

## 남은 위험과 후속 작업

- GitHub branch protection이나 CI 강제는 이번 범위에 포함하지 않았다. 현재는 에이전트 컨텍스트와 PR
  템플릿으로 준수 여부를 확인한다.
- 기존 회계 코드의 통합 영향·검증·미러·배포 항목이 비어 있으므로 현재 브랜치는 아직 PR 완료 상태가
  아니다. 구현 담당자가 결과를 채운 뒤 `검토 요청`으로 바꾼다.
- PR 및 handoff 회신: 브랜치 푸시 후 링크를 원 요청 또는 후속 `to-서버` 요청에 기록한다.
