# feat/tax-invoice-file-import — 세금계산서 파일 반입 + 행 단위 롤백 수정

담당: 테스트 · 최종 커밋: `ce025d5` · 배포: `-u account_kr_reports`

## 무엇을 했나

1. **세금계산서 파일 반입** (`ff30ff7`) — 홈택스·스마트빌에서 내려받은 파일을 **가공 없이 그대로**
   올려 전표를 만든다. 업체마다 헤더 문구가 달라 한글 헤더를 정규화해 동의어 사전으로 매핑한다
   (작성일자/발행일자, 승인번호/국세청승인번호, 공급가액/공급가 …). xlsx·xls·csv(UTF-8/CP949),
   머리말·합계행이 섞여 있어도 헤더 행을 찾아낸다.
2. **회계 검토 지적 3건** (`b4591f8`) — 승인번호 필드 통합 위저드, 면세 선택이 과세로 되돌아가던
   문제(구분을 고르면 라인 세금까지 교체), 전표의 `+GT10a` 세금그리드 기본 숨김.
3. **행 단위 롤백 누락 수정** (`ce025d5`) — 아래 §지적 조치 참조.

## 지적 조치 — 행 단위 롤백

**증상(수신)**: 검증 오류 주입 시 결과는 "생성 0건 / 오류 1건" 인데 초안 청구서가 트랜잭션에 남는다.

**원인**: 예외를 잡기만 하고 세이브포인트가 없어 `create()` 가 만든 부분 생성분이 살아남는다.

**수정**
- 행 생성을 `cr.savepoint()` 로 감싸고 **세이브포인트 안에서 `flush_recordset()`** 호출
  (지연 제약이 세이브포인트를 빠져나온 뒤 터지면 롤백 범위 밖이라 같은 문제가 반복된다)
- 자동 게시도 **건별 세이브포인트로 격리** — 일괄 게시는 뒤쪽 실패 시 앞선 게시분까지 되돌아가거나
  일부만 게시된 채 남아 "무엇이 게시됐는지" 를 말할 수 없다
- 결과 요약에 "게시 N건 / 초안으로 남음 M건" 추가
