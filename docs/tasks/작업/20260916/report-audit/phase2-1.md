## 변경과 영향

### 결재선 관리

- 기안자·지정 결재자의 기존 참여 권한에 더해 품의서 관리자는 원문서의 읽기/쓰기 권한 및 활성 회사 범위에서 품의 결재선을 관리한다.
- 공정검사 담당자와 관리자는 공정/최종/OQC 결재선을 같은 기준으로 관리한다. 다른 품의 작성자에게 모든 결재 근거를 공개하지 않는다.
- 초안 결재선 추가·수정·삭제는 허용하되, 진행/완료/이전 결재선 직접 변경과 판정 위조는 금지한다. 실제 승인·반려는 현재 지정 결재자만 수행한다.
- 관리자 재상신 준비 시 원래 기안자를 유지한다. 새 버전의 create_uid에는 실제 처리자가 기록된다.
- 관리 역할의 위임 조회는 원문서의 읽기·쓰기 record rule을 따르며, Odoo의 규칙 SQL 확장 과정에서 sudo가 전달돼도 실제 사용자 권한으로 조회한다.
- 품의·공정검사 원문서와 상세에 허용 회사 규칙을 추가했다. 회사가 없는 기존 기록은 별도 점검 대상으로 두며 복제본에서는 0건이다.
- 실제 사용자 계정의 그룹은 변경하지 않았다. 배포 시 담당자에게 기존 품의서 관리자 또는 공정검사 담당자 역할을 부여하고, 승인자는 원문서 조회 권한과 결재선 지정을 갖춰야 한다.

### 결재 이력과 청구

- 다음 결재 버전 연결을 추가했다. 미러의 전자결재 대시보드·진행 건수·기본 목록은 현재 버전만 대상으로 삼고 이전 버전은 이력으로 조회한다.
- 결재 요청 화면에서 서버 소유 상태·일시·원문서 연결 직접 편집과 독립 요청 생성/삭제를 노출하지 않도록 맞췄다.
- 품의 상세를 context의 기본 부모로 생성해도 INSERT 전에 부모를 잠근다. 세금 적용 순서·과세표준 적용 조건·하위 세금 연결도 승인 근거에 포함한다.
- 새로운 승인 기준과 맞지 않는 기존 품의는 이력을 보존하여 재상신한다. 기존 업무 데이터에 과거 승인 근거를 임의로 만들어 넣지 않는다.

### 출하 검사

- 취소된 검사는 현재 출하 판정에서 제외한다. 유효 검사가 없으면 새 검사를 생성하고, 새 검사 승인 전까지 출하는 차단한다.
- 부분 출하의 잔량 전표는 별도 OQC와 승인이 필요하다. 실제 backorder wizard 경로를 시험했다.
- 검사 상세 항목의 추가·수정·삭제·부모 변경은 관련 문서의 승인을 새 버전으로 돌린다. 승인 당시 항목값을 JSON 근거에 보존한다.
- OQC 승인 후 LOT이 새로 보류되면 출하 버튼·picking 완료·move 완료 경로 모두에서 막는다.
- 이 변경이 LOT 보류의 전체 생명주기나 모든 동시 보류 경합까지 완성했다는 의미는 아니다.

### 사출 중량 (미러 전용)

- Weight와 Final 표시를 같은 서버 판정 기준으로 맞춘다. 범위 밖은 NG, 미완성 값은 판정 대기이며 다른 공정 NG가 있으면 최종 NG다. PLC 원자료는 보존한다.
- 대시보드의 판정 대기 칩을 불합격 색으로 표시하지 않도록 구분한다.
- 기존 자동 검사 221건을 읽기 전용 점검한 결과 저장 합격→현재 기준 불합격 2건을 발견했다.
- 18.0.8.5.3 업그레이드에서 오래된 자동 합격만 fail/none으로 재평가한다. 원판정·새판정·기록/검사 ID·중량/기준·PLC 결과를 ir.logging에 남긴다. 기존 fail/none을 자동 pass로 승격하지 않으며, 반복 실행 시 중복 변경·로그·알림을 만들지 않도록 시험한다.

## 배포 조건 및 한계

- Phase 2-1은 Phase 1·2 위의 로컬 후보이며 원격 push/PR/merge/운영 배포는 하지 않는다.
- 적용 시 변경 모듈 업그레이드가 필요하며 중량 판정의 기존 데이터 보정도 포함된다. 백업 및 정지 시간을 확보하고 코드·DB·filestore가 함께 복원되는 롤백을 준비한다.
- 복제본에서 기존 품의 재상신 대상 1건을 확인했다. 실제 운영서버의 데이터 건수와 역할은 별도로 확인해야 한다.
- 브라우저 실제 조작, 실제 PLC/스캐너, 고부하·전체 IATF 전수 회귀는 미실행이다. UI XML 검증과 서버 payload 검증을 실제 브라우저 검증으로 부르지 않는다.
- WSL 원본 DB·사용자 그룹·실행 서비스와 실제 운영서버는 변경하지 않는다.
