## 설계 원칙

SQ에 업무 장부를 복제하지 않는다. 기존 관리문서가 한도견본·시험·설비 기준의 원본이며, 기존 배합/분쇄·지그·포장 모델을 확장한다. 현재 유효 기준과 완료 당시 기준을 구분한다. 완료 기록·기준·첨부의 내용은 JSON/파일 지문으로 보존하고 수정은 새 개정으로 진행한다. 실측값·현장 기준값을 자동으로 채우지 않는다. 부적합을 조치했다는 설명만으로 적합으로 바꾸지 않는다.

기존 승인 없는 완료 장부를 새 승인 기록으로 변환하지 않는다. 정정 필요 시 새 초안과 이전 기록 연결을 만들며 과거 상태는 보존한다. 분쇄 완료 버튼은 재고를 생성하지 않고, 실제 완료된 생산→내부 입고 이동의 품번·LOT·회사·kg 수량을 확인한다. 이력 개정은 동일 소비를 중복 합산하지 않는다.
