### 자격 관리 경계

`iatf.qualification` 자격 마스터는 만들지 않았다. 자격증·만료일·현재 등급의 정본은 기존 `iatf.competence.matrix`다. 현재 후보의 `iatf.qualification.preassessment`는 전달서 23 §3의 사전 평가서 요구를 위해 추가한 시험 점수·판정·원본 첨부·승인·개정 이력이다. 평가를 완료해도 현재 역량 등급을 자동 변경하지 않는다.

따라서 **새 모델이 전혀 없다고 회신하지 않는다.** 별도 자격 원장을 추가하지 말라는 정정과 구별해 위 보조 이력의 존재를 총괄에 알린다. 자격 출력의 주 모델은 기존 역량표로 지정하고 평가 근거를 연결한다. 이 보조 이력까지 불필요하다는 추가 결정이 있으면 공유 DB에 넣기 전에 기존 역량표 중심 구조로 조정한다. 현재 8070에는 설치하지 않았다.
