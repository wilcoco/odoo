## 변경과 보존

보관 사본의 버전은 18.0.1.2.1이고 정본은 18.0.1.2.3이다. 네 파일을 정본과 대조했으며 실제 변경은 매니페스트와 menu_cleanup.xml 두 파일이다. 모듈 신규 추가가 아니다.

1. PR97의 SPC 루트 비활성화 레코드를 제거하고 연구 메뉴의 active=False 레코드는 유지한다.
2. 보관 사본에 아직 없던 정본 선행 커밋 `ae6f00e401d23b9e8e8735593b2670f4f48fa7bf`의 일상점검 메뉴 복구도 같은 모듈의 누적 차이로 보관한다. 이 레코드는 통합 설비 메뉴 아래로 옮기고 active=True를 설정한다. 새로운 설계 변경이나 운영 갱신 범위 추가가 아니다.
3. __init__.py와 menu.xml은 이미 동일했다. 모듈 네 파일은 최종 정본과 바이트가 같으며 의도적 파일 차이는 없다. 다른 모듈·회사 규칙·그룹·의존성 목록은 변경하지 않는다. 사본 내 같은 기술 모듈은 addons_custom 한 경로만 확인했다.
