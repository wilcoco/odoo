## 기준과 범위

정본 `wilcoco/odoo`의 `codex/sq-outputs-canonical`은 P1 후보 `4754c436e`에서, 배포 미러
`escon-odoo/odoo_gh`의 `codex/sq-outputs-mirror`는 `47db7e699`에서 이어지는 의존 브랜치다.
P1이 포함되므로 정본 P1 검토·통합 후 미러 순으로 진행한다. main·18.0 병합 및 운영 변경은 하지 않았다.
큐 기준은 `wilcoco/odoo:handoff`의 05 회신이며, 이번 결과는 06 회신으로 연결한다.

사출 점수는 승인된 CSV 원문 **1030 / 사내 항목 제외 1010**을 유지한다. 출력물은 **467 = 보고서244 + 업로드207 + 내보내기9 + 외부7**이다.
과거 전달문의 1040·업로드212는 최신 정정과 다르다. D-24·D-38 미확정 조건 때문에 제안 스위치는 OFF를 유지한다.

## 사용자 시험 순서 (공유8070 적용 승인 후)

1. 승인된 P1 및 출력 모듈을 시험 DB에 설치·업그레이드하고 해당 시험 서비스만 재시작한다. 주소/DB·SHA·버전을 확인한다.
2. `t3.sqmgr`: SQ → 설정 → 출력 목록·별칭 보충. 467행/ASM 별칭36을 확인하고 재적재해 원천 연결이 유지되는지 확인한다.
3. SQ → 준비 현황 → 해당 서류 → 서류 출력. 실제 원천 모델·점검 대상/기록과 연결 근거를 지정한다.
   같은 원장을 모든 항목에 포괄 연결하지 않는다. 범위가 다르면 다른 서류의 연결을 별도로 지정한다.
4. 원래 생산/품질/점검 메뉴에서 실제 결과·LOT·일자·설비·담당·조치를 입력하고 기존 승인 절차를 수행한다.
   점검표의 5점 평가 사용·점수별 의미·중지 기준은 책임자가 확정한 경우에만 설정한다. 설비가 없다는 이유로 합격 실적을 만들지 않는다.
5. `t3.sq`: SQ → 준비 현황 → 서류 출력에서 기간 선택. 기본 PDF는 격자·서명 요약, 상세 체크는 원천 전체 추가, XLSX는 상세값을 내보낸다.
   승인 문서/실측값/미기록 날짜/원천 ID/개정 이력을 대조한다. CP·FMEA·8D는 기존 전용 서식 버튼도 확인한다.
6. 지정 문서 담당자에게만 업로드 그룹을 부여하고 전후 그룹을 기록한다. `CHECK.004/기준서.pdf`처럼 실제 업로드형 원본 키로 폴더 ZIP을 만든다.
   SQ → 준비 현황 → 서류 일괄 업로드. 새 초안 문서번호 확인 → 같은 ZIP 재실행 → 중복0 → 별도 문서 검토·승인.
7. SQ 평가서 기간·항목을 확인하고 기존 심사 패키지 ZIP 실행. 목차·영역 폴더·원본 파일·미비목록을 검토한다.
   미연결·미승인을 먼저 해소하고 심사자가 평가 응답과 근거를 확정한다. 출력만으로 평가서를 합격 처리하지 않는다.

현재 t3 시험은 ORM 및 화면 정의 로딩이며 **브라우저 클릭 시험은 아직 하지 않았다**. 공유8070의 UT3C/[시험]UT3C/AUD-2026-0017은 변경·삭제하지 않았다.
229개의 PDF 요구 행을 모두 실제 현장 자료로 출력·검수한 것은 아니다. 실제 원천 연결·서식 적합성 확인은 담당자 사용자 시험에 남아 있다.

## 적용·원복 경계

공유8070 P1 적용·재시작은 앞선 자동 승인 검토가 명시 승인 부족으로 거절하여 대기 중이다.
**8070 적용 SHA: 본 단계 미적용. 운영 반영·main/18.0 병합 없음.** 코드 후보와 격리 검증 완료를 운영 반영으로 해석하면 안 된다.

격리 출력 적용 전 백업: `/db/codex-testdb/sq-followup-20261023/pre-outputs-rehearsal.dump`
SHA256 `e360ea7c0f781bfde484fd70afae2938f68af229de79fb5058ed8c87e211bead`.
이는 **공유8070 복원용이 아니다**. 공유 적용 직전 DB dump·첨부 filestore·코드 HEAD·그룹을 새로 백업하고 접근 제한·지문을 기록한다.
P1 선행 모듈 적용 후 `cams_sq` 업그레이드, `cams_sq_outputs` 단독 설치, 목록 적재, 역할 배정, 역할/브라우저 회귀 순서다.

출력만 중지하려면 전담 역할을 변경 전 구성원으로 돌리고 신규 출력 메뉴/모듈을 제거한다. 새 점수·원천 연결·추가 필드가 삭제될 수 있으므로 먼저 내보낸다.
업로드한 기존 IATF 원본 문서는 제거하지 않는다. 잔여 XML 식별자·그룹·자체 테이블0과 원래 업무를 확인한다.
**완전 원복은 해당 환경의 직전 DB+filestore+코드+권한 백업 복원**이다. 코드 HEAD만 되돌려 데이터·필드까지 복구됐다고 보지 않는다.
공유 DB는 적용 후 다른 사용자가 입력했으면 과거 백업을 바로 덮어쓰지 않고 추가 입력을 확보한 뒤 원복 창을 잡는다.

남은 사람 확인: 기준값22종, D-38 제안 비율 승인, 현장 원천 연결/서식 수용, D-01 t2est479 활성화의 실제 의도/승인자.
운영 이력 복원 등 운영 데이터 변경은 별도 승인 전 실행하지 않았다. 비밀번호 교체 D-36은 기존 P0 처리분을 반복하지 않는다.
