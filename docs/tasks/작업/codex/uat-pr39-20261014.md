# PR39 엄격 승인 규칙과 UAT 10/7 통합 검증

## 접수와 범위
사용자는 충돌 4개 해소, 최신 운영 백업으로 복제환경 구성, 기존 잔여 28건 검증, 현장 MES 보존을 요청했다. 후속 답변으로 PR #39의 엄격한 승인·환불 규칙을 선택했다. 운영 반영은 검증 후 별도 단계이다.

- 정본: wilcoco/odoo, 브랜치 codex/uat-pr39-20261014, 기준 PR39 6cc548713801b0d3903a85cd0870e7f9c2c04bf3. 미러: escon-odoo/odoo_gh codex/uat-20261007-mirror, 운영 기준 b3a0a992a28bab62aaa5ce67089273652df8b798.
- 정본 addons_custom의 변경 파일을 미러 iatf_plugins에 대응한다. 미러 전용 odoo_plugins 현장 앱은 정본으로 덮어쓰지 않는다. PR39 변경을 먼저 정본에 보존한 뒤 같은 파일을 미러 시험 후보에 고정한다.
- manifest 3개와 pumui.py 충돌을 해소하고 두 승인 보호 계층의 내부 토큰을 연결했다. 원청구서 없는 독립 환불, 전기 후 품의 변경, 계산금액 및 전표 연결 위조는 거부한다. 승인 이력·공유 예산·MES 증빙 보호를 유지한다.
- 운영 코어에 종료시간 훅이 없는 경우 사출 계획의 동결 능력·수량·달력으로 계산하도록 보완한다. 일반 MO와 정상 라우팅은 코어 경로를 유지한다. 회사별 품질팀 우선 선택을 보완했다.
- 시험 준비는 실제 직원 계정, 실서버 세금 기본값, 실재 PLC 번호에 의존하지 않도록 합성 자료를 사용한다. 강화된 정책과 반대였던 기존 시험은 명시적으로 거부를 검증하도록 변경했다.
