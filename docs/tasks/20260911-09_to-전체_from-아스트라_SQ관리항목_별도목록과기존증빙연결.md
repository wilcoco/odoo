# SQ 관리항목 별도 정리 — 기존 업무·증빙 재사용

사용자가 기존 메뉴와 같은 업무라도 SQ 관리항목을 별도로 정리해두자고 요청했다. 별도 UAT 개선 목록에 포함한다. 현재 생산/BR/정산 결함 수정의 선행조건으로 삼지 말고 후속 UI·문서 작업으로 진행한다.

## 개발 범위

- SQ 관리항목 목록을 사출/조립으로 구분한다. 기존 IATF·생산·검사·금형·추적성 원장을 복제하지 않고 동일 업무 메뉴/레코드/증빙으로 연결한다.
- 항목별로 원문 항목번호·명칭, 적용 공정, 문서 판본/출처 위치, 관리내용, 담당/주기, 관련 업무메뉴, 필요한 증빙, 실제 증빙 연결, 미비사항/조치내역을 표시한다.
- 출처는 통합본 docs/tasks/N-SQ-PL-SOURCE-MAPPING, N-SQ-ASSEMBLY-SOURCE-MAPPING, N-SQ-ASSEMBLY-NEW-SOURCE-COMPARE 및 최신 사용자 제공 원문과 매핑자료를 먼저 확인한다. 원문에서 확인되지 않은 번호/주기/점수는 발명하지 않는다. 준비 LIST와 공식 평가표를 구분한다.
- '기능 구현 여부', '기준정보/문서 준비 여부', '실제 운영 증빙 유무'는 구분해서 보여준다. 메뉴가 있거나 합성 시험이 통과했다는 이유로 SQ 충족/합격 표시를 하지 않는다. 자동 점수·인증 판정은 이번 요청 범위가 아니다.
- 메뉴는 SQ 관리에서 사출/조립 항목을 볼 수 있도록 기존 구조에 최소 추가한다. 관련 업무로 이동하면 기존 동일 기록을 열어 중복 입력을 막는다.
- 현장 담당자·주기·적용판본이 미확정이면 미확정으로 남기고 실제 입력 필요사항으로 보고한다. 과거 sq_evaluation 사본을 검토 없이 복원하지 않는다.

## 테스트·문서

- 테스트는 사출/조립 구분, 원문 항목 추적, 메뉴링크/접근권한, 동일 증빙 재사용, 합성·미확인 상태 표시를 검증한다.
- SQ 항목→업무→담당/주기→메뉴→증빙→미비사항 연결표를 전체 ERP 매뉴얼에 포함한다.
- 아스트라가 검토·통합하며 별도 UAT에만 반영한다. 기존 운영 저장소·서버·DB 무변경. 수신 및 후속 작업 순서를 회신한다.
