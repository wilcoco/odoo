한 번도 실행되지 않고 있었습니다. 문서에 미검증으로 적었다가, **설치해서 실제로
돌렸습니다.** 순환 의존 없이 설치됐고 개정이 증빙에 실제로 남는 것을 확인했습니다.

→ 배정 3항의 **「다른 BOM / 차종 / 개정」 세 갈래가 모두 실행**됐습니다.

```
후보 SHA : e478dd6 (제품 25546ca) / DB cams_night_dev_main
명령     : python3 tools/night_runtime.py dev update --modules mrp_bom_scan_guard \
             --test-tags '/mrp_bom_scan_guard'
결과     : 0 failed, 0 error(s) of 14 tests, skip 0
로그     : artifacts/scan_gate_rev_25546ca.log
```

### ⚠ 그래도 넘겨짚지 말아 주십시오

지금은 적용 개정을 **증빙에 남기는 것**까지입니다. **「구 개정 부품을 스캔하면 막는다」는
아닙니다.** 그건 「어느 개정이 유효한가」라는 BOM 개정 운영 규칙이 정해져야 붙일 수
있어서 임의로 정하지 않았습니다. 필요하면 규칙을 주십시오.
