# BR 기반 조립·이종검사 E2E 수정 배정

사용자가 지금 공장 전체 모의운영에서 발견된 결함을 모두 고치도록 개발 세션에 실제 업무를 배정하라고 지시했다. 앞서 내부 에이전트에만 배정되어 개발 세션에는 새 요청이 전달되지 않은 오류를 바로잡는 요청이다.

## 작업 범위

격리 통합본에서 `escon_br`, `escon_mo_barcode`를 중심으로 다음 흐름을 실제 코드와 시험으로 닫는다.

1. 원청 BR에 BR번호·개정·수신시각·납기시각·품목·수량을 기록하고, 중복·개정·취소가 생산수요와 출고에 중복 반영되지 않게 한다.
2. BR 수요가 조립 제조오더, 완제품 LOT, 납품, 매출 근거까지 추적되게 한다. 현재 수동 연결 경로가 있으면 재현해 자동 연결 또는 명시적 차단으로 수정한다.
3. 조립 공정에서 적용 BOM 및 개정 기준으로 공정별 부품 바코드를 검사한다. 정상 부품만 투입하며 다른 품목, 다른 BOM/차종 개정, 중복 스캔, 알 수 없는 LOT, 품질보류 LOT는 즉시 차단한다.
4. 차단 시 작업자·공정·시간·스캔값·LOT·사유·BR/MO/BOM 개정을 증빙으로 남기고 SQ/IATF 부적합·추적성 기록과 연결한다. 정상 재스캔과 승인된 처분 뒤에만 진행한다.
5. 합성 난수 seed `20260930`, 조립 불량률 기본 3%로 불량을 재현한다. 불량 수량은 양품·재고·납품·생산량 기준 BOM 정산에 포함하지 않고, 재작업·폐기·가감정산은 승인 근거 없이는 진행되지 않게 한다. 실제 품질 합격 기준값은 임의로 만들지 않는다.
