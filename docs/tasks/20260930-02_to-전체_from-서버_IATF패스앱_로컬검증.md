## 기능과 영향

홈 화면에 **IATF 패스 검증** 앱을 표시합니다. 설치 시 회사별 패스가 기본 활성화되며, 시스템 관리자가 **패스 설정**에서 끄면 이후 호출은 기존 검증으로 복원됩니다. 이미 진행한 업무를 자동 취소하지 않습니다.

입고 IQC 검사대기 이동, 공정 IPQC 불합격, 품질 보류 LOT 투입·출하, OQC·포장/라벨 승인 및 관련 IATF 검증 실패를 기록하고 업무를 계속합니다. 입고의 검사대기 이동은 관찰 후 롤백하므로 해당 신규 입고의 IQC 초안은 생성되지 않고 원래 위치에 입고됩니다. PQC/IPQC·추적·금형·SPC 등 자동 품질 후처리 실패도 분리해 기록합니다. 검사 판정·승인·LOT 보류 상태를 통과의 근거로 임의 변경하지 않습니다.

로그에는 통과 일시·분야·내용·오류·호출 지점·원본 모델/ID/이름을 남기고, 원본 레코드·업무 첨부파일과 당시 Python 소스 파일·SHA-256·줄 번호·traceback을 연결합니다. 로그와 소스 스냅샷은 일반 수정·삭제를 막습니다. 로그 저장에 실패하면 통과하지 않으며, 업무 전체가 롤백되면 같은 트랜잭션의 로그도 롤백됩니다.

품질 문서를 직접 승인·완료하는 검증, 증빙 보호, 원본 업무 권한·회사/제품/LOT 식별, 인증·SQL 오류, 금융·정산 오류, MES 양품/NG/수량/원천 조건은 유지합니다. IATF 전용 기준 조회나 자동 후처리의 품질 권한 오류는 분리하여 기록할 수 있습니다. 품질 보류는 7개 MES 지점에도 선택적으로 연결했고 패스 앱 미설치/비활성 시 기존 차단을 유지합니다.
