# 회사 실제 운영 기준 정정 — 부품 무발주 납입과 BR 2시간

사용자가 이번 대화에서 명시한 실제 회사 특성이다. 이전 작업서의 일반 구매·입고·검사 가정과 충돌하면 이 기준을 우선한다. 개발과 테스트는 현재 별도 UAT 수정 작업에 적용하고 수신·영향 범위를 회신한다.

## 확정된 기준

1. 협력사 부품은 개별 구매발주 없이, 협력사가 우리와 동일한 원청 생산계획을 보고 적기에 미리 납입한다. 계획 공유·필요수량 통보·납입예정/ASN·부족 경보는 필요하지만 이를 필수 구매발주로 바꾸지 않는다.
2. 부품 입고는 수량·재고·LOT·납입이력 관리 대상이며 입고 시 회계처리는 없다. 발주서가 없다는 이유로 정상 부품 입고를 막지 않는다. 입고 시 자동 회계분개가 발생하는지 반드시 독립 시험한다.
3. 부품 마감은 확정 양품 생산량 × 생산 당시 적용 BOM을 기준으로 한다. 공급사 공급 주장 수량과 내부 BOM 수량 차이의 대사가 주요 업무이다. 불량·스크랩·재작업·실사 차이는 별도 승인 후 가감 정산한다. 입고 수량이나 입고검사 합격 수량을 부품 정산 기준으로 바꾸지 않는다.
4. 부품은 다품종·대량·실시간 납입되어 전 품목·전 수량 입고검사가 현실적으로 어렵다. 모든 입고에 일률적인 전수검사나 수기승인 병목을 강제하지 않는다. 검사대상 선정/샘플링/협력사 성적서/이력/고위험 부품 및 부적합 보류 정책은 설계 제안과 확정 정책을 구분한다. 현재 확인된 NG/품질보류를 우회시키지는 않는다. 미검사를 합격으로 위장하지 않는다.
5. 조립은 실시간 BR을 받아 수신 후 2시간 내 고객에게 배달해야 한다. 2시간을 조립완료 또는 출하완료로 축소하지 않는다. 수신→자재가용→조립→이종검사/필수품질→포장→상차→운송→고객 도착까지 시간기록·경보·부족 대응을 검증한다. 운송시간과 공정시간은 합성 가정을 명시하고 BR 변경·지연·불량 재작업 반례도 시험한다.
6. 수지 원재료는 별도 예외로 기존 사용자 정책 유지: 30톤 사일로에서 약 9톤 잔량에 20톤 발주, 발주 기준 정산, 초과적재·중복발주 방지. 부품의 무발주 정책과 섞지 않는다.

## 개발·테스트 지시

- 기존 코드와 현재 후보에서 부품 PO 의무, 입고 자동분개, 전 입고 일률 품질차단, 입고기준 정산이 있는지 먼저 대조하고 충돌 항목을 보고한다.
- 회계 인식 시점/계정, 재고 소유권과 평가방법은 입고 무분개만으로 추정하지 않는다. 기존 승인된 마감 설계와 대조하고 미확정 사항을 아스트라에게 보고한다.
- 검사 방식별 대상·주기·샘플수·승인권자는 회사 품질기준 확인이 필요한 값으로 표시하고, 합성 시험을 회사 확정 기준으로 배포하지 않는다.
- 실제 무발주 부품 납입부터 양품 생산/BOM 대사 마감까지 정상 E2E를 추가하고, BR 고객 도착 2시간을 별도 판정열로 둔다.
- 작업은 별도 UAT 저장소·별도 배포 원칙 유지. 기존 운영 코드/DB 변경 없이 지정 격리 공간에서 수행한다.
