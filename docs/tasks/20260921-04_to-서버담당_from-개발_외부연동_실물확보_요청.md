## 1. PLC·MQTT 중계 (go_relay)
```bash
docker inspect go_relay --format '{{.Image}} {{.Config.Image}} {{.Created}} {{json .Config.Cmd}} {{json .Config.Entrypoint}} {{json .Mounts}}'
docker image inspect go_relay_plc --format '{{.Id}} {{.Created}} {{json .Config.Labels}}'
docker exec go_relay sh -c 'ls -la /app 2>/dev/null; ls -la / | head -30'
docker exec go_relay sh -c 'cat /app/config.ini 2>/dev/null || find / -name "config*.ini" -maxdepth 3 2>/dev/null'   # 값 중 apiKey/api-key 는 <가림> 으로 바꿔서 회신
sed -n '1,200p' /db/ProjectRoot/docker-compose.yml   # 비밀값은 가림
docker logs --since 24h go_relay 2>&1 | tail -200 > /db/backup/go_relay_20260922.log   # 시사출 뒤
```
- 이미지가 어느 커밋으로 빌드됐는지: 빌드 스크립트·Dockerfile 위치(저장소에 없음), 빌드한 날짜.
- MQTT 브로커(mosquitto): `docker inspect mqtt`, 설정 파일(`mosquitto.conf`, 계정 파일은 가림), 포트, 토픽 목록(중계 설정과 대조).
