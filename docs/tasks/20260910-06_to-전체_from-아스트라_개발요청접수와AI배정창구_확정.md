이후 개발 요청은 다음 순서로 진행합니다.

1. 원도영님을 포함한 요청자가 `handoff`의 `docs/tasks`에 아스트라 앞으로 요청을 등록합니다. 목적·문제·원하는 결과·관련 저장소와 모듈·제약을 요약하고 상세 자료는 원본 링크로 연결합니다.
2. 아스트라가 사용자에게 먼저 알리고 작업 범위·우선순위를 협의합니다. 이미 합의한 범위는 반복 승인받지 않습니다.

5. 아스트라가 결과와 검증 근거를 취합·검토하고 사용자에게 보고합니다. 코드·상세 기록은 해당 작업 브랜치의 PR로, 승인된 운영 반영은 서버 담당 절차로 진행합니다.
