### ① ⚠ 지적하신 누적 중복 생산 — 제 구현의 실제 구멍이었습니다

> 「'동시에 살아 있는 MO가 하나'만으로 누적 중복 생산을 방지했다고 판정하지 마세요.」

맞습니다. 앞 가드는 형제 오더가 **살아 있을 때만** 막습니다. 이전 개정의 오더가
**완료**되면 살아 있는 오더가 없어 가드를 통과하고, 새 개정이 **전량을 다시** 생산합니다.
1개를 만든 뒤 2개짜리 개정이 오면 **합계 3개**입니다.

고친 내용:
- `_produced_qty_for_br()` — 살아 있는지가 아니라 **얼마나 만들어졌는지**를 셉니다
  (형제 오더 `qty_produced` 합).
- 새 개정의 오더는 요청 수량에서 **이미 만든 수량을 뺀 남은 수량**만 지시합니다.
- 더 만들 것이 없으면 오더를 내지 않고, 초과분은 `needs_disposition` +
  `disposition_note` 로 **처분 필요 이력**을 남깁니다.
- 취소도 같습니다 — 남은 WIP/완제품(`qty_produced` 포함)을 처분 필요로 보존합니다.

### ② 불량 처분 — 먼저 읽어 보니 셋은 이미 되고 하나가 빈자리였습니다

| 배정 항목 | 코드 실측 |
|---|---|
| 불량 **실물완료** | **된다** — 게이트가 지연 PLC 판정 전 내부재고 생산을 허용 |
| **원재료소비** | **된다** — MO 가 완료되므로 불량분도 원재료를 소비 |
| **격리** | **된다** — 미검사·불량 LOT 은 하류(생산 투입·고객 출고)에서 막힘 |
| **처분** | **⚠ 빈자리** |

게이트는 목적지가 `production`/`customer` 인 이동만 막습니다. 폐기 위치는
`usage='inventory'` 라 **스크랩은 그냥 통과**했습니다. 즉 **불량 LOT 을 아무나 사유
없이 폐기**할 수 있었고, 어떤 불량 근거였는지도 남지 않았습니다.

→ 사출 원천 LOT 의 스크랩에 **처분 구분(폐기/재작업)·사유·품질관리자 승인**을 요구하고,
승인 시 **불량 근거(사출 단위 MO)** 를 함께 기록합니다.
부품·원재료 폐기는 통제하지 않습니다 — 거기까지 막으면 현장이 멈춥니다.

**품질 기준값을 발명하지 않았습니다.** 처분에 근거를 요구하는 절차 통제이고,
