# 대기 해소 — 기존 승인 범위 후속 배정

최신 개발 e478dd6/테스트22e27c8 회신을 접수했고, 사용자에게 부분 완료이며 총괄 결정 대기였다고 알렸다. 사용자는 이미 가상 BR 공정 시험과 전체 결함 수정을 승인했다. 아래 기술·소유 경계는 총괄이 확정하므로 재승인 대기하지 않는다.

## 개발 — BR 구현 우선

- 격리 UAT에서 BR→조립 MO→LOT→납품 추적을 구현한다. 기존 비활성 스텁을 완료로 취급하지 않는다. 실제 운영 FDW/원청에는 접속하지 않는다.
- FDW 모델 아래 임의 테이블을 만들어 운영 연결로 위장하지 않는다. 별도 내부 BR 수신 원장/입력 어댑터에 합성 BR을 넣고 source=simulation으로 식별한다. 중복키·개정·취소·수신시각·납기·MO/납품 연결을 보존한다. 외부 FDW 원본은 미래 연계 경계로 남긴다.
- 사용자 지정 2시간은 BR 수신부터 고객 도착이다. 차단 지속시간120분과 혼동하지 않는다. 가상 운송시간 가정을 명시하고 도착시각을 실제 기록하지 않은 건은 납품완료/2시간PASS로 표시하지 않는다. 정상·지연·중복·개정·취소를 시험한다.
- 이 작업에 필요한 BR/MES 모듈 소유권을 개발에 명시적으로 부여한다. 별도 adapter 모듈 방식 가능. 기존 소유 규칙 때문에 중단하지 않는다. 다른 담당 작업공간은 수정하지 않는다.
- 계획 후보 fix/planning-inventory-week=3bb4cf3은 145PASS/3SKIP 보고가 있으나 부분 부모MO 예정입고 중복 등 잔여 한계가 있어 완료로 보지 않는다. 품질 후보 fix/quality-precedence-gates=fc61e235는13PASS/1ERROR로 배포 후보 아님. 두 후보를 재구현하지 말고 필요한 연계를 보고한다.
- BR 뒤 후속 순서: 사출 PLC 품질팀 회사필터 오류(injection_worksite/models/plc_weight_sync.py:176), 불량 실물완료/원재료소비/격리/처분, 입고검사 운영정책 설정 경계. 해당 소유권도 개발에 부여하되 실제 품질기준을 발명하지 않는다. 각 단계 후보를 제출하면 테스트가 독립 시험한다.

## 테스트 — 무발주 주간 E2E 즉시 착수

- B 무발주 정상 E2E 하네스는 테스트 소유로 확정한다. 제품코드 변경 없이 부품PO를 제거한 주간 시나리오를 지금 수행한다. 개발의 BR 구현을 기다리지 않는다.
- 공유 원청계획→납입예정/ASN→무발주 입고·재고/LOT→양품생산→BOM 정산대사까지 실행한다. 원재료 수지PO는 유지한다. 입고무분개가 manual_periodic 설정 때문임을 검증표에 명시한다.
- 설정이 없는 품질판정을 자동합격하지 말고, 현행 전건IQC 병목을 별도 관찰결과로 남긴다. 전사 기준 확정 없이 일률적으로 gate를 끄지 않는다.
- 개발 e478dd6 이종검사 후보의 정상·누락·다품목·미등록LOT·보류LOT·중복·해소 권한·BOM 개정 증빙을 독립 재시험한다. 개정 증빙과 구개정부품 차단을 구분한다.
- BR 후보가 오면 수신→고객 도착2시간 판정을 합본에 추가한다. 계획/품질 후보는 정확 SHA와 설치모듈을 고정한 별도 DB에서 시험하고 실패를 숨기지 않는다.

## 아스트라

협력사 대사·회계마감 후보 검토/통합과 전체 통합 판정을 맡는다. 후보 수치만으로 회사 전체 완료를 선언하지 않는다. 새로운 사업정책 결정이 필요한 항목은 사용자에게 먼저 알린다.

별도 UAT 저장소/별도 Railway 배포 원칙 유지. 기존 제품/운영DB 무변경. 수신 후 현재 수행항목과 첫 실행 근거를 회신하고 배정 범위 작업을 계속한다.
