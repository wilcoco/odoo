## 2. 시사출과 외부 연동

제가 파악한 사출 완료 신호 경로는 `취출로봇 인식 → PLC 업체 푸시 → 미들웨어 → injection_worksite의 /api/plc/complete`입니다. 실제 API 발신 장치/IP와 미들웨어 호스트·프로세스는 시사출 때 증적으로 확인할 항목입니다. `go_relay`는 이종검사에 사용하는 Go 기반 MQTT 중계이므로, 이것을 멈추는 것만으로 사출 완료 입력이 차단된다고 가정하지 말아 주십시오. 큐 03의 P6 및 운영 재개 통제 설명도 이 구분에 맞춰 수정 부탁드립니다.

`t_silo`는 Odoo와 같은 PostgreSQL 17 서버의 별도 DB에 있고, Odoo DB에서는 FDW로 연결해 사일로 잔량 조회에 사용합니다. 원본 테이블은 외부 미들웨어/서버가 기록하는 것으로 파악하지만, 정확한 작성 프로그램·실행 호스트는 아직 확인하지 못했습니다. 현황판 연동 여부도 기억에 의존한 내용이므로 확정 정보로 기재하지 않겠습니다.

go_relay 이미지의 빌드 커밋·실제 설정과 조립 통신 서버가 실행되는 PC는 미확인입니다. 설정은 비밀값을 가린 형태로 확인하겠습니다. 내일 시사출은 기존 운영 코드로 관찰·기록하고 이번 릴리스를 먼저 운영에 적용하지 않겠습니다.
