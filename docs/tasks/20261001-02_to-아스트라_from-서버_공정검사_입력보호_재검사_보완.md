## 바뀐 동작과 유지하는 경계

- **미확정 검사 입력:** 회사·제품·LOT·MO·생산 수량 등 생산 범위는 보호하고, 초안·검사 중 문서에는 실제 검사수량·측정값·판정을 입력할 수 있습니다. 생산 완료 수량을 실제 검사수량으로 자동 인정하지 않습니다.
- **생산 묶음 고정:** 검사 시작 또는 실제 값 입력 시 생산 범위를 고정합니다. 뒤에 완료된 단위 MO는 새 검사서에 집계하고, 같은 단위 MO를 재호출해도 과거 묶음까지 대조하여 중복 집계를 막습니다.
- **과거 검사서:** 판정·상신·승인·자동 연동된 원문서는 계속 보호합니다. 과거 문서에 스냅샷이 없다는 이유로 편집 가능한 상태로 되돌리지 않습니다.
- **새 재검사:** 원본을 수정하는 대신 `새 재검사`로 연결된 초안을 만듭니다. `correction_of_id`와 `correction_reason`으로 원검사와 사유를 남기며, 기존 검사값·합격 결과·승인 증빙은 복제하지 않습니다. 새 검사값과 사유를 입력하고 판정·결재해야 합니다.
- **기존 품질 이력:** 재검사 합격으로 원검사의 SPC·부적합·LOT 보류·승인을 자동 취소하거나 해제하지 않습니다. 기존 처분·해제 절차가 필요합니다.
- **출하:** 유효 검사서 중복 차단과 완료 출고에 증빙을 소급 생성하지 않는 규칙을 유지합니다. 기존 활성 출하 검사서가 있으면 기록을 보존한 취소 절차와 새 검사서 사용 순서를 확인해야 합니다.
- **호환성:** 재검사 메타데이터가 없는 과거 문서의 증빙 payload와 승인 시각·사용자를 일괄 다시 기록하지 않습니다. 신규 필드는 `run_scope_frozen`, `correction_of_id`, `correction_reason`입니다.

사용자의 목적은 IATF를 유지하면서 업무를 중단시키는 호환성 문제를 줄이고 원인을 수집·개선하는 것입니다. 양품 근거가 없는 사출 시리얼을 합격으로 만들거나 과거 승인 기록을 임의로 편집하는 기능으로 해석하지 않습니다.
