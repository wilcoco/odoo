# SCM(외주 자동발주·협력사 포털) 사용자 매뉴얼

작성: 2026-08-24 · 대상: 협력사 사용자 + 사내 구매·자재 담당 · 환경: 운영 서버 `http://10.10.21.20/odoo` (DB odoo18)

**시스템 한 줄 요약**: 생산계획에서 외주 부품이 나오면 협력사별 발주서가 자동 생성되고,
협력사는 **계정 없이 토큰 URL로 포털에 접속**해 발주에 응답·출하·ASN(납품 예정) 등록까지
처리합니다. 사내는 응답을 검토·승인하고 QR 스캔으로 무지(無紙) 입고합니다.

```
생산계획 확정 → 외주부품 추출 → PO 자동생성 → [협력사 포털] 응답 → 사내 검토·승인
                                                → ASN 등록 → QR 입고 → 재고·정산
```

---

## 1부. 협력사 편 (포털)

### 1-1. 접속

- 에스콘에서 받은 **본사 전용 URL**(토큰 포함)을 브라우저 즐겨찾기에 등록해 사용합니다.
  - 예: `http://10.10.21.20/supplier/portal?token=...`
- **아이디·비밀번호가 없습니다** — URL 자체가 열쇠이므로 외부에 전달·게시 금지.
- URL 분실·유출 시 에스콘 구매 담당에게 연락 → 토큰 재발급(기존 URL 즉시 무효).

### 1-2. 대시보드 (`/supplier/portal`)

접속 첫 화면. 다음이 보입니다:
- **알림 배지**: 신규 발주·반려·승인 등 (이메일 대신 포털 알림이 정본)
- **발주 현황 카운트**: 응답 필요 / 검토중 / 확정완료 / 납품완료
- 납품 일정, 바로가기 버튼

### 1-3. 에스콘 발주에 응답하기 (받은 발주)

【발주 목록】 → 응답 필요(🔴) 건 클릭 → 상세에서 **응답 유형 3가지 중 선택**:

| 유형 | 언제 | 입력 |
|---|---|---|
| **전체 승인** | 요청 수량·납기 그대로 가능 | 추가 입력 없음 |
| **조건부 승인** | 수량 또는 납기 조정 필요 | 품목별 확정수량·확정납기 입력 |
| **납품 불가** | 공급 불가 | 사유 필수 |

[응답 제출] 후 상태가 **검토중**으로 바뀌고 에스콘 구매 담당이 검토합니다.
- **승인되면**: 알림 + 상태 확정완료 → 납품 준비
- **반려되면**: 반려 사유가 화면 상단에 표시 → 사유 확인 후 **[재응답]**

주의: 수량 0, 과거 날짜 등 이상 입력은 **폼 전체가 거부**되고 몇 번째 행이 문제인지
안내됩니다 — 일부만 몰래 등록되는 일은 없습니다.

### 1-4. 납품 예정(ASN) 등록 → QR 무지입고

납품 갈 준비가 되면 【납품 예정(ASN)】 → [새 등록]:
1. 발주 선택 → 품목·수량·LOT 입력 (같은 품목을 LOT 다르게 여러 줄 가능)
2. 등록하면 **ASN 번호(ASN-연도-####)와 QR**이 발급됨
3. QR을 인쇄하거나 기사 휴대폰에 전달 → **기사는 종이 서류 없이 QR만 지참**
4. 에스콘 도착 → 담당자가 QR 스캔 → 입고전표 자동 생성
5. 입고·검사 완료 후 【납품 인수증】에서 **인수증 PDF 다운로드** (수량·LOT·검사 결과 포함)

### 1-5. 협력사 간 발주 (2차 협력사와 거래)

우리 회사가 다른 협력사에 재발주하는 경우:
- **보낸 발주**: 【발주 생성】 → 공급업체·품목·수량·납기 입력 → 발주 → 상대 협력사 포털에 알림
  - 상대가 출하하면 【입고 현황】에 입고 대기로 표시 → 실물 확인 후 [입고확인]
- **받은 발주**: 다른 협력사가 우리에게 보낸 발주 → [확정] → 준비 완료 시 [출하]
  - 이미 확정·출하된 건은 뒤로가기로 재제출해도 상태가 꼬이지 않고 오류 안내만 나옵니다
  - 출하 완료된 발주는 취소할 수 없습니다

### 1-6. 공급망 추적 / 재고

- 【공급망】: 내 위치의 공급 단계 확인·진행 처리([확정]/[출하]/[완료]), 문제 발생 시 [이슈 제기]
- 【내 재고】: 에스콘과 공유하는 재고 수량 갱신

## 2부. 사내 편 (구매·자재)

메뉴 위치: 【구매 › 외주 관리】

### 2-1. 마스터 준비 (최초 1회)

| 무엇 | 어디서 | 입력 |
|---|---|---|
| 외주 부품 지정 | 【외주 부품】 또는 품목 화면 | 외주 여부 체크 + 기본 협력사 + 리드타임(일) |
| 포털 협력사 지정 | 【협력사 관리】 거래처 | "협력사 포탈 사용" 체크 → **토큰 자동 발급** → URL 전달 |
| 조달 설정 | 【외주 조달 설정】 | 자동 발주 생성 여부, 납기 버퍼 일수, 리마인더 D-N |

### 2-2. 외주 조달 계획 → 자동 발주

【외주 조달 계획】 → 새로 만들기 → 기간 입력:
1. **[수요 로드]** — 생산 수요(production.demand) 연결
2. **[계산 실행]** — BOM 전개로 외주 부품 소요 산출 (발주일 = 필요일 − 리드타임 − 버퍼)
3. **[확정]** → **[발주 생성]** — 협력사별 PO 자동 생성 + 포털 알림 발송

생성된 PO는 `자동 생성` 표시와 포털 상태(신규→응답→승인→완료)를 가집니다.

### 2-3. 협력사 응답 검토

【협력사 응답】 (또는 【승인 대기】):
- **전체 승인 응답** → 내용 확인 후 [승인]
- **조건부 승인** → 품목별 차이(수량↓/납기+N일)와 **생산 영향도(🟢/🟡/🔴)** 확인 후
  [승인] 또는 [반려](사유 필수 — 협력사 화면에 그대로 표시됨)
- 반려하면 협력사가 재응답할 수 있고, 재응답 시 다시 검토 목록에 올라옵니다

### 2-4. 입고 (ASN·QR)

협력사가 ASN을 등록하고 기사가 도착하면:
1. 태블릿/PC에서 기사 QR 스캔 (또는 사내 【ASN】 목록에서 해당 건 처리)
2. 입고전표 자동 생성 — 품목·수량·LOT이 ASN에서 프리필
3. 실물 대조 후 수량만 보정, 확정 → IQC 검사 → (원재료는 사일로 적재)
   ※ 검사 기준·보류 LOT 처리는 IATF 수입검사 매뉴얼 참조
4. 입고 확정 시 협력사 포털의 발주 상태가 자동으로 **납품완료** 처리

### 2-5. 모니터링

- 【공급망 대시보드】·【공급망 추적】: 단계별 진행 현황, 공급 단계 보기
- 【외주 일별 분석】: 일별 발주·입고 추이
- 【포탈 알림】: 발송된 알림 이력 (미응답 D-2 리마인더는 자동 발송)

## 3부. 자주 묻는 질문

| 증상 | 원인·조치 |
|---|---|
| 협력사가 "포털이 안 열려요" | URL의 토큰 누락/오타 — 즐겨찾기 재등록. 계속 안 되면 토큰 재발급 |
| 발주 확정했는데 협력사 포털에 안 보임 | 해당 거래처에 "포탈 사용" 체크·토큰 발급 여부 확인 |
| 계획 확정해도 PO가 안 생김 | 품목의 **외주 여부 체크 + 기본 협력사** 누락이 대부분. 조달 설정의 자동 발주 생성 여부도 확인 |
| 알림 이메일이 안 와요 | 정상 — 알림은 **포털 배지**가 정본입니다 (이메일은 보조) |
| QR 스캔했는데 전표 실패 | 스캔 계정에 재고/구매 권한 필요. 이미 처리된 ASN 재스캔은 차단됨 |
| 응답 제출이 통째로 거부됨 | 안내된 행 번호의 입력값(수량 0·과거 납기 등) 수정 후 재제출 — 정상 동작 |
