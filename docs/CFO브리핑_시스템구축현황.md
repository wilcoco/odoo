# 경영 브리핑 — ERP(오두) 구축 현황 및 재무 관점 요약

작성: 2026-07-22 · 대상: CFO·경영진 · 첨부: 원가시스템 회계·CFO 검증보고서(7/3), 회계·급여 담당자 요청문서

---

## 1. 한 장 요약

자동차 부품(사출·조립) 제조 전 과정이 하나의 시스템에서 돌아가도록 구축을 완료했습니다.
**생산계획(자동차 ERP 자동 수신) → 사출 실적(PLC 실측) → 품질(IATF·SQ) → 원가 → 구매·정산 →
회계(품의·전표·재무제표) → 급여(4대보험·퇴직급여)**까지 연결되며, 전 구간을 실데이터·모의데이터로
검증했습니다(통합 테스트 18/18 통과). 현재 운영 투입 전 상태로, 남은 것은 **담당자 입력값**
(요율·계정매핑·품목마스터)과 **운영 서버 이관 결정**입니다.

## 2. 재무 관점 핵심 3가지

**① 통제가 코드에 박혀 있습니다.** 품의 없는 지출 전표는 시스템이 전기를 거부합니다(결재 승인
후에만 청구서·전표 생성). 세금계산서 이중 등록은 DB 차원에서 차단됩니다. 마감 잠금을 풀면
누가 언제 풀었는지 불변 이력이 남습니다. 사람이 실수해도 장부가 오염되지 않는 구조입니다.

**② 마감·신고 체계가 준비됐습니다.** 마감 전 체크리스트(12개 지표: 총계 0원 청구서, 승인번호
누락, 청구-원장 불일치 등)가 문제 건수를 자동 검출하고 클릭 한 번으로 해당 전표를 보여줍니다.
매입매출장·부가세 합계표·K-GAAP 재무제표(대차평형 자동 검증)·원천세 신고 집계까지, 신고에
옮겨 적을 숫자를 시스템이 만들어 줍니다.

**③ 원가는 회계와 분리된 관리 분석층입니다.** (7/3 보고서 그대로) 재고 평가·세무에 영향 없이,
PLC 실측 기반 실제원가와 표준원가의 차이를 가격/수량/능률로 잔차 없이 분해합니다. 어디까지
실측이고 어디부터 추정인지 커버리지 %로 표시되어 과신을 방지합니다.

## 3. 영역별 현황

| 영역 | 상태 | 비고 |
|---|---|---|
| 생산계획 | ✅ 자동차 ERP(오라클) 계획을 매일 자동 수신 — 실데이터 검증 완료 | 신차종 품번 285종 품목 등록이 선행 과제 |
| 사출 실행 | ✅ PLC 단위실적·14자리 시리얼·실측중량, 통신장애 시 백필 원칙 | 이중장부 위험 구조 차단(계획 MO 완료 가드) |
| 품질 | ✅ IATF 47양식 + SQ 평가(증빙 자동조회) + 결재체계 | PR 리뷰 대기 |
| 원가 | ✅ 표준·실제·차이분해·소급(frozen/restated) | 7/3 CFO 검증보고서 참조 |
| 회계 | ✅ 리포트 지적 33항목 중 24 구현 (9건은 담당자 입력 대기) | 별도 검증 세션 PASS |
| 급여 | ✅ 4대보험(EDI 고지액 방식)·간이세액·상여650%·OT 4종·퇴직급여·근태연동 | 요율 확정값 입력 대기 |
| 인프라 | 개발 5개 DB에서 검증 완료 | 운영 정본 DB는 신규 생성+이관 예정 |

## 4. 비용·리스크 관점

- **외부 시스템 대체 효과**: 급여(노무사 위탁분 일부)·세금계산서 관리·수기 원장 작성이
  시스템으로 이동. enterprise 라이선스 범위 내 표준 모듈(자산·회계리포트·급여엔진) 활용으로
  추가 개발 최소화.
- **매년 유지비 최소화 설계**: 보험 요율·세액표·상여율 등 매년 바뀌는 수치는 전부 화면 입력
  방식 — 요율 개정 때 개발자 개입이 필요 없습니다.
- **주요 리스크와 통제**:
  - 운영 이관 시 "코드+DB갱신 세트" 절차 미준수 → 배포 체크리스트로 통제 (드리프트 6건 경험)
  - 담당자 실환경(외부 회계서버)의 임시 자동화 규칙과 이중 실행 → 배포일 비활성화 목록 확보 중
  - 주 52시간 초과 → 근태 집계에서 자동 경고

## 5. 의사결정 요청 사항

1. **운영 서버 이관 일정** — 브랜치 5개 머지 순서·배포 체크리스트는 준비됨. 결정만 필요.
2. **담당자 시간 배정** — 회계(계정매핑·오류재현 등 30분~1시간×2회), 급여(요율·직원명단 제출).
3. **신차종 품목/BOM 적재 착수** — ERP 계획에 이미 등장하는 285종부터. 이것이 끝나면
   "자동차 계획 수신 → 사출 MO 자동 생성"이 실가동됩니다.
4. (선택) 연말정산 내재화 여부 — 노무사 위탁 유지 시 개발 불필요.
