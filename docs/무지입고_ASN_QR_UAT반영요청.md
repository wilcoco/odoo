## 1. 기능 요약 (문서 서술용)

| 기능 | 누가 | 어디서 | 대체하는 것 |
|---|---|---|---|
| 납품 예정(ASN) 등록 | 협력사 | 포털 【납품 예정 등록】 — 품목(자기 납품 품목만)·수량·LOT·도착일·차량정보, 최대 5라인 | 종이 거래명세서 |
| 납품 패스(QR) | 협력사 기사 | 포털 납품예정 목록 [납품 패스] 버튼 → 휴대폰 제시용 화면(대형 QR+품목표) | 서류 전달 |
| QR 스캔 진입 | 입고 담당자 | 태블릿/카메라로 기사 QR 스캔 → (로그인 상태) 입고전표 자동 생성·화면 자동 진입 | 전표 검색·타이핑 |
| 원클릭 전표 | 입고 담당자 | 【구매 > 납품 예정(ASN)】 건 열기 → [입고전표 생성] — 품목·수량·LOT 프리필 | 수동 전표 작성 |
| 인수확인서 PDF | 협력사 | 포털 【납품 인수증】 — 입고 확정 건 PDF 다운로드(일시·수량·LOT·처리담당·IQC 결과·서명란) | 종이 인수증·서명 |

**보안**: QR은 건별 일회성 토큰(포털 토큰과 분리 — 기사 화면 노출 안전), 위조 토큰 404,
포털 접근은 기존 토큰 검증(만료·위조 차단) 재사용. 인수증은 본인 납품·완료 전표만.

**자동 연결(확정 클릭 한 번에)**: 재고↑ · 담당자/일시 기록 · IQC 자동 생성+LOT 보류 ·
ASN "입고 완료" 마킹 · 추적기록 · 협력사 포털 인수확인서 게시.

## 2. UAT 시나리오 (순서서 5단계 교체본 — 그대로 사용 가능)

**5단계. 협력사 납품 → 무지 입고 → 검사 → 사일로** (협력사 역할 + 자재 + 품질, 2인 1조)

*협력사 역할 (포털, 브라우저/휴대폰):*
1. 【납품 예정 등록】 수지 1,000kg·LOT 기재·도착일·차량번호 입력 → 등록
   - ✔ 등록 즉시 이력에 "납품 예정" 표시
2. 목록에서 [납품 패스] → ✔ 휴대폰에 QR+품목표 화면

*자재(입고 담당) 역할:*
3. 경로 A(QR): 담당자 계정으로 로그인된 태블릿에서 기사 QR 스캔
   - ✔ 입고전표가 **자동 생성되어 화면에 열림** (품목·수량·LOT 프리필)
   - 경로 B(수동): 【구매 > 납품 예정(ASN)】 건 열기 → [입고전표 생성] — 같은 결과
4. 실물 대조 → (차이 시 수량 보정) → [확정]
   - ✔ ASN 상태 "입고 완료" / ✔ IQC 자동 생성 + LOT 품질보류
   - ✔ 위조 QR(주소 조작) 접근 → 404 차단

*협력사 역할:*
5. 포털 【납품 인수증】 → ✔ 방금 건 PDF 다운로드 (수량·LOT·처리담당·IQC 결과 확인)

*품질·현장 (기존 유지):*
6. IQC 합격 전 사일로 적재 시도 → ✔ 차단 / 합격 판정 → ✔ 보류 해제 → 적재 → 톤정산 (기존 절차)

**확인 포인트 추가분**: 담당자 타이핑이 수량 보정 외 0인지 / 부족 납품(예: 1,000 중 800만 도착) 시
800 확정 → 협력사 포털에 800으로 표시되는지(차이 투명성)

- 6단계 협력사 역할에 추가: `[ ] 납품 예정 등록·납품 패스 화면 표시` / 인수증 항목의 "(머지·배포 후 활성화)" 문구를 배포 상태에 맞게 갱신
