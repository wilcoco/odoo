## 1단계. 협력사 계정 발급 (구매) — 기능 A

지금까지는 협력사에 토큰 링크를 보내거나 초대 메일을 발송해야 했고, 메일이 안 가거나
링크가 만료되면 전화가 왔습니다. 이제 관리자가 그 자리에서 아이디/비번을 정해 알려줄 수 있습니다.

1. 【연락처】에서 원재료 협력사 하나를 엽니다 (없으면 `TEST-원재료협력사` 생성)
2. **[협력사 포탈]** 탭 → `포탈 사용` 체크
3. **[아이디/비밀번호 직접 설정]** 버튼
4. 아이디(예: `test-raw`), 비밀번호(8자 이상) 2회 입력 → **[적용]**
5. 완료 화면에 뜨는 **아이디**와 **접속 주소**를 메모

- [ ] 완료 화면에 아이디·접속 주소가 표시된다
- [ ] 시크릿 창에서 그 주소로 접속 → 방금 정한 아이디/비번으로 **로그인된다**
- [ ] 협력사 대시보드가 뜬다 (사내 메뉴는 하나도 안 보인다)
- [ ] 연락처 폼으로 돌아가 **챗터를 확인** → 계정 설정 기록은 남아 있고 **비밀번호는 안 적혀 있다**
- [ ] 같은 협력사에 **[아이디/비밀번호 직접 설정]** 을 한 번 더 눌러 비번만 바꿈 → 새 비번으로 로그인되고 옛 비번은 거부된다
- [ ] 기존 **토큰 링크도 여전히 동작한다** (아이디/비번은 토큰을 대체하는 게 아니라 추가된 것)

**실무 확인 질문 (기록해 주세요)**
- 비밀번호를 협력사에 무엇으로 전달할 계획입니까? (전화/문자/대면) — 챗터에 안 남기는 게 맞습니까?
- 최소 8자 규칙이 협력사 현장에서 과한가/부족한가?

🔒 권한: 이 버튼은 **관리자(ERP 관리자 그룹)만** 눌러야 합니다. 일반 구매 담당 계정이 확보되면
그 계정으로 버튼이 안 보이는지(또는 오류가 나는지) 별도 검증 — admin 공용 체제에선 스킵.

## 2단계. 사출 계획 관제 화면 (생산관리) — 기능 D

**【사출 현장 › 사출 계획 관제】** (또는 【사출 생산계획 › 사출 계획 관제】)

지금까지는 수요 로드 → 계획 계산 → MO 발행 → 소진 예측 → 보충 통보가 각각 다른 메뉴에
흩어져 있어, 담당자가 "지금 어디까지 했더라"를 기억해야 했습니다. 이 화면은 그 사슬 전체를
한 장에 놓고 **지금 눌러야 할 버튼 하나만** 가리킵니다.

### 2-1. 빈 상태에서 시작

1. 관제 화면을 엽니다 (계획이 없으면 자동으로 새 계획이 열립니다)
2. 계획 기간을 입력합니다 (예: 다음 주 5일)

- [ ] 화면 위쪽 배너가 **① 수요 로드**를 가리킨다
- [ ] 부품 흐름(①~④)과 원재료 흐름(⑤~⑧)이 **위아래 두 줄**로 구분돼 보인다
- [ ] 아직 안 한 단계에는 초록 완료 표시가 없다

### 2-2. 사슬을 순서대로 진행

각 단계마다 **배너가 가리키는 버튼만** 누르세요. 배너를 무시하고 뒤 단계를 먼저 눌러도 되는지도
같이 봐 주십시오(눌러지면 안 되는 게 정상입니다).

1. **[수요 로드]** → 자동차 생산계획이 들어옴
2. **[계획 계산]** → BOM 전개 → 필요량 → 재고 대비 사출 계획 수립
3. 계획 확정 → **[MO 발행]**
4. **[예측 실행]** → 이 계획이 사일로를 언제 얼마나 소진시키는지 계산
5. **[통보 발행]** → 재주문점 도달 예상 사일로의 소요예상 통보

- [ ] 각 단계를 끝낼 때마다 배너가 **다음 단계로 넘어간다**
- [ ] 마지막까지 가면 배너가 **"완료 — 모니터링"** 으로 바뀐다
- [ ] 「지금 여기」 표시가 **한 곳에만** 있다 (두 곳에 있으면 결함 — 기록)
- [ ] 앞 단계를 안 했는데 뒤 단계 버튼을 누르면 **막히거나 안내가 나온다**
- [ ] 하단 탭 「① 수요」 「③ 사출 생산계획」 「⑤ 원재료 일자별 소요」의 숫자가 카드의 숫자와 **일치한다**

### 2-3. 되돌아가기 (이게 진짜 시험입니다)

계획을 다 돌린 뒤 **수요를 다시 로드**하거나 **계획을 재계산**해 보세요.

- [ ] 재실행해도 **MO가 중복 발행되지 않는다**
- [ ] 사람이 손으로 조정한 값이 있었다면 **그 값이 보존된다** (덮어써지면 반드시 기록)
- [ ] 배너가 적절한 단계로 되돌아간다

**실무 확인 질문**
- 배너가 가리키는 문구("계획 기간의 자동차 생산계획을 불러옵니다" 등)가 현장 용어와 맞습니까?
- ①~⑧ 번호 체계가 직관적입니까, 아니면 이름만으로 충분합니까?
- 이 화면 하나로 기존 메뉴들을 대체할 수 있겠습니까? (아니라면 무엇이 빠졌는지)

## 3단계. 사일로 소진 예측 → 보충 통보 (생산관리 + 자재) — 기능 D

**【사출 현장 › 원재료 수급 현황】** 아래 세 메뉴:
`SILO 재고·발주 현황` / `소진 예측 (그래프)` / `소요예상 통보 (발주)`

발주 규칙은 **30톤 사일로 · 공급 단위 20톤 · 9톤 이하면 발주**입니다.
핵심은 *9톤이 된 뒤*가 아니라 **9톤이 될 것으로 예상되는 시점보다 리드타임만큼 앞서** 신호가 나오는 것입니다.

1. 【SILO 재고·발주 현황】에서 테스트 사일로의 현재 잔량·재주문점 확인
2. 【소진 예측 (그래프)】 → 2단계에서 만든 계획 기준 소진 곡선 확인
3. 사일로 폼에서 **[소진 곡선]** / **[소진 예측 재계산]** 동작 확인

- [ ] 소진 곡선이 **계획 기간만큼** 그려진다
- [ ] **재주문 예정일**이 소진 예정일보다 **리드타임만큼 앞선 날짜**다
- [ ] 20톤이 제때 들어오는 것으로 계산되면 **"비는 날"이 안 잡힌다** (정상)
- [ ] 필터 「재주문점 이하」 「소진 예상」이 기대대로 걸린다
- [ ] 【소요예상 통보】 목록에 통보가 생성됐고, **통보 시점 잔량 스냅샷**이 남아 있다
- [ ] 통보 폼에서 **[공급사 통보]** → 협력사 포탈에 알림이 뜬다 (4단계에서 확인)

**끝까지 밀어보기 (권장):** 사일로 잔량을 **9톤 미만으로 직접 수정**해 보세요.

- [ ] 예측 상태가 **즉시** 「발주 필요」류로 바뀐다 (화면만 조용하면 결함 — 반드시 기록)

**실무 확인 질문**
- 리드타임은 실제 공급사 기준으로 어디에 입력돼 있어야 합니까?
- 통보가 나갔는데 공급사가 안 보내면 누가 언제 챙깁니까? (독촉 알림이 필요한지)

## 4단계. 협력사 공급 현황 화면 (자재 — 협력사 역할) — 기능 B·C

**1단계에서 만든 계정으로 시크릿 창 로그인** 후:

- 상단 메뉴 **「공급 현황」** (`/supplier/supply-status`)
- 상단 메뉴 **「소요 전망(비구속)」** (`/supplier/forecast`)

### 4-1. 공급 현황

- [ ] 사일로 **충전 게이지**가 실제 잔량과 맞는다
- [ ] 소진 추이 **그래프가 보인다** (선/막대가 그려짐 — 빈 상자면 기록)
- [ ] **재주문점 임계선**이 그래프에 표시된다
- [ ] 「예상 사일로 잔량」이 3단계 소진 곡선과 **같은 방향**이다
- [ ] 3단계에서 통보를 보낸 품목에 **빨간 「보충 요청」 배지**가 붙어 있다
- [ ] 배지 없는 항목에는 "참고용"이라는 취지의 안내가 함께 보인다

### 4-2. 소요 전망(비구속)

- [ ] BOM 전개된 소요 예상이 일자별로 보인다
- [ ] **"발주가 아니다"** 라는 성격이 화면에서 분명히 읽힌다

### 4-3. 협력사에게 보여도 되는가 (가장 중요)

이 화면은 **외부 회사가 봅니다.** 아래를 눈으로 훑어 주십시오.

- [ ] **다른 협력사** 이름·품목·수량이 하나도 안 보인다
- [ ] 우리 **판매가·원가·마진**이 안 보인다
- [ ] 우리 고객사(자동차사) 이름이 노출돼도 되는 범위인가 — 판단해서 기록
- [ ] 로그아웃 후 같은 주소 재접속 → **접근 거부** 된다
- [ ] 다른 협력사 계정으로 로그인 → **자기 품목만** 보인다

**실무 확인 질문**
- 협력사가 이 화면을 보고 실제로 자체 납품 판단을 할 수 있겠습니까? 뭐가 더 필요합니까?
- 「보충 요청」이라는 말이 협력사에게 발주로 오해될 여지는 없습니까?

## 5단계. 부품 협력사도 같은 화면인가 (자재) — 기능 C

원재료 전용 화면이 아니라 **모든 공급 품목이 같은 구조**여야 합니다.

1. 부품 협력사 하나에도 1단계 방식으로 계정 발급
2. 그 계정으로 「공급 현황」 접속

- [ ] **같은 레이아웃**의 화면이 뜬다 (원재료 전용 화면이 따로 있지 않다)
- [ ] 사일로 게이지 자리에 **재고 카드**가 대신 들어간다
- [ ] 임계선이 **0** 기준으로 그려진다
- [ ] 「보충 요청」 배지는 **원재료에만** 붙고 부품에는 알림만 뜬다 — 이 차이가 의도한 것인지 판단
- [ ] 사일로가 없는 품목에서 **화면이 깨지지 않는다**

## 6단계. 대시보드 야간조 실적 (생산관리) — 회귀 확인

이번에 고친 결함입니다. 이 공장의 하루는 자정이 아니라 **주간교대 시작(08:00)** 에 시작하는데,
7일/30일 집계와 트렌드 그래프가 달력 자정으로 잘려서 **야간조가 0시를 넘겨 만든 물량이
통째로 빠지거나 다음날 칸에 찍히고** 있었습니다.

## 이슈 기록 양식

발견한 것은 아래 형식으로 남겨 주세요. **"이상함"만으로는 고칠 수 없습니다.**

| # | 단계 | 화면/메뉴 | 무엇을 했더니 | 기대한 것 | 실제 | 심각도 | 수행자 |
|---|---|---|---|---|---|---|---|
| 1 | | | | | | 상/중/하 | |

**심각도 기준**
- **상** — 숫자가 틀리다 / 다른 협력사 정보가 보인다 / 중복 발행된다 / 화면이 죽는다
- **중** — 절차가 막힌다, 우회는 가능
- **하** — 용어·배치·문구

**용어와 문구에 대한 의견도 「하」로 반드시 남겨 주세요.** 이 화면들은 협력사가 보는 것이고,
현장 용어와 어긋나면 결국 전화가 옵니다.
