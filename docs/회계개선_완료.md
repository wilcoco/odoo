## 3. 구현 완료 항목 (§ 번호)
전수 대조: 리포트 §2~§34 총 33항목 = 구현 23 + 보류 10 (아래 4절, 전부 사유 명시) — 누락 없음.
- **§6·§7 품의서 시스템**: `pumui_approval` — 다단계 결재(상신/승인/반려+사유 필수), 계약금/중도금/잔금
  단계별 청구서 생성 위저드, 품의-청구-결제 금액 대사, **승인 전 전기 서버측 차단**(우회 방어)
- **§3** 사업자번호 중복·유사 상호 경고 / **§4·§14** 청구서 결제요약(지급액/잔액 표시)
- **§12** 결제대기(outstanding) 계정 미설정 시 결제 전기 차단 가드
- **§28** 마감 전 체크리스트 (9지표+부가세 3지표, 전부 드릴다운)
- **§27** 청구서↔전표 정합 — 체크리스트 '청구↔전표 잔액 불일치' 지표 + 청구서 결제요약 필드로 커버
- **§19·§20** 거래처원장·계정별원장 바로가기 + 일계표/월계표(계정×일/월 피벗)
- **§10** 오늘 전표·일자별 조회 / **§30** 수금/지급 예정표(만기·잔액)
- **§15~§17** 과세/영세/면세 자동추정, 증빙종류, **승인번호 unique 중복차단**, 수정분-원본번호 연결
- **§18** 신고 전 검증(승인번호 누락/사업자번호 없는 거래처분/원본 없는 수정분)
- **§21** 자금현황(은행·현금 저널별 잔액, 당일 입출금, 대기 결제)
- **§29** 매입매출장 + 매출/매입처별 합계표 + **K-GAAP 재무제표**(재무상태표/손익계산서,
  계정유형 매핑 마스터 — 조정 가능, 대차평형 검증 통과)
- **§25** 대출관리(약정 조건 입력형: 매월/만기일시/1회/사용자지정 스케줄, 잔액 자동)
- **§15/§23 (역발상)** 업로드 표준 템플릿 다운로드(세금계산서 매출/매입·은행내역 CSV,
  오두 native import 헤더와 정합, UTF-8 BOM)
- **§26** 고정자산: enterprise `accountant`+`account_asset` 설치로 상각·자산대장 확보 (표준 모듈 사용)
- **§31** 프로젝트별 품의·청구 집계(1단계 피벗) / **§33** 삭제 대신 취소+사유 패턴(품의 반려사유 필수)

검증: pumui 12/12 · guard 7/7 · reports P3 7/7 · P4 20/20 (cams, `env.cr.rollback()` 배터리) —
대차평형·멱등(스케줄 재생성 시 지급완료 회차 보존) 포함.

## 5. 코드가 아니라 DB 설정으로 처리한 것
- **enterprise `accountant` + `account_asset` 설치** — test_cams1 / test_plan1 / cams_stg 3개 DB.
  (enterprise 소스는 절대 규칙에 따라 git 미포함 — 검증 세션이 복제 DB를 만들면 모듈 설치 상태는
  복제되지만, 새 DB에 새로 설치하려면 `/mnt/enterprise` addons-path 필요)
- **임시 자동화 규칙 관련**: 로컬 4개 DB(cams/test_cams1/test_plan1/cams_stg) 모두
  `base_automation` 테이블 자체가 없음을 확인 — 리포트에 언급된 임시 규칙(청구서 총계 자동계산,
  고아결제 감지 등)은 **회계 담당자의 외부 환경에만 존재**. 따라서 로컬에서 비활성화할 대상이 없었고,
  코드 승격분(승인 전 전기차단·결제계정 가드·체크리스트 검출)을 그 환경에 배포하는 시점에
  기존 임시 규칙 비활성화가 **배포 체크리스트 항목으로 필요** (미수행 상태임을 명시).
- 그 외 Live View 수정·계정 추가 등 DB-only 변경 없음. 모든 기능은 코드(브랜치)로 재현 가능.

## 6. 검증 세션 참고
- 재현 절차: 복제 DB에 `-u pumui_approval,account_kr_guard,account_kr_reports`
  (의존 iatf_approval 자동 설치). odoo.conf addons-path 순서: enterprise → custom → core.
- cams의 gh_fcaio/morning_rc 로드 에러, cams_stg의 car.info.quick.wizard 에러는
  타 개발자 모듈의 기존 이슈로 본 작업과 무관.
