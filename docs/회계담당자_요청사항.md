# 회계 담당자님께 요청드리는 자료 목록

작성: 2026-07-18 (개발팀)
배경: 「오두 회계 사용 리포트」 33개 지적사항 중 24건은 개발·배포 완료했습니다.
남은 9건 + 정밀화 6건은 **담당자님만 주실 수 있는 자료·판단**이 선행되어야 합니다.
아래 자료를 주시면 순서대로 마무리하겠습니다. (완벽한 형식 불필요 — 쓰시던 파일 그대로 주셔도 됩니다)

---

## A. 오류 재현 정보 3건 (§5·§11·§13) — 가장 급합니다
버그 수정은 재현이 되어야 원인을 잡을 수 있습니다. 각 건에 대해:

1. **§5 청구서 총계 0원**: 총계가 0원으로 나온 **청구서 번호** 몇 개와,
   그 청구서를 만들 때의 절차(어느 메뉴에서, 세금 어떤 걸 선택했는지). 화면 캡처면 충분합니다.
2. **§11 "외화 누락" 오류**: 그 오류 메시지가 뜬 **화면 캡처**(메시지 전문 포함)와
   무엇을 하던 중이었는지 한 줄.
3. **§13 결제 취소 후 청구서 수정 꼬임**: 꼬였던 **청구서/결제 번호**와
   취소→수정을 어떤 순서로 하셨는지 순서만 적어주세요.

## B. 은행 거래내역 파일 (§22 자동매칭)
- **IBK기업은행, 전북은행** 인터넷뱅킹에서 내려받은 거래내역 파일 **각 1개** (엑셀/CSV 원본 그대로).
- 계좌번호·잔액은 지우거나 가리셔도 됩니다. **열 제목과 데이터 몇 줄**만 있으면 됩니다.
- 이것이 있어야 "파일 올리면 자동으로 전표 매칭"을 그 양식에 정확히 맞춰 만듭니다.

## C. 현재 쓰시는 자동화 규칙 목록 (§32)
- 지금 회계 오두에 설정된 자동화 규칙(청구서 총계 자동계산, 고아결제 감지 등)의 목록.
- 방법: 설정 → 기술 → 자동화 규칙 화면 캡처면 됩니다. (접속 정보를 주시면 저희가 직접 봐도 됩니다)
- 이유: 이번 개발분이 같은 일을 코드로 대신하므로, **중복 실행 방지를 위해 배포일에
  기존 규칙을 끄는 목록**이 필요합니다.

## D. 계정·거래처 정리 기준 (§2·§24) — 미팅 30분~1시간
- 안 쓰는 계정과목 중 **숨길 것** 목록 / 영문 계정명 중 **한글로 바꿀 것** 목록
- 거래처 목록에서 유형(고객/공급사) 정리 기준
- 목록을 미리 만드실 필요 없습니다 — 화면 같이 보면서 정하는 **설정 미팅 1회**면 충분합니다.

## E. 사용자·권한 표 (§8)
아래 표만 채워주세요:

| 이름(오두 로그인) | 전표 작성 | 품의 승인 | 지급 실행 | 관리자 |
|---|---|---|---|---|
| (예) 홍길동 | O | X | X | X |

## F. 자산 목록 (§26 고정자산)
- 현재 관리 중인 고정자산 목록: **자산명 / 취득일 / 취득가액 / 내용연수(또는 상각방법)**.
- 쓰시던 엑셀 대장 그대로 주시면 됩니다. 저희가 오두 자산 모듈에 올리는 템플릿으로 변환해 드립니다.

## G. 부문 구분 기준 (§29 구분손익: 전주공장/서비스)
- 매출·비용을 부문으로 나눌 때 **무엇을 기준으로 나누는지**만 알려주세요.
  (예: 거래처별로 나뉜다 / 품목별로 나뉜다 / 계정과목별로 나뉜다 / 담당자가 건별로 지정한다)
- 기준에 따라 설계가 완전히 달라져서, 이것 없이 만들면 재작업이 됩니다.

## H. 실제 쓰시는 보고서 양식 (§19·§20 정밀화, §23 2단계)
- 지금 수기로 만드시는 **일계표 엑셀 양식** 1부 (전일잔액 이월 형식이면 그 형태 그대로)
- 세금계산서 대량 업로드 시 "이런 오류 요약 화면이면 좋겠다" 하는 의견 (자유 서술)

## I. 판단 요청 (§9 그리드 전표입력)
- 이번에 enterprise 회계가 설치되어 표준 전표 화면이 개선되었습니다.
  **1~2주 써보시고** 그래도 엑셀식 그리드 입력이 필요한지 의견 주세요. 필요 없으면 개발 안 합니다.

## 우선순위 (전부 한번에 안 주셔도 됩니다)
1. **A (오류 재현 3건)** + **C (자동화 규칙 목록)** — 배포 전 필수
2. **B (은행 파일)** + **E (권한 표)** — 다음 개발 착수 조건
3. D 미팅 일정, F·G·H·I — 여유 있을 때

## 제공 방법
- 파일·캡처는 개발팀에 전달 (형식 무관). 계좌번호·주민번호 등 민감정보는 가려주세요.
- 배포일에는 저희가 **체크리스트**(모듈 설치 → 기존 임시 규칙 비활성화 → 잠금 설정)를 갖고
  진행하니, C 목록과 D 미팅만 그 전에 되어 있으면 됩니다.
