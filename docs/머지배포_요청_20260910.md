```bash

  -u account_kr_reports,iatf_mold,iatf_work_environment,iatf_spc,iatf_process_inspection,iatf_ppap,iatf_menu
docker restart odoo_green
```

> 그 내용은 정본 브랜치 `security/20260909-injection-permission`·`checkpoint/20260907`·
