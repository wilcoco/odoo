# [UAT 요청] 사출 생산계획 전 사이클 검증

안녕하세요. 사출 생산계획 시스템의 UAT를 요청드립니다.
이 UAT는 기존 **「발주 없는 매입 UAT 순서서」의 자매편**입니다 — 그쪽이 부품 정산(무발주)·포털·회계, 이쪽이 **생산계획→사출 생산→품질**입니다. 겹치는 단계(원재료 입고·IQC·사일로·톤정산)는 순서서에서 완료했으면 생략하도록 상호참조되어 있습니다.

## ⚠️ 환경·접속 — 반드시 확인 (가장 중요)

로그인 화면에 **DB 선택 메뉴가 없습니다.** 주소의 `?db=` 또는 지정된 URL을 그대로 즐겨찾기에 등록해 접속하세요.

| 환경 | 주소 | 언제 |
|---|---|---|
| A. 운영 서버 (순서서와 동일) | `http://10.10.21.20/odoo` (DB: odoo18) | 실데이터(품목 707·BOM 524) 기반 — 단 **계획 신기능(테스트 수요 입력·수요 소스 선택·단위 기준) 배포 완료 공지 후** 진행 |
| B. 로컬 UAT DB | `http://<서버주소>:8069/web/login?db=uat_plan1` | 신기능 포함 — **지금 즉시 가능**. 계정 `uat / uat1234!` |

- **admin 계정으로 테스트하지 마세요** (순서서 방침 동일 — 역할 권한 검증을 겸합니다)
- 주소에서 DB 지정이 빠지면 다른 DB로 들어갑니다 — 화면에 낯선 데이터가 보이면 주소부터 확인

## 무엇을 검증하나

테스트 수요 입력 → 생산계획 수립 → **원재료 발주·입고**(수지는 발주함, 대금은 톤정산) → 사출 생산 → 재고 증감 → 불량 처리(품질 연동) → 재계획.
※ 매입 구분: **원재료(수지)=발주함**(대금은 적재 실적 톤정산) / **부품=무발주**(사용실적 정산 — 순서서 소관). 실제 오라클 계획이 아직 없어 **"테스트 수요 입력" 메뉴**로 수기 수요를 만들어 진행합니다.

## 진행 방법

첨부한 **「생산계획_UAT_시나리오_매뉴얼」** 순서대로:
- 0~6단계 + 3-B(톤정산), 각 단계에 담당·소요시간·메뉴 경로(【】)·확인 항목(✔)
- 단계마다 **기록 양식**(순서서와 동일: 적합/수정 필요 + 캡처)을 채워주세요
- **"이미 자동 검증된 것" 절 참고** — 금액 계산·차단 로직은 회귀 테스트로 고정돼 있으니, 담당자는 화면·용어·절차가 실무와 맞는지에 집중하시면 됩니다
- 문서 끝 **"자주 걸리는 함정" 6개를 먼저 읽어주세요** (풀캐퍼 정책, 계획 MO 완료 버튼 차단 등 — 버그처럼 보이는 정상 동작)

## 이슈 발견 시

1. 어느 단계에서 2. 무엇을 입력/클릭했고(캡처) 3. 무엇이 나왔는지 — 3가지면 당일 원인 분석해 드립니다.
화면 채터(메시지 로그)의 **⚠ 경고 문구**는 그대로 캡처해 주세요.

## 일정

- 예상 소요: 담당별 합계 약 2.5시간 (기준정보는 순서서 1단계 완료 시 대부분 생략)
- 기한: [날짜]까지 단계별 기록 양식 회신 부탁드립니다
