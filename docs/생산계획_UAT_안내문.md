# [UAT 요청] 사출 생산계획 전 사이클 검증 (양산 전)

안녕하세요. 사출 생산계획 시스템의 UAT를 요청드립니다.

## ⚠️ 접속 — 반드시 이 주소로 (가장 중요)

로그인 화면에 **DB 선택 메뉴가 없습니다.** 아래 주소를 그대로 즐겨찾기에 등록하고, 항상 즐겨찾기로 접속하세요:

```
http://<서버주소>:8069/web/login?db=uat_plan1
```

- 계정: **uat / uat1234!** (UAT 전용 계정 — 다른 계정 사용 금지)
- 주소 끝의 **`?db=uat_plan1` 이 빠지면 개발용 DB로 들어가집니다** — 화면 상단에 이상한 데이터가 보이면 주소부터 확인하세요
- uat_plan1 은 UAT 전용 복제 DB — 무엇을 만지셔도 실환경에 영향이 없으니 마음껏 테스트하세요

## 무엇을 검증하나

수요 입력부터 생산·품질까지 한 바퀴입니다:
테스트 수요 입력 → 생산계획 수립 → 원재료 발주·입고 → 사출 생산 → 재고 증감 확인 → 불량 처리(품질 연동) → 재계획.
실제 오라클 생산계획이 아직 없어, **"테스트 수요 입력" 메뉴로 수기 수요를 만들어** 진행하시면 됩니다.

## 진행 방법

첨부한 **「생산계획_UAT_시나리오_매뉴얼」** 순서대로:
- 0~6단계, 각 단계에 메뉴 경로(【】)와 확인 항목(✔)이 있습니다
- 마지막 장의 **합격 판정표**에 단계별 ☐ 체크만 해주시면 됩니다
- 문서 끝 **"자주 걸리는 함정" 6개를 먼저 읽어주세요** — 버그처럼 보이지만 정상 동작인 것(계획 수량이 수요보다 큰 풀캐퍼 정책, 계획 MO 완료 버튼 차단 등)이 정리돼 있습니다

## 이슈 발견 시

아래 3가지만 적어주시면 바로 재현·수정 가능합니다:
1. 어느 단계(예: 3-4 입고)에서
2. 무엇을 입력/클릭했고 (화면 캡처면 더 좋음)
3. 무엇이 나왔는지 (기대와 다른 점)

특히 화면의 **채터(메시지 로그)에 ⚠ 경고**가 뜨면 그 문구를 그대로 캡처해 주세요 — 시스템이 원인을 이미 적어둔 경우가 많습니다.
