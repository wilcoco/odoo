# 사출 생산계획 UAT 시나리오 & 사용 매뉴얼

작성: 2026-08-18 · 대상: 각 단계 담당자(영업·자재·생산·회계·품질)·테스터 · 환경: 테스트 DB (양산 전)
목적: 수요 입력 → 계획 → 발주·입고 → 사출 생산 → 재고 증감 → 품질 유입까지 **전 사이클을 손으로 한 바퀴** 돌려 검증한다.

> 표기: 【메뉴】 = 화면 경로, ✔ = 확인(합격 기준). 각 단계의 ✔가 모두 통과하면 UAT 합격.

## ⚠️ 환경·접속 — 「발주없는매입 UAT 순서서」와 함께 보세요

## 0. 사전 준비 (최초 1회 — 기준정보)

> 순서서 1단계(마스터 실값 입력)를 이미 진행했다면 0-3~0-5는 완료 상태입니다 — 0-1·0-2(단위 기준)만 확인하세요.

| # | 할 일 | 메뉴 | 내용 |
|---|---|---|---|
| 0-1 | 단위 기준 확인 | 생산계획 > 기준정보 > 단위 기준 정책 | 재고 kg / **BOM 원단위 g** / 실측 g / 수량 개 |
| 0-2 | 단위 정합 점검 | 〃 > 단위 정합 점검 → [점검 실행] | ✔ 위반 0건 (위반 있으면 [보기]로 열어 수정) |
| 0-3 | 품목·BOM | 기준정보 > 품목/BOM | 완제품 BOM(완제품→사출품×n), 사출품 BOM(→수지 g, 마스터배치 g). **원단위는 반드시 g로** |
| 0-4 | 사출기-금형 조합 | 생산계획 > 기준정보 > 사출기-금형 조합 | 사이클타임(초)·캐비티·불량률·초기불량. 시간당 능력은 자동계산 |
| 0-5 | 원재료 공급사 | 품목(수지) > 구매 탭 | 공급업체·단가·리드타임 등록 — **없으면 자동발주에서 제외됨** |
| 0-6 | 교대·계획 설정 | 생산계획 > 설정 | 주/야 교대 시작시각, 안전재고 일수(기본 3), 최소로트, MO 분할 모드 |

## 1. 테스트 수요 만들기 (양산 전 — 오라클 계획 없음)

【생산계획 > 테스트 수요 입력】
1. 라인 추가: 완제품 품번(BOM 있는 것만 목록에 뜸) / 수요일 / 수량
   - 예: `V-완제품` 8/20 100개, 8/21 150개
2. [수요 생성] → 생성된 수요 목록이 열림
- ✔ 수요의 **소스 = 테스트** 로 표시
- ✔ 【생산계획 > 수요 데이터】 에서도 같은 건 조회됨 (원장 하나)

## 2. 계획 수립

【생산계획 > 계획 실행】 새로 만들기
1. 계획 기간 입력 (예: 8/20~8/22), **수요 소스 = 테스트** 선택
2. [수요 불러오기] — ✔ 테스트 수요만 로드 (오라클/수동 수요가 섞이지 않음)
3. [가동 일정 생성] — 사출기×날짜 가동시간 생성 (휴무일은 시간 0으로 수정 가능)
4. [계획 계산] — 자동 6단계: BOM 전개→순수요(재고·**진행 중 MO 차감**·안전재고·최대재고)→사출기 배정(형체력·유효능력·금형교환 최소화)→계획 라인→일별 요약→자재 소요
- ✔ 계획 라인에 호기/금형/일자/교대/수량 채워짐
- ✔ 채터에 경고(⚠) 없는지 — 있으면 내용대로 마스터 보완 (capability 없음, 다중 BOM 등)
- ✔ **풀캐퍼 정책 이해**: 생산하는 날은 하루 최대치로 계획됨 (수요보다 큼) — 최대재고를 설정하면 상한이 걸림
5. 검토 상태에서 라인 수동 조정 가능 — 재계산하려면 [초안으로] 후 다시 계산 (수동 조정 보호)

## 3. 원재료 소요 확인 → 발주 → 입고 (원재료사 납품)

계획 화면에서:
1. [원재료 소요] — ✔ 수지 소요량 = 계획수량 × 원단위(g→kg 자동 환산), **마스터배치도 0이 아닌 정확한 kg** 표시
2. ✔ 재고 부족(is_short) 표시 — 부족 수량·최초 소요일 확인. [원재료 일별 추이]로 결품 시점 확인
3. [원재료 발주 생성] — 공급업체별 발주서 자동 생성 (리드타임 역산 납기)
   - ✔ 공급사 미등록 품목은 채터에 "발주 제외" 경고
4. **입고 처리 — 무지(無紙) 입고 우선** (운영 서버 배포 완료 — 2026-08-20 검증):
   - 신형 A(QR): 협력사가 포털에 납품 예정(ASN) 등록 → 기사 QR을 담당자가 스캔
     → ✔ 입고전표 자동 생성·열림 (품목·수량·LOT 프리필 — 타이핑은 수량 보정만)
     ※ 스캔 계정은 **재고 또는 구매 권한 필수** (SCM 검토수정 배포 후 권한 축소 — 없으면 전표 생성 실패)
     ※ ASN 세부 검증(같은 품목 2줄·폼 전체 거부 등)은 순서서 5단계 추가 체크 참조 (⏳ 배포 후 유효)
   - 신형 B(원클릭): 【구매 > 납품 예정(ASN)】 건 열기 → [입고전표 생성]
   - 폴백(수동): 발주서 → 입고(Receipt) → 로트번호 입력 (배포 전·ASN 미등록 납품)
   - ✔ 확정 시 원재료 재고 증가 + **IQC 자동 생성 + 로트 품질보류**(제조 투입 차단)
   - ✔ **협력사 포털 [납품 인수증]에서 인수확인서 PDF** 내려받아지는지 (수량·LOT·IQC 결과)
5. IQC 합격 판정 → ✔ 보류 해제 (이제 투입 가능)

## 3-B. 원재료 대금 정산 — 톤정산 (적재 실적 기준)

> **매입 구분 (실무 규칙)**: **원재료(수지)는 발주를 한다** — 3단계(발주→입고→IQC→사일로)가
> 그 경로다. 다만 **대금 정산은 발주서 금액이 아니라 사일로 적재 실적(톤)×톤단가**로
> 월 집계해 매입계산서를 만든다 — 그 정산 검증이 이 절이다.
> **부품은 발주를 하지 않는다** — 생산 사용 실적을 적립해 정산하는 무발주 방식이며,
> 이는 「발주없는매입 UAT 순서서」 2~4단계(부품 정산·가→정단가 소급)에서 검증한다.

1. 톤단가 등록 【사출 현장 > 원재료 정산 > 톤단가】: 공급사×수지×유효기간×원/톤
   - ✔ 등록 시 해당 수지 품목이 자동으로 '톤정산 대상' 표시
2. 사일로 적재 【사출 현장 > SILO】: 공급사 지정하여 적재(충전) 처리 — 예: 3,000kg
   - ✔ 사일로 잔량 증가 + **적재 이력(공급사·일자·수량) 기록**
3. 정산 집계 【원재료 정산】: 기간·공급사 지정 → [집계]
   - ✔ 기간 내 적재 실적이 공급사×수지별 합산 (예: 3.0톤 × 톤단가 = 정산금액)
   - ✔ 월 경계 검증: 말일/1일 적재가 각각 올바른 달에 귀속
4. 정산 확정 → ✔ **매입계산서(공급자청구서) 자동 생성**
   - ✔ 공급가·세액 **별도** 표시 (부가세 포함가로 나오면 즉시 보고 — 세금 설정 결함)
   - ✔ 재집계 차단(확정 후) — 초안에서만 재집계 가능
5. 회계 대사: 【회계 > 공급자청구서】에서 해당 계산서 확인, 품의 연계 여부는 회사 정책에 따름

## 4. MO 확정 → 사출 생산

1. 계획 화면 [MO 생성 확정] → 요약 확인 → [생성]
   - ✔ 계획 라인 수만큼 MO 생성, 호기·금형·`사출 MO` 플래그 전달, 실패 건은 채터에 각인
2. **사출 생산 (현장)**: PLC 연동 환경이면 1타마다 단위 MO+14자리 시리얼 자동.
   테스트 환경 수동 재현: 현장앱(또는 단위 MO 수동 생성)으로 몇 개 완료 처리
   - ✔ **원재료 재고 감소** (수지: 소비 g만큼 — SILO 사용 시 사일로 잔량 차감)
   - ✔ **완제품(사출품) 재고 증가** + 시리얼/로트 생성
   - ✔ 보류 중인 원재료 로트는 투입 시도 시 차단 메시지
3. 생산 마감: 계획 MO는 [계획 종료] 버튼 사용 (완료 버튼은 차단됨 — 이중계상 방지)
   - ✔ 전량 생산 시 상태 '완료', 부분 생산 시 잔여 취소 — **재고는 단위 실적 기준 그대로**

## 5. 불량 처리 → 품질(IATF) 유입

1. 생산 런마다 **공정검사(PQC)** 자동 생성 확인 【IATF 품질 > 공정검사】
   - ✔ 하루·교대 단위 1건 (개당 수천 건 아님), 수량 누적
2. 불량 발생 시나리오: PQC 열어 불합격 수량 입력, 판정=불합격 → [판정]
   - ✔ **부적합(NC) 자동 생성** (제품·MO·불량수량 연결) 【IATF 품질 > 부적합】
   - ✔ 불합격 로트 자동 격리
3. 측정값 있는 검사(예: 중량 783.5g 라인 입력) 판정 시
   - ✔ **SPC 연구(수집 중 상태)에 부분군 자동 적재** 【IATF 품질 > SPC】
4. (선택) SPC 화면 [PLC 실측 수집] — PLC 실측중량 일괄 적재

## 6. 재계획 (연속 운영 확인)

같은 수요로 계획을 한 번 더:
1. 새 계획 실행 → 같은 기간·소스 → [계획 계산]
- ✔ **추가 계획 0 또는 감소** — 진행 중 MO 물량이 자동 차감됨 (이중 생산 방지)
2. 오라클 전환 리허설: 수요 소스=오라클로 새 계획 → [수요 불러오기]가 ERP 수신분만 로드
   - 전제: 서버에 oracledb + Oracle Instant Client(thick) 설치 후 가능
     (시스템 파라미터 `erp_plan_sync.thick_lib_dir` 설정)
   (ERP 수신은 【생산계획 > ERP 계획 연동】 — 품번 미매칭은 보완 큐에서 재매칭)

## 이미 자동 검증된 것 (재확인 불필요 — 담당자는 화면·용어·절차 적합성만)

계획 수량 계산(풀캐퍼·안전재고·최대재고)·원단위 g→kg 환산 정밀·진행 MO 차감(이중 계획 방지)·
소스 분리 로드·MO 생성과 호기/금형 전달·PQC 런 묶음·불합격→NC 자동·측정→SPC 자동 —
전부 회귀 테스트로 고정되어 있습니다. 문제 발견 시 캡처와 함께 보고 — 당일 원인 분석해 드립니다.

## 자주 걸리는 함정 (사전 공지)

1. **BOM 원단위를 kg로 입력하면 소수 3자리째부터 잘림** (0.784→0.78) — 반드시 g로. 단위 정합 점검이 잡아줌
2. 계획 수량이 수요보다 크게 나오는 것은 **풀캐퍼 정책** (정상) — 상한이 필요하면 품목의 최대재고 설정
3. capability(사출기-금형 조합) 없는 품목은 **배정에서 탈락** — 채터 경고 확인 습관화
4. 공급사 미등록 원재료는 자동발주 제외 — 채터 경고 확인
5. 계획 MO에 완료 버튼을 누르면 차단됨 — **[계획 종료]가 정상 경로** (실물은 단위 실적이 정본)
6. 검토 단계에서 수동 조정 후 재계산하면 조정이 날아가므로 서버가 차단 — [초안으로] 후 재계산
7. **금형-제품 불일치는 작업 개시가 차단되지 않음** (예외 생산 허용 정책 — 계획 단계 경고만).
   현재 무승인 상태로 허용되니 결재·승인 절차 결정 전까지 불일치 시작은 주의해서 기록할 것
