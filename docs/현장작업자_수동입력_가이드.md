# 현장 작업자 수동 입력 가이드 (PLC 미연동 시)

대상: 사출 현장 작업자·반장 · 상황: **PLC 자동연동이 안 될 때**(설비 점검·통신 장애·신규 설비) 실적을 손으로 입력하는 절차.
원칙: 평소엔 PLC가 자동 기록(`/api/plc/complete`). 아래는 **대체(수동) 절차**.

> 📸 스크린샷은 실제 화면에서 캡처해 각 [스크린샷 N] 자리에 삽입하세요(캡처 대상 설명 포함).

---

## 0. 시작 전 확인
- 내 사출기(작업장)와 금형이 맞는지, 오늘 생산할 MO가 있는지.
🖥️ `사출 현장 > 생산관리 > MO > 오늘의 제조 주문서`
> 📸 **[스크린샷 1]** 오늘의 제조 주문서 목록 — 내 사출기 MO가 보이는 화면.

---

## 1. 사출 1개 완성마다 — 생산 기록 입력
🖥️ `사출 현장 > 생산관리 > 기록 > 사출품 생산 기록` → 우상단 **[새로 만들기]**
> 📸 **[스크린샷 2]** 사출품 생산 기록 리스트 + [새로 만들기] 버튼 위치.

**입력 필드(순서대로):**
| 필드 | 입력값 | 비고 |
|---|---|---|
| 제조 오더(mo_id) | 내 계획 MO 선택 | 필수 |
| 작업장(workcenter_id) | 내 사출기 | 필수 |
| 생산 품목(product_id) | 자동(제품) | MO 기준 |
| 사용 금형(mold_id) | 장착 금형 | |
| **측정 중량(measured_weight)** | **저울 실측값(g) 입력** | ★ 원가 정밀도 핵심 |
| **실측중량 여부(weight_is_measured)** | **체크 ON** | ★ 수동이어도 실측이면 ON |
| 사용 원재료 LOT | 투입 수지 LOT | |

▶️ **[저장]**
> 📸 **[스크린샷 3]** 생산 기록 폼 — 측정 중량·실측중량 여부 체크 위치 강조.

⚠️ **핵심**: `측정 중량`에 **실제 저울값**을 넣고 `실측중량 여부`를 **반드시 체크(ON)**.
- 체크 ON → 실제원가에 "실측"으로 반영(커버리지↑).
- 체크 OFF/미입력 → 표준으로 대체(커버리지 0). 저울값이 진짜면 꼭 ON.

---

## 2. 양품 / 불량 판정
- **양품**: 위 1번처럼 측정 중량 > 0 입력(정상 기록).
- **불량**: 측정 중량 **0** 입력(또는 불량으로 표시) → 시스템이 불량 수량으로 집계.
> 📸 **[스크린샷 4]** 불량 기록 예시(측정 중량 0 또는 불량 표시).

🖥️ 검사 연동: `사출 현장 > 품질관리 > 중량 검사`에서 pass/fail 확인.
- NG는 `품질관리 > 중량 검사 불합격`(quality.alert)에 자동 등록 → 필요 시 8D 시정.
> 📸 **[스크린샷 5]** 중량 검사(quality.check) 목록 — pass/fail 표시.

---

## 3. 초·중·종물 검사 (교대/로트 시작·중간·끝)
🖥️ `사출 현장 > 품질관리 > 초중종물 검사`
- 로트 시작·중간·끝 샘플 검사 기록. NG면 `초중종물 품질 불합격` 등록.
> 📸 **[스크린샷 6]** 초중종물 검사 입력 화면.

---

## 4. 수지(원재료) 재고 확인·차감
- 자동 소비가 안 될 때(수동 상황) SILO 재고를 확인:
🖥️ `사출 현장 > 사출 설정 > 작업장 > SILO 관리` → 내 사출기 SILO 잔량(current_qty) 확인.
- 필요 시 반장이 소비/보충 반영. 잔량이 재발주점 미만이면 **소요예상 통보** 자동 발생.
> 📸 **[스크린샷 7]** SILO 관리 — 잔량·재발주점.

---

## 5. 교대 종료 시 마감 확인
- 오늘 생산한 기록 수 = 실제 생산 수량과 일치하는지.
🖥️ `오늘의 제조 주문서` → MO 열어 **현장 양품/불량 수량**(qty_good_worksite/qty_defects_worksite) 확인.
> 📸 **[스크린샷 8]** MO 폼 — 현장 양품/불량 수량.

⚠️ 수량 불일치 시 반장에게 보고(누락 기록·중복 확인).

---

## 요약 카드 (붙여두고 보는 용)
```
사출 1개 완성
  → 사출품 생산 기록 [새로 만들기]
     · MO 선택 / 사출기 선택
     · 측정 중량 = 저울값(g)         ← 실제값!
     · 실측중량 여부 = 체크 ON        ← 잊지 말 것!
     · (불량이면 측정 중량 0)
  → 저장
교대 끝 → MO에서 양품/불량 수량 확인
```
