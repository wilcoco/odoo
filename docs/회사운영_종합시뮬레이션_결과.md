- **조립 BOM**: 완제품 → 사출부품 + 외주부품. **사출 BOM**: 사출부품 → 수지 0.5kg
- 가상 업체 3: 가상수지㈜·가상체결구㈜·가상클립㈜ (SCM 부품공급)
- 초기재고(사출부품 200/외주 300·500), 사일로 SIM-SILO 800/2000kg(재주문점 500)
- 10일 수요(완제품1 50/일, 완제품2 40/일)

## ✅ 정상 작동 확인
1. **BOM 기반 조립/사출 구조** — 완제품→사출부품+외주부품→수지 다단계 전개.
2. **사일로 → 소요예상 통보(보조자료)** — 우리 모델대로 정식발주 아닌 통보.
3. **불량 → IATF 부적합 → 생산 연계** — production_id/lot_id/product_id 연동. 대시보드에 nc_open/nc_total_ytd/ca_open 집계필드 존재(G4 반영).
4. **생산량 기준 업체 마감(회계)** — MO 완료 시 BOM 전개로 협력사별 자재 정산 자동 생성. 우리 회사 핵심 모델 작동.

## 🔴 추가개발 목록 (우선순위)

### [P1] 납기경과 미입고(납품 실패) 자동감지 + 생산영향 경고 ★중요
- 현재: '외주 발주 미응답 리마인더' cron, Odoo 'receipt reminder'는 있으나 → **'납기 지났는데 미입고=납품 실패'를 자동 감지해 어느 생산(MO/조립)이 막히는지 경고·에스컬레이션하는 메커니즘 없음.**
- 개발: 지연 입고 감지 cron + 영향받는 MO 식별 + 담당자/포탈 경고(supplier.portal.notification 재활용) + 대체발주/긴급 통보.

### [P2] 조립 MO 부품 재고소비 정확성 ★중요
- 현상: 시뮬에서 조립 MO 완료 시 원자재 이동이 cancel(0 소비)로 끝남 → 부품 재고 미차감.
- 원인 후보: 백엔드 MO 완료 플로우 + consu 제품 재고처리. UI 정상여부 + backflush 설정 점검 필요.
- 영향: 재고관리(입고·차감) 정확도. 마감은 생산량 기준이라 무관하나, 재고 가시성엔 영향.

### [P3] 불량 → 시정조치 자동연결 UX
- iatf.corrective.action 필수필드 많음(name·ca_type·responsible·due_date·state). 부적합에서 '시정조치 생성' 버튼으로 기본값 채워 자동연결하는 UX 보강.

### [P4] 원재료 톤당 정산 '납품 톤' 집계 소스 확정
- 현재 SILO 충전 lot라인(loaded_qty) 의존. 외부 잔량센서가 lot라인 안 남기면 별도 납품실적 입력 필요 → 센서 연동방식 확정.

### [P5] 계약단가 마스터 운영
- vendor.part.price(부품)·material.ton.price(원재료 톤단가) 미설정 시 standard_price 폴백. 운영 전 계약단가 입력 필수.

### [P6] 사출 스케줄링 엔진(사출기 배정) — SIM 제품 미연동
- injection_planning 스케줄러는 mold/machine/capability 설정 필요. SIM 제품엔 미설정(기존 injection 데모로만 검증). 실품번 적용 시 capability 마스터 구축 필요.

## 종합 판정
