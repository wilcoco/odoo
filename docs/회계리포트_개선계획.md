## P0 — 품의서 (리포트 #6·#7) ✅ 구현 완료 (2026-07-15, `pumui_approval` 모듈)
- **품의서 작성**: 거래처·프로젝트·계약명·품목 라인(수량/단가/세금) + **계약금/중도금/잔금 단계**.
- **결재**: 검증된 `iatf.approval.mixin` 재사용 — 기안→상신→다단계 승인/반려(이력·현재승인자).
  **반려 사유 필수**(미입력 반려 차단), 결재선 미지정 상신 차단.
- **청구서 연계**: 승인 후에만 [청구서 생성] — 단계 선택 위저드(전체/계약금/중도금/잔금) →
  고객/공급업체 청구서 자동 생성, 라인↔라인 연결, **부분청구·미청구 잔액·지급완료 상태** 추적.
- **승인 전 지급 차단**: 품의 연계 전표는 미승인 상태에서 `action_post`(전기) 서버 차단 —
  수기로 pumui_id를 붙인 우회 경로까지 방어(검증 ⑥).
- **정합 표시**: 청구서 폼에 품의 링크·승인상태 배지·**품의-청구 차이 금액**(≠0 경고색).
  "품의 미연계 청구서" 전용 메뉴+검색필터(#6 요구).
- 검증(cams, 12/12): 금액 자동계산·미승인 생성/전기 차단·반려사유 필수·계약금만 부분청구→
  잔액 추적→전액 청구 시 차이 0·기청구 단계 재청구 차단·멀티컴퍼니(회사 명시) 수정 반영.
