# 오두 급여 시스템 사용 매뉴얼

대상: 급여 담당자 · 기준: 생산직 급여업무 매뉴얼(2025.04) 반영판 · 2026-07-21

계산식은 시스템에 들어 있고, **담당자는 수치(요율·세액표·고지액·시간)만 입력**합니다.
요율이 바뀌어도 프로그램 수정 없이 화면에서 새 기간 행을 추가하면 됩니다.

---

## 1. 최초 1회 설정

### 1-1. 기준정보 입력 (급여 > 기준정보 입력)
| 화면 | 입력 내용 | 주기 |
|---|---|---|
| **4대보험 요율** | 국민연금·건강·장기요양·고용·산재의 근로자/회사 요율(%), 기준보수 상·하한 | 매년 (기존 행에 '적용 종료' 입력 후 새 행 추가) |
| **간이세액표** | 국세청 근로소득 간이세액표 — '가져오기(Import)'로 일괄 업로드 (컬럼: date_from, income_from, income_to, dependents, tax_amount) | 개정 시 |
| **4대보험 고지액(EDI)** | 직원별 건강보험·국민연금 월 고지액 — **고지액이 있으면 고지액대로 공제, 없으면 요율로 계산** | 매월 또는 고지 변경 시 |

> 현재 요율은 골격값으로 들어 있고 "확정 필요" 표시가 있습니다.
> 국민연금 상·하한, 고용보험 회사분, 산재 업종요율은 고지서 값으로 확정 입력하세요.

### 1-2. 근무 캘린더 (설정 → 기술 → 근무 시간)
- 표준 캘린더의 **시간대(tz)를 Asia/Seoul 로** 변경 (기본이 유럽으로 되어 있음)
- **공휴일을 전사 휴일로 등록** — 등록된 날의 근무는 자동으로 특근/특잔 처리
- 주야 2교대는 교대별 캘린더를 만들어 직원에게 배정

### 1-3. 시스템 파라미터 (필요 시에만, 설정 → 기술 → 시스템 매개변수)
| 키 | 의미 | 기본값 |
|---|---|---|
| hr_payroll_kr.bonus_annual_pct | 상여 연간 % | 650 |
| hr_payroll_kr.monthly_hours | 통상시급 분모(월 소정근로시간) | 209 |
| hr_payroll_kr.meal_tax_free | 식대 비과세 한도 | 200000 |
| hr_payroll_kr.proration | 월급제 일할 방식 | fixed30 (30일 나누기) |
| hr_payroll_kr.lunch_break_hours | 6시간 초과 근무 시 중식 공제 | 1.0 |

## 2. 직원·계약 등록

직원 등록(인사) 후 **계약서**에서:

| 필드 | 설명 |
|---|---|
| 임금 형태 | **월급제 / 일급제(생산직)** — 일급제면 '기본일급' 입력 |
| 급여 구조 유형 | "한국 정규직" 선택 (필수 — 이걸로 급여 규칙이 연결됨) |
| 수습 | 체크 시 급여 90% 지급 + 상여 미지급. 정규 전환 시 해제 |
| 소득세 조정율(%) | 기본 100. 연말정산 과다추징 방지용 직원별 조정 |
| 퇴직급여 제도 | 퇴직금 / DB형 / DC형 |

## 3. 매월 급여 흐름 (순서대로)

### ① 근태 — 출퇴근 기록 확인
- 직원 출퇴근은 **근태(Attendance) 앱**이 정본. 누락·오류는 근태 앱에서 수정.

### ② 급여 > 월 근태 집계
1. 새로 만들기 → 직원·기간(해당 월) 입력
2. **[출퇴근에서 집계]** 클릭 → 자동 분류:
   - 평일: 소정 초과=**잔업**, 미달=**지각/조퇴** / 휴일·공휴일: 8h 이내=**특근**, 초과=**특잔**
   - **심야**: 22시~익일 5시 겹침 / 6h 초과 근무일은 중식 1h 자동 공제
3. 일별 내역에서 이상값 보정 (특별 인정 OT — 사출 휴게근무, 도장 청소 등 — 은 여기서 가감)
4. **주 52시간 초과 경고**가 뜨면 해당 주 근태를 재확인
5. **[확정]** — 확정해야 급여에 반영됩니다 (근태 마감 개념)

### ③ 급여 > 급여명세서 생성·계산
1. 급여명세서(또는 일괄 배치) 생성 → 직원·기간 입력
2. **[시트 계산]** — 확정된 근태 집계가 있으면 근무일수/잔업/특근/특잔/심야/지각 시간이
   **자동으로 들어갑니다** (명세서에 '근태 집계' 링크 표시)
3. 근태 외 항목은 **기타 입력**에 추가:

| 코드 | 항목 | 비고 |
|---|---|---|
| CALW | 통상수당 합계 | 근속·직책·공정·사출·도장·파견·근무형태변경지원금·보전2,3 등 합계 — **통상시급·상여에 반영됨** |
| OALW | 기타수당 합계 | 자격수당 등 — 통상시급 미반영 |
| FAM | 가족수(본인 제외) | 1인당 1만원, 4인 한도 자동 |
| MEAL | 식대 | 20만원까지 비과세 자동 처리 |
| INSADJ | 보험료 정산 | 건보 연말정산 추징은 음수(−), 환급은 양수(+). 분할공제는 나눠서 매월 입력 |
| LOAN / TUITION / CONDOL / OTHDED | 대여금/학자금/경조금/기타공제 | 해당 월 공제액 |
| DEP | 공제대상 가족수(본인 포함) | 간이세액표 조회용, 미입력 시 1 |
| PAYFACT | 지급률 % | 병가 90·80·70·60·50, 산재 30 |
| BONUS0 | 상여 미지급 | 병가 등 — 1 입력 |
| DAYS/OTEXT/OTHOL/OTHOLX/OTNIGHT/LATE | 시간 항목 | 근태 집계에서 자동. **수동으로 넣으면 수동값이 우선** |

4. 재계산 후 명세서 확인 → **확정** → (회계 연계 시) 급여 전표 자동 생성

### 자동 계산되는 것 (입력 불필요)
- 상여금: (기본급+통상수당) × 650% ÷ 12 매월 분할
- OT수당: 통상시급 × 배율 × 시간 — 통상시급 = (기본급+통상수당+상여월분) ÷ 209
  (잔업·특근 1.5 / 특잔 2.0 / 심야 0.5 가산)
- 4대보험: 건보·국민연금은 **고지액 우선**, 고용보험은 지급분×요율, 산재는 회사 전액
- 소득세: 간이세액표 × 조정율, 지방소득세 = 소득세의 10%
- 지각/조퇴 공제: 기본시급(일급÷8) × 시간
- 회사부담분 4종: 명세서 하단 별도 표시 (실지급 무영향, 전표·원가용)

## 4. 특수 케이스

| 케이스 | 처리 |
|---|---|
| 수습 | 계약서 '수습' 체크 → 90% 지급+상여 0 자동. 월 중 정규 전환은 수습/정규 기간을 명세서 2장으로 분리 |
| 중도 입·퇴사 (월급제) | 자동 일할 (30일 나누기) — 계약 시작/종료일 기준 |
| 병가 | PAYFACT(첫달 90 → 80·70·60·50) + BONUS0=1 |
| 산재 | PAYFACT=30 (휴업보상 30%) — **상여는 자동으로 100% 지급** 유지 |
| 지각/조퇴/외출 | 근태 집계에서 자동. 수기 시 LATE에 시간 입력 |

## 5. 퇴직급여 (급여 > 퇴직급여)

- **퇴직금 계산서**: 직원·퇴직일 입력 → [급여에서 집계]로 최근 3개월 임금 자동 합산
  (수기 조정 가능) + 연간 상여·연차수당 입력 → 평균임금·법정퇴직금 자동.
  1년 미만 자동 0, 확정 시 0원 차단.
- **퇴직연금(DC) 납입 대장**: 납입일·금액·금융기관 기록, 연간 임금총액 입력 시
  필요 납입액(1/12) 대비 점검.

## 6. 매년 갱신 체크리스트
1. 4대보험 요율: 기존 행 종료일 입력 → 새 해 행 추가 (1월)
2. 간이세액표: 국세청 개정 여부 확인 → 개정 시 재업로드
3. 건보 연말정산(4월): 추징/환급을 INSADJ로 (과다 시 2~3회 분할)
4. 국민연금 보수월액 변경(7월): 새 고지액을 고지액(EDI) 화면에 입력
5. 상여율·수당 변경(임단협): 파라미터/통상수당 입력값 갱신
6. 학자금 의무상환(7월~익년 6월): 통지서 금액을 TUITION으로 매월

## 7. 아직 시스템 밖인 것 (수기 유지)
- 연말정산 (노무사 위탁 여부 확인 후 결정)
- 상여 원천세 3배수 특례 (노조 협의 사항 — 필요 시 개발)
- 특별 인정 OT 자동화 (사출 휴게 10+10분 등 — 현재는 근태 집계 보정으로 처리)
- 통상임금-평균임금 비교 (퇴직금) — 통상임금 산정 기준 확정 후
