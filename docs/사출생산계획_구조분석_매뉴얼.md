## 1. 전체 구조 (한 장)


## 2. 운영 매뉴얼 (절차)

### 2-1. 기준정보 (선행, 실값 입력 지점)
| 대상 | 메뉴 | 실값 필드 |
|---|---|---|
| 사출기-금형 조합 | 생산계획 > 마스터 데이터 > 사출기-금형 조합 | **cycle_time(초)·cavity·불량률(%)·초기불량(개)** → 시간당능력 자동 |
| 금형 | 〃 > 금형 관리 | **changeover_hours(교체시간, 금형별)**·보증샷수 |
| 품목 | 〃 > 사출 제품/부품 | **min_lot_size·max_inventory_qty·injection_base_code**(컬러 제외 기준코드) |
| 사출기 가동일정 | 〃 > 사출기 가동 일정 | **일자×사출기별 주/야 가용시간, 비가동 사유(PM·고장·휴무), 전일 장착 금형** |
| 계획 파라미터 | 생산계획 > 설정 | 교대시간·시작시각, **기본 교체시간·불량률·초기불량·최소로트**, 안전재고일수, MO분할(없음/교대), Oracle 접속 |

### 2-2. 계획 실행
1. `생산계획 > 계획 실행` 새 Run 생성 (기간 from~to)
2. 수요 확보 — 3경로 중 택:
   - **[Oracle 조회]** 원청 생산계획(일별 T_ZM_PLN1 + 시간별 T_ZM_PLN2) 자동 수신·합산
   - [수요 추가] 수동 / [파일 임포트] 엑셀
3. **[계획 계산]** → ②~⑤ 자동 실행 → 상태 `review`, 계획라인 생성
   - 재계산 가드: 계산된 계획은 '초안으로' 후에만 재계산(수동 편집 보존)
4. 검토: 계획라인(일×사출기, 시작~종료시각, 교체 여부/시간, 불량 반영 수량) · 일별 요약/차트 · **원재료 소요**(수지, 일별)
5. **[MO 생성]** → 계획 MO 발행(사출 현장으로) / 필요 시 원재료 PO

### 2-3. 산출물 읽는 법 (계획라인)
`순수요` 재고·안전재고 반영 생산必수량 → `계획수량` 불량률+초기불량 gross-up → `교체`(금형교체 여부/시간) → `생산/총시간` → `시작~종료`(교대 타임라인).

## 3. 핵심 알고리즘 (세부)

### ② BOM 전개 — 컬러 대응이 설계에 내장
완제품 BOM 라인을 펼쳐 **사출품 기준으로 합산**. 컬러만 다른 완제품(…EBB/…SWP)이 같은 사출품을 쓰므로 자연 합산. BOM 없는 품목은 자체를 사출품으로 간주. (`injection_base_code`로 기준코드 관리)

### ③ 순수요 — "풀캐퍼 생산 + 3일 안전재고" 정책
- running_stock(재고→소비→생산 연속 추적), 생산 필요한 날은 **일 풀캐퍼**로 생산
- 당일 부족 최우선 → 향후 N일(설정) 수요 충당 → **최대재고 상한** → 최소로트 하한 → 정수 올림

### ④ 배정 — 금형교체 최소화 휴리스틱
- 품목별 **시간당능력 최대 조합 1개** 선택 → 그 사출기에 전량
- 사출기 내: 전일 장착 금형 그룹 최우선(교체 0) → 나머지 작업량 많은 순
- 교대(주/야) 타임라인 커서, 비가동일 건너뜀, 잔여시간 부족 시 익일 이월
- 교체 발생 시 금형별 교체시간 + 초기불량 반영. MO분할=교대 옵션

## 6. 개선안 (논의용 — 우선순위 제안)
1. **[즉시·소규모] G1**: `_explode_bom`에서 `is_injection_part`(또는 capability 보유) 품목만 통과 — 이번에 만든 필드가 정확히 이 용도. BOM 전개 시 비사출 라인 제외.
2. **[즉시·로직만] G3+유효능력**: 잡 정렬 납기(날짜)순 / 조합 선택을 `capacity×(1−불량률)` 유효능력 기준으로.
3. **[단기·필드+로직] G5**: 사출기 톤수 + 품목(금형) 요구 형체력 필드 → 적합성 필터 + "적정 최소 기계 우선".
4. **[단기] G4 부하분산**: 최적 기계 캐파 초과 시 차선 기계 분산(현재는 한 대에 몰림), 2금형 병렬 허용.
5. **[협의] G6**: 원재료 조달을 소요통보(무발주)로 일원화할지, PO 병행 유지할지.
6. [저] G2 반올림 이월 정리.

## 7. 향후 문제 시 보는 곳
수요 안 들어옴 → `action_fetch_demand`/Oracle config · 계획 0라인 → 재고/순수요 로그(`[순수요] SKIP`) · 배정 이상 → `_schedule`(best_cap·금형그룹) · 교체시간 이상 → mold.changeover_hours · 시각 이상 → config 교대/availability.
