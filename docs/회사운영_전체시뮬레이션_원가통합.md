## Phase 8 — 표준원가 vs 실제원가 비교 (신규 sim MO, 실측 반영)
| 품목 | 양품 | 표준원가 | 실제원가 | 차이% | PLC커버 | 가격 | 수량 | 능률 | 수율 |
|---|---|---|---|---|---|---|---|---|---|
| INJ-SHELL-A | 100 | 506,222 | 461,670 | **-8.8%** | **100%** | 0 | 0 | -44,552 | 15,187 |
| INJ-BRKT-B | 150 | 245,500 | 241,548 | -1.6% | **100%** | 0 | 0 | -3,952 | 8,183 |
| FIN-BPR-A | 200 | 1,644,444 | 1,622,444 | -1.3% | 0% | -22,000 | 0 | 0 | 0 |
| FIN-BPR-B | 100 | 431,333 | 427,333 | -0.9% | 0% | -4,000 | 0 | 0 | 0 |

- **대사 정합**: Σ(실제−표준) = Σ(가격+수량+능률) **정확히 일치**(수율은 별도).
- **커버리지 100%**(사출품): PLC 실측중량(weight_is_measured=True)이 실제로 반영됨 — 더미였으면 0%. **실측 유입 시 재료 정밀도가 살아남을 입증.**
- 해석: 사출품 능률차이(-)=작업시간이 표준보다 짧음(favorable), 수율차이=불량손실. 조립품 가격차이(-)=외주 가단가(500/175)가 표준(520/180)보다 낮음(favorable).

## 검증된 통합
전 영역이 **하나의 원가 파이프라인으로 연결**됨을 확인:
```
생산(실측) → 재고떨기 → 부족→통보 → 입고 → 마감(정산=실제단가)
   → 표준 vs 실제 4분해·대사정합 → 가단가 정단가 확정 → 소급전표+B표준갱신+restated
```
- **회계 무변경**(valuation=standard/manual_periodic 유지) — 관리원가는 참고치.
- **PLC 실측 반영 시 커버리지 100%** → 실운영 데이터 완성의 관건이 실측 유입임을 재확인.
