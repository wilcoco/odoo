## A. 품질 담당자 일상 업무 매뉴얼

### 1. 수입검사 (IQC) — 자동으로 생깁니다
- 자재가 **입고 확정되는 순간** 제품·LOT별 수입검사서(IQC-….)가 자동 생성되고, 해당 LOT에는 **품질 보류**가 자동으로 걸립니다.
- 보류 중인 LOT은 시스템이 **3중으로 차단**합니다 — ①사일로 적재 불가 ②제조오더 확정 시 투입 불가 ③확정 후 LOT을 지정해도 **실소비 시점에서 최종 차단**. 즉 어떤 경로로도 검사 전 원재료는 생산에 들어가지 않습니다.
- 처리 절차: IQC 문서 열기 → [검사 시작] → 검사수량·합격수량·판정결과 입력 → [판정]
  - **합격/조건부합격** → LOT 보류 자동 해제 → 자재 사용 가능
  - **불합격** → 부적합(NC) 자동 생성 + LOT 격리 — 부적합 처리 절차로 이동
- 확인 지점: 입고전표 화면 상단 "수입검사" 버튼으로 해당 입고의 검사 목록 바로 조회.

### 2. 공정·최종검사 (PQC) — 생산 런(품목×생산일×교대) 단위로 생성됩니다
- **사출(단위 실적) 생산**: 검사서 1장 = **"이 품목의 그 날 그 교대 생산 런"**입니다. 그 런의 첫 타가 완료될 때 초물검사(IPQC) 1건이 자동 생성되고(첫 시리얼 LOT 연결), 같은 런의 이후 타는 그 검사서에 **수량만 누적**됩니다.
  - 예: 하루 주간·야간 생산 시 검사서 주간 1장 + 야간 1장. 3일 생산이면 6장 — 초/중/종물 실무 단위와 일치.
  - 검사서의 생산일·교대 필드(회사양식)가 자동으로 채워집니다.
- 이미 **승인(결재 완료)된 검사서는 불변** — 이후 실적은 누적되지 않습니다.
- **일반 MO(조립 등)**: 완료 시 최종검사(FQC) 1건 자동 생성 — 기존과 동일.
- 처리: 검사 결과·항목 입력 후 결재선에 따라 승인.

### 3. SPC — PLC 실측이 자동으로 들어옵니다
- SPC 조사서의 **[PLC 실측 수집]** 버튼: 사출 실측중량(실측 확정분만)을 부분군(기본 5개)으로 자동 적재합니다.
- 여러 번 눌러도 중복 수집되지 않고(멱등), 부분군을 못 채운 잔여분은 다음 수집 때 이어집니다. 더미값(미실측)은 수집되지 않습니다.
- 담당자는 관리도 판독·이상 판정에 집중하면 됩니다.

### 4. 부적합(NC)과 품질경보
- IQC 불합격 시 부적합 자동 생성. 부적합은 Odoo 품질경보(quality.alert)와 양방향 연결.
- 처리: 부적합 문서에서 원인·시정조치 입력 → 결재.

### 5. 중량검사 NG 처리 (매일)
- 사출 현장 > 품질관리 > 중량 검사 불합격 목록에서 미처리 NG 확인·처리. (운영현황 앱의 일일 태스크와 연동)

### 6. 월 루틴
- 마감 전 체크리스트(회계 앱)의 품질 관련 지표 협조: 원본 없는 수정분·검사 미완료 등.
- IATF 증빙 관점: IQC/PQC/NC/SPC 기록이 곧 심사 증빙. 판정·결재를 미루지 말 것.

## B. 품질팀에 요청하는 테스트·결정 사항 (UAT)

시스템 로직은 검증 완료 상태입니다. 아래는 **실무 판단**이 필요한 항목입니다.
테스트 환경: cams_stg (운영 DB 사용 금지).

| # | 요청 | 상태 | 확인 방법 / 결정할 것 |
|---|---|---|---|
| 1 | IQC 양식 적합성 | 확인 요청 | 입고 1건 → 자동 IQC 열람. 샘플링(AQL·Ac/Re)·검사항목 필드가 실무 양식과 맞는가 |
| 2 | **특채(긴급 투입) 예외** | **결정 필요(우선)** | 현재는 합격 전 투입이 전 경로 차단됨. 긴급 생산 시 특채 절차(권한자 승인+이력)가 필요한가? |
| 3 | PQC 생성 단위 | ✅ 구현됨(생산 런 단위) — 적합성만 확인 | 품목×생산일×교대당 초물 1건+수량 누적이 초중종물 절차와 맞는지. **중물·종물 기록 추가 필요 여부** |
| 4 | 초중종물 검사 | 확인 요청 | 현행 절차와 초물 자동생성 시점·기록 위치 대조 |
| 5 | 불합격 체인 | 확인 요청 | IQC 불합격 1건 → 부적합 자동생성·격리 확인. 양식 용어·시정조치 단계가 사내 양식과 맞는가 |
| 6 | SPC 관리 기준 | ✅ 수집 자동화됨 — 기준 결정 | [PLC 실측 수집] 실행 후 관리도 검토. **부분군 크기(기본 5)와 관리한계(CL/UCL/LCL) 기준** 결정 |
| 7 | 검사기준 마스터 | 데이터 입력 | 검사항목 기준(criteria)에 실제 품목 1~2개 기준 입력 |
| 8 | 판정 권한 | 확인 요청 | 품질 외 계정으로 판정 시도 → 판정·해제 권한을 품질 그룹으로 제한할 필요 여부 |

### 회신 형식
각 번호에 "적합 / 수정 필요(내용) / 결정(선택)"으로 회신 → 수정 필요분은 개발 반영 후 재검증.
**2번(특채)이 최우선 결정 사항**입니다 — 검사 전 투입이 전면 차단된 현재 정책이 현장 운영과 충돌하는지 여부.
