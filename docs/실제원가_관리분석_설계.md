# 실제원가(관리분석) 설계 — 품목별 원가 · PLC 실측 우선 · 회계 분리

작성: 2026-07-03. 상태: **설계 확정(사용자 결정 반영), 구현 전.**
선행결정: [원가산출_현황과_capability원가연결.md](원가산출_현황과_capability원가연결.md) — 표준원가는 명목(불량0) 기준선 확정.

## 0. 결정 요약 (사용자 확정)
1. **목적·범위** = 관리분석용 **품목별 원가**. 회계 정본 아님(참고치).
2. **소스 우선순위** = **PLC 실측 우선**(measured_weight) → 오류·결측·이상치(표준 ±허용범위 초과) 시 **표준값 대체** + **출처/사유 필드 명시**.
3. **회계·정산 분리 유지** = stock.move 기반 그대로. **valuation 전환 없음 → 톤정산 충돌 회피.**
4. **PLC 커버리지(%)** = 집계에 필수 표시(신뢰도).
5. **PLC vs 표준 대사 리포트 = SQ 1_5(원단위 중량) 증빙 겸용.**

## 1. 두 원가의 분리 (핵심 원칙)
| | 표준원가 | 실제원가(관리) | 회계원가 |
|---|---|---|---|
| 근거 | BOM 명목(capability→공정) | PLC 실측 우선+표준 fallback | stock.move 실소비 |
| 용도 | 기준선 | **품목별 관리분석·수익성** | 재고자산·매출원가(정본) |
| valuation | — | **건드리지 않음** | manual_periodic(현행 유지) |
| 정산연계 | — | 없음 | 무발주 정산(톤/생산량) |

→ 관리원가는 **별도 분석층**(신규 모델/리포트)으로 산출. 재고·회계 분개는 일절 변경 없음.
> 라벨 필수: "관리 참고치 — 회계 정본 아님". 두 숫자 공존 혼동 방지.

## 2. 실제원가 산출 로직 (품목·기간별)
### 2.1 재료비 (원단위 중량 기반)
- **PLC 정상**: `measured_weight`(g) × 재료단가 → source=`plc`
- **판정 기준(표준 원단위)**: BOM 원재료 수량(예 INJ-SHELL-A=3.2kg=3200g) = SQ 1_5_0 원단위 마스터
- **이상치**: `|measured − 표준| / 표준 > ±15%(기본, 제품별 override)` → 표준 대체, reason=`이상치`
- **결측**: measured 없음/0 → 표준 대체, reason=`결측`
- **오류**: 음수·비정상 → 표준 대체, reason=`오류`

**재료단가 정책 (확정)**: 실제=계약단가/톤단가(정산 마스터), 표준=standard_price → **차이 = 가격차이**. 조건:
1. **단가 유효기간 매칭** — 계약단가의 유효일자로 매칭. **소급단가는 과거 마감 재개봉 없이** 당월 **"소급차이"로 별도 계상**(마감 무결성 보존).
2. **월 마감 레코드에 표준단가 스냅샷 저장** — 중간 개정이 과거 분석을 뒤틀지 않게.
3. **계약단가 없는 품목 = 표준 폴백** + **단가출처 필드**(PLC provenance 패턴 재사용: source/reason).
→ 이러면 가격차이·수량차이 분해가 **정산 마스터와 같은 기준으로 월 대사**됨.

### 2.2 가공비 (설비시간)
- 실제시간 = workorder duration(있으면) → 없으면 **실적수량 × 표준 cycle/cavity** 환산, source 표기
- × 워크센터 costs_hour

### 2.3 불량·수율
- MO `qty_good_worksite` / `qty_defects_worksite` → 수율 = 양품/(양품+불량)
- 불량품에 투입된 재료·시간 = 수율손실(실제원가에 포함, 표준엔 없음 → 수율차이)

### 2.4 PLC 커버리지
- `coverage% = PLC소스 수량 / 전체 수량` (재료·시간 각각 산출)
- 집계 화면·리포트에 **필수 표시**. 낮으면 관리원가 신뢰도↓ 경고.

## 3. 스키마 (확정) — grain=MO/LOT, 마감=월
**모듈 = 신규 `injection_costing`** (관심사 분리·독립 PR).
**원가 grain = MO/LOT까지.** 시리얼(14자리)은 **드릴다운용 원본 로그로만** — 시리얼 단위 원가 화면은 만들지 않음.

- `injection.mo.cost.actual` (**MO/LOT 단위 적재** — 정본 grain)
  - mo_id, product_id, lot_id, date_done
  - qty_good, qty_defect, yield
  - mat_qty_actual(실측/폴백 합), mat_cost_actual, mat_source(plc/standard), mat_reason(정상/이상치/결측/오류), mat_coverage_pct
  - time_actual, proc_cost_actual, time_source
  - unit_price_used, unit_price_source(계약/톤/표준폴백)
  - std_weight, std_unit_price_snapshot, std_mat_cost, std_proc_cost (표준 스냅샷)
  - var_material_price, var_material_qty, var_processing, var_yield
- `injection.cost.monthly.close` (**월 마감 집계** — 공식)
  - period(월), product_id, Σ 실제/표준/차이, coverage%, **표준단가 스냅샷 보존**
  - retro_diff(소급차이 — 과거 마감 재개봉 없이 당월 계상)
- **주간/기간 조회** = MO 데이터 위 **필터 뷰**(별도 롤업 인프라 불필요).
- **커버리지% = PLC소스 적용 수량 / 전체 수량** (재료·시간 각각).

## 4. 차이분석(표준 vs 실제)
- 재료 사용량차이 = (실측중량 − 표준원단위) × 표준단가 → **수율/원단위 관리 핵심**
- 재료 가격차이 = (실제단가 − 표준단가) × 실측중량
- 가공 능률차이 = (실제시간 − 표준시간) × 요율
- 수율차이 = 불량손실(재료+가공)
- 조회: 품목별 pivot + 기간추이. (회계 분개 아님)

## 5. SQ 1_5 증빙 겸용 (대사 리포트)
동일 대사 데이터가 SQ 자기평가 증빙으로 재사용:
| SQ 1_5 항목 | 대사 리포트가 제공하는 증빙 |
|---|---|
| 1_5_0 원단위 중량 마스터 최신화 | 실측중량 vs BOM 원단위 편차 → 마스터 갱신 필요 판정 |
| 1_5_1 월 신재투입 대비 생산 수율(%) | Σ신재투입(measured/stock) 대비 양품 → 수율 |
| 1_5_2 스크랩 발생/매각 비교검증 | 불량·스크랩 수량 집계 |
| 1_5_3 수율 이상여부 판정 | 허용범위 초과 건 = 이상 플래그 |
> sq_evaluation 은 **다른 세션(feat/sq-evaluation) 소관** → 대사 리포트는 원가 도메인에서 산출하고 SQ엔 **증빙 소스로 연계**(직접 수정 금지, 조율). SQ_증빙기반_자동채점_명세.md 와 정합.

## 7. 구현 순서 (제안)

## 9. 후속 개발 (2026-07-03 — 완료·검증)
1. **재료비 다품목 정밀화**: 수지(톤단가)뿐 아니라 **모든 구매품 실제단가=계약단가(vendor.part.price)** vs 표준단가 → 조립 MO도 가격차이 포착. 검증: FIN-BPR-A 외주단가 520→560 시 가격차이 96,000, 대사 정합 유지.
2. **뷰 다듬기**: pivot·graph·search(그룹: 기간/품목/출처/사유) — MO실제원가·월마감 양쪽.
3. **SQ 1_5 대사 리포트**(증빙 겸용, 원가도메인 산출): 월마감에 원단위 중량 대사 필드 추가 — 표준원단위·실측평균·**편차%**(1_5_0)·**신재대비수율%**(1_5_1)·불량(1_5_2)·**이상MO건수**(1_5_3). 전용 화면 `SQ 1_5 원단위 중량 대사`. sq_evaluation 직접수정 없음(다른 세션 소관 → evidence 연계만).
   - 검증: BRKT 편차27.6%(이상MO 1), SHELL 편차0.4%(정상), 커버 0/100%, 수율 88.9/94.3%.

**파킹 유지**: 재무 자동분개(2단계) = valuation 전환 + 무발주 정산충돌 해소 **설계 의사결정** 필요 → 개발 아닌 결정사항이라 미진행.

## 10. 소급(가단가→정단가) 원가 대응 (2026-07-04 — 완료·검증)
가단가/정단가 소급([[가단가_정단가_설계명세]] §8 검증기준)의 **원가 세션 몫**을 구현:
1. **단가매칭 결함 수정**: 실제단가를 `order id desc(최신)` → **생산일 유효단가**(vendor.part.price/material.ton.price 의 date_from/date_to 매칭)로 교정. frozen 정확도 확보.
2. **frozen/restated 이중** + **마감잠금(locked)**: frozen=생산일 단가 스냅샷(잠금 후 불변), restated=현재 단가이력 재계산, **`retro_diff` = restated − frozen**(=소급차이). `action_recompute_restated`·`action_lock`.
3. **§8-5 정합등식 자동검증**: 월마감 `recon_ok` = (restated−frozen == Σretro_diff).
4. **§8-6 폴백 가시성**: `unit_price_source`(ton/contract/**표준폴백**) 리스트 노출 — 미합의(폴백)단가 식별.

**검증(cams_sim3, §8-7 시나리오)**: 톤단가 1,300→1,400 소급 확정 시 frozen 불변(208,780), restated 224,840, 소급차이 16,060(=100×3.212kg×50 정확), 월마감 recon_ok 전건 True.

**정산 세션 의존(미충족분)**: §8-1~4·7의 소급전표(멱등 retro_bill_id·양방향 credit note·부분정산·취소후 재실행)와 매출 customer.part.price·가/정 상태·과거기간 소급행(overlap 제약 재설계)은 정산 세션 몫. 그 소급행/단가확정이 반영되면 본 restated가 자동으로 되살림(추가작업 없음).
