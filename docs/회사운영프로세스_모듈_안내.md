# 회사 운영 프로세스 (cams_ops_process) — 사용 안내

신규 앱 **「회사 운영」** · 브랜치 `feat/ops-process` (escon/odoo_gh) · 목적: 초보 운영자도 "언제 무엇을, 어떻게, 됐는지, 승인됐는지"를 한 화면에서.

## 개념 3개
```
역할(ops.role)        회계·정산·원가·생산관리·사출현장·품질·조립·구매·경영 + 담당자 배정
업무 정의(task.def)   무엇을/어느 역할이/어떤 주기(일·주·월·분기·년·수시)로/기한/승인 필요/매뉴얼
업무 건(task)         이번 기간의 그 업무 — 해야 함 → 완료 보고 → 승인 (지연 자동 표시)
```
cron이 매일 주기 확인 후 업무 건을 자동 생성(정의×기간 유일 = 중복 없음).

## 화면 (메뉴: 회사 운영)
| 메뉴 | 용도 |
|---|---|
| **오늘의 업무** | 칸반(상태별). 필터: 내 역할 업무 / ⚠지연 / 승인 대기 |
| 업무 현황(전체) | 리스트 — 지연 빨강, 승인 초록. 행에서 바로 [완료]/[승인] |
| **역할별 업무 매뉴얼** | 정의를 역할별 그룹으로 열람 — 초보자 따라하기 |
| 설정 > 업무 정의 | 주기·기한·승인·매뉴얼 등록/수정, [지금 생성](백필) |
| 설정 > 역할·담당자 | 역할에 사용자 배정 |

## 업무 수행 흐름 (담당자)
1. 오늘의 업무에서 내 건 열기 → **「업무 매뉴얼(따라하기)」 탭** 읽기
2. [업무 화면 열기]로 해당 Odoo 화면 이동(정의에 액션 설정 시) → 실제 업무 수행
3. 수행 메모 기록 → **[완료 보고]**
4. 승인 필요 업무는 승인자(승인 역할 사용자 또는 운영관리자)가 **[승인]** — 채터에 이력
- 지연: 기한 경과+미완료면 자동 빨간 표시. 잘못 완료 시 [재작업], 해당 없음은 [건너뜀].

## 시드된 업무 13종 (설치 즉시 가동)
- **일일**: 생산계획 계산·검토(생산관리) / 금일 사출 MO·실적(사출현장) / SILO·소요통보(사출현장) / 품질알람 처리(품질) / 이종검사 확인(조립)
- **월마감 체인**(docs/월마감_체크리스트 반영, 1~5일 순차 생성): ①부품 생산량 정산(정산→회계승인) ②수지 톤정산 ③실제원가 재집계·월마감 recon(원가→경영승인) ④SQ 1_5 대사(품질) ⑤가단가 노출(구매→경영승인) ⑥전표 전기(회계) + 경영 원가리포트 검토
- **주간**: 기준정보 정합 점검(생산관리)

## 초기 설정 (관리자, 5분)
1. 설정>사용자에서 관리자에게 **「운영 관리자」** 그룹 부여 (신규 설치는 admin 자동 / 기존 DB는 수동 1회)
2. 설정>역할·담당자 — 각 역할에 실제 사용자 배정
3. (선택) 업무 정의에 **바로가기 액션** 연결, 자사 업무 추가 등록
4. 첫날은 정의 목록에서 [지금 생성]으로 현재 기간 업무 백필

## 검증됨 (cams_stg2)
시드 로드 / 크론 생성·재실행 멱등 / 월 백필 멱등 / 완료→승인 / 승인불요 즉시승인 / 비권한 승인 차단 / 지연 검색.
