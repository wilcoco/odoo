# 서버 확인 요청 — 운영 서버 실제 구성

작성 2026-09-09 · 대상: 운영 서버 `10.10.21.20` 담당
소요: 명령 5개, 5분 내외 · **읽기만 합니다. 서버를 변경하지 않습니다.**

## 왜 필요한가

개발 쪽에서 서버에 접속할 수 없어(SSH 미보유), **서버가 실제로 무엇을 읽고 무엇이 설치돼 있는지**를
저장소 내용으로 추정하고 있습니다. 추정이 틀리면 배포 후에야 드러납니다.
아래 5개 결과를 보내주시면 로컬 개발 환경을 서버와 동일하게 맞출 수 있습니다.

각 명령의 출력을 그대로(잘라내지 말고) 보내주시면 됩니다.

---

## 1. Odoo 가 읽는 애드온 경로

```bash
grep -E "addons_path|db_name|dbfilter" ~/cams-odoo/odoo.conf
```

우리가 아는 것과 순서까지 같은지 확인합니다. **경로 순서가 다르면 같은 코드라도 다른 모듈이 뜹니다.**

## 2. 그 경로에 실제로 있는 폴더

```bash
ls -d ~/cams-odoo/odoo_gh/*/ 2>/dev/null
ls ~/cams-odoo/odoo_gh/iatf_plugins/ 2>/dev/null | head -80
```

저장소(`gamehon/odoo_gh`)와 서버 디스크가 같은지 확인합니다.
과거에 미러에만 있던 수정이 정본에 없던 사례가 있어, 반대 방향(서버에만 있는 것)도 확인이 필요합니다.

## 3. 미러가 어느 시점인지

```bash
git -C ~/cams-odoo/odoo_gh log --oneline -3
git -C ~/cams-odoo/odoo_gh status --porcelain | head -20
```

두 번째 명령의 출력이 **비어 있지 않으면**, 서버에서 직접 고친 파일이 있다는 뜻입니다.
그 경우 재동기화 시 그 수정이 사라지므로 반드시 알려주셔야 합니다.

## 4. 설치된 모듈 목록

```bash
docker compose -f ~/cams-odoo/docker-compose.yml exec -T db \
  psql -U odoo -d <운영DB> -tAc \
  "select name || ' ' || latest_version from ir_module_module where state='installed' order by name" \
  > ~/installed_modules.txt
wc -l ~/installed_modules.txt
```

이 파일을 보내주십시오. 로컬에 코드가 없는 모듈이 있으면 미리 잡을 수 있습니다.

> `<운영DB>` 는 아래 5번으로 확인하십시오.

## 5. DB 이름과 엔터프라이즈 구독 상태

```bash
docker compose -f ~/cams-odoo/docker-compose.yml exec -T db \
  psql -U odoo -d postgres -tAc \
  "select datname from pg_database where datistemplate=false and datname<>'postgres'"

docker compose -f ~/cams-odoo/docker-compose.yml exec -T db \
  psql -U odoo -d <운영DB> -tAc \
  "select key || ' = ' || value from ir_config_parameter
    where key in ('database.expiration_date','database.expiration_reason','database.enterprise_code')"
```

**두 가지를 확인하려는 것입니다.**

**① 운영 DB 이름** — 사내 문서마다 `odoo18`(UAT·사용자 매뉴얼 다수)과 `cams`(odoo.conf 주석)로
엇갈려 있습니다. 배포 스크립트가 틀린 DB에 업그레이드를 걸면 엉뚱한 DB 스키마가 바뀌므로,
지금은 스크립트가 임의로 고르지 않고 멈추게 해두었습니다. 확정되면 문서를 정리하겠습니다.

**② 엔터프라이즈 구독** — 개발용 로컬 DB가 체험판 만료 상태(`trial`, 2026-07-19 만료)로
엔터프라이즈 애드온을 쓰고 있습니다. 운영에 정식 구독이 있다면 같은 구독 코드를 개발 환경에도
넣어 정리하려 합니다. `enterprise_code` 값 자체는 보내지 않으셔도 되고,
**"있음/없음"과 `expiration_reason` 값만** 알려주셔도 충분합니다.
