# CAMS Odoo 운영 매뉴얼 — 사출·조립 자동차부품 공장

작성: 2026-07-06 · 대상: 현장·생산관리·구매/정산·원가·품질 담당 · 범위: 기준정보~생산~품질~재고~정산~원가~소급~품질경영 전 과정.

---

## 0. 이 회사의 운영 모델 (반드시 먼저 이해)
일반 ERP(발주→입고→재고→마감)와 **다릅니다.**
- **부품(외주)**: 발주-입고 정산이 아니라 **생산량 기준 정산** — 완제품을 조립할 때 소비된 외주부품 수량 × 계약단가로 월 매입 마감.
- **원재료(수지)**: **톤당 월정산**(예외) — SILO 적재량 기준.
- **자동 발주**: 강제 발주가 아니라 **소요예상 통보**(협력사에 "이만큼 필요할 것 같다" 알림).
- **2단계 MO**: 계획 MO → PLC 단위 MO(14자리 시리얼) — 사출기가 1개 완성할 때마다 실적.
- **가단가→정단가**: 자동차 관행상 양산 전 임시단가(가단가) 거래 → 양산 후 정단가 확정 → 과거분 소급.
- **원가 3층 분리**: 표준원가(BOM 기준선) / 실제원가(PLC 실측 관리분석) / 회계(표준+정산, 별도). ★ 관리원가는 회계 정본 아님.

## 2. 기준정보 구축 (최초 1회 + 변경 시)
운영 전 반드시 세팅. 순서대로.

### 2.1 제품·BOM
- `생산계획 > 마스터 데이터 > 사출 제품/부품` — 완제품(FIN)·사출품(INJ)·외주부품(OUT)·원재료(수지) 등록.
  - 외주부품: **is_outsourced=True** + 공급사 지정(정산 대상 식별).
  - 수지: 정산단가(material.ton.price) 등록 시 **settle_by_ton=True** 자동.
- BOM: 완제품 ← 사출품+외주부품, 사출품 ← 수지(kg). 도면기반 구성·수량·**원단위 중량**.

### 2.2 설비·금형·능력
- `생산계획 > 마스터 데이터 > 사출기(작업장)` / `금형 관리` / **`사출기-금형 조합`**(capability: cycle_time·cavity·불량률).
- `사출 현장 > 사출 설정 > 작업장 > 전체 작업장 관리` — **워크센터 시간당원가(costs_hour)** 입력(노무+설비+간접 요율). ★ 원가 산출의 가공비 기준.
- **표준 가공비 연결**: capability 등록/수정 시 브리지가 사출품 BOM에 '사출성형' 공정을 자동 upsert(표준 원가에 가공시간 반영).

### 2.3 SILO(원재료 저장)
- `사출 현장 > 사출 설정 > 작업장 > SILO 관리` — 사출기별 SILO, reorder_point(재발주점)·reorder_qty 설정.

### 2.4 단가 마스터
- **외주 계약단가(가/정)**: `가단가/정단가 > 계약단가(가/정)` — 품목+공급사+단가+유효기간+**상태(가단가/정단가)**.
- **수지 톤단가**: `사출 현장 > 사출 설정 > 작업장 > 원재료 계약 톤단가`.
- **고객 판매단가(가/정)**: `가단가/정단가 > 고객 판매단가(가/정)`.
- **표준원가**: 제품 마스터 standard_price → 사출품/완제품은 BOM '원가 계산'(button_bom_cost)으로 재료+가공 roll-up.

## 3. 일상 운영 흐름

### 3.1 생산계획
- `생산계획 > 사출기 생산 계획` — 수요를 사출기-금형 조합에 배정(시간당능력·금형교체 최소화·교대 타임라인 반영).
- `생산계획 > 원재료 소요/재고` — 계획 대비 원재료 소요·재고 확인.
- 산출물: **계획 MO**(사출기별 생산 지시).

### 3.2 사출 생산 (2단계 MO + PLC)
- `사출 현장 > 생산관리 > MO > 오늘의 제조 주문서` — 금일 사출 MO.
- 실물 흐름: 계획 MO → PLC가 1개 완성할 때마다 **`/api/plc/complete`** 호출 →
  - **단위 MO(14자리 시리얼)** 완료, `사출품 생산 기록`(injection.production.record) 생성.
  - **실측중량**(PLC payload weight) 기록 + `weight_is_measured` 마커. 중량 검사(quality.check) 자동 발행.
  - OK/NG(final_result) → 양품/불량 판정. NG는 `중량 검사 불합격`(quality.alert) 생성.
  - 수지 SILO 자동 소비(consume_fifo, FIFO 로트).
- 조회: `기록 > 사출품 생산 기록` / `사출품 시리얼 추적` / `원재료 LOT 추적`.
- 품질: `품질관리 > 중량 검사` / `초중종물 검사`.

### 3.3 조립·출하
- 조립 MO(완제품) 완료 시 사출품+외주부품 소비 → **외주부품 생산량 정산(accrual)** 자동 발생(vendor.mrp.accrual).
- (gh_total_mes 설치 시 조립/출하/거래명세 통합.)

### 3.4 재고·SILO — 재고떨기 & 부족→통보
- 생산이 원재료·부품 재고를 **소비(재고떨기)**.
- SILO 잔량이 reorder_point 미만 → `사출 현장 > 사출 설정 > 작업장 > 소요예상 통보`(material.requirement.notice) 자동/수동 생성 → **협력사 통보**(강제발주 아님).
- 조회: `소요예상 통보` 목록(품목·공급사·상태 sent).

### 3.5 협력사 (외주 발주·입고·포털)
- `Purchase > 외주 관리 > 협력사 간 발주` / `협력사 응답` / `협력사 재고`.
- 협력사 포털(supplier_portal_purchase): 토큰 기반 외부 접근(협력사가 소요통보 확인·응답). DMZ 리버스프록시로 노출.
- 입고: 외주부품 재고 반영, 수지 SILO 재적재(`원재료 가상 입고` / action_load_lots).

## 4. 월 마감 (정산) — 이 회사의 핵심
### 4.1 부품 = 생산량 기준 매입 마감
- `사출 현장`(정산 위저드) 또는 vendor.mrp.settlement.wizard — 기간 지정 → **미정산 accrual 집계** → 공급사별 **매입계산서(in_invoice) 초안** 생성.
- 단가 = 계약단가(가/정 유효단가) → 없으면 표준 폴백. accrual state → billed.
- ★ 발주-입고가 아니라 **"완제품에 들어간 외주부품 수량 × 계약단가"** 로 마감.

### 4.2 원재료(수지) = 톤당 월정산
- `사출 현장 > 사출 설정 > 작업장 > 원재료 톤당 월정산`(raw.material.settlement) —
  - `원가 계산`(action_compute): SILO 적재로그(injection.silo.load.log)를 적재일 기준 집계.
  - `확정`(action_confirm) → `매입계산서 생성`(action_create_bills). (재실행·동시성 방어 내장)

## 5. 원가 관리 (표준 vs 실제 vs 차이) — `실제원가(관리)`
### 5.1 표준원가 (기준선)
- BOM(도면기반 구성·원단위) × 표준단가 + capability 표준시간 × 워크센터 요율 = **표준원가**. 불량0 명목 기준.

### 5.2 실제원가 (관리분석) — `실제원가(관리) > MO 실제원가`
- MO/LOT 단위. **PLC 실측중량 우선**(weight_is_measured=True만 실측 인정) → 이상치(표준 ±허용범위)·결측·오류 시 **표준 대체 + 출처/사유**.
- 재료 실제단가 = 계약/톤단가(생산일 유효단가). 가공 실제시간 = 작업지시 실측(없으면 표준 폴백, 설정).
- 화면: 표준원가 / 실제원가 / **가격·수량·능률·수율 차이** / **PLC 커버리지%**. Pivot·Graph로 품목×기간 비교.
- **대사 정합**: (실제−표준) = 가격+수량+능률(잔차 0). 수율차이=불량손실 별도.
- **재집계**: `실제원가 재집계`(멱등). 마감: `실제원가 월마감`(품목×월, 커버리지·차이 집계).

### 5.3 SQ 1_5 원단위 대사 — `실제원가(관리) > SQ 1_5 원단위 중량 대사`
- 표준 원단위(BOM) vs PLC 실측평균 → **편차%·신재대비수율·이상MO** → IATF/SQ 1_5 증빙 겸용.

### 5.4 원가 정책 설정 — `설정 > 사출 원가정책`
- 가공시간 소스(작업지시 우선/항상표준/실측만), 재료수량 소스(수지PLC·나머지표준 / 전표준 / 실제소비), 원단위 허용범위 기본값(±15%).

## 6. 가단가→정단가 소급 — `가단가/정단가`
### 6.1 상태·확정
- `계약단가(가/정)`(매입) / `고객 판매단가(가/정)`(매출) — 상태 **가단가/정단가** + 근거·확정일.
- **정단가 확정** 버튼(위저드): 가단가 행 보관(archive)+정단가 행 삽입(§7-1)+감사추적.

### 6.2 소급(마감 내장, 별도계산 아님)
- **매입 소급**: (정단가−가단가)×기청구수량 → **추가청구(in_invoice)/감액(in_refund) 초안**. 멱등(retro_bill_id)·양방향·부분정산 경계. 전기는 승인.
- **매출 소급**: 발행 매출계산서 delta → 수정전표 초안(마진 restated=원가불변·판가소급).
- **B안 표준 갱신**: 정단가 확정 시 부품 standard_price=정단가 + 완제품 표준원가 재계산(향후 기준선; 과거 마감 불변). ※ 표준=재고평가 기준이라 회계 표준 재설정에 해당.
- **원가 restated**: frozen(마감본) 불변 + restated(현재 단가이력 재계산), 소급차이=restated−frozen. 월마감 정합등식 자동검증.

### 6.3 노출 리스크 — `가단가 노출(매입)`
- 가단가로 청구된 누계액(정단가 확정 시 소급 대상 규모).

## 7. 품질경영 — `IATF 16949` / `심사평가(SQ·IATF)`
- **검사**: 수입검사 / 공정·출하검사 / 레이아웃 검사 / 초중종물·중량 검사(사출 현장).
- **부적합·시정**: `부적합/8D` → `시정 조치`, `고객 불만`, `협력업체 품질 > SCAR`.
- **문서·계획**: 관리계획서, FMEA, 컨트롤플랜, APQP/PPAP, MSA/SPC.
- **설비·금형**: 설비 대장/TPM/고장이력, 금형 대장/보전이력.
- **추적성**: 추적성 기록 / 리콜 시뮬레이션(시리얼 기반).
- **심사평가(SQ·IATF)**: `평가서` 자체평가 + `증빙 조회`(시스템 운영데이터로 자동 증빙) + `영역별 대시보드`. ★ SQ/IATF = 우리가 기준에 맞음을 **증빙**하는 시스템.

## 8. 회계 경계 (담당자·감사용)
- **관리원가(실제원가) = 참고치, 회계 정본 아님.** valuation=standard/manual_periodic 유지 → 재무제표·재고자산·매출원가 **미변경**.
- 회계에 이미 반영: **매입=정산 매입계산서**(실제 지급), **노무·경비=급여/경비 전표**.
- 표준-실제 차이가 **중요(material)하면** 회계 재고를 실제로 맞추는 원가차이 배분(재무 자동분개 2단계)이 **회계 판단**으로 필요 — 별도 결정(파킹).

## 부록 A. 운영 사이클 요약(1장)
```
[기준정보] 제품·BOM·설비·capability·SILO·단가(가단가)·표준원가
        │
[일] 생산계획 → 사출 MO(PLC 실측·양품/불량) → 재고떨기(수지 SILO)
        │                                         └ 조립 → 외주 생산량 정산(accrual)
        │  재고 부족 → 소요예상 통보 → 협력사 응답 → 입고(외주/수지 재적재)
        │
[월] 마감: 부품=생산량 매입계산서 / 수지=톤당 월정산
        │
[분석] 실제원가(관리): 표준 vs 실제 4분해·커버리지·SQ 1_5
        │
[사건] 양산→정단가 확정: 소급전표(매입/매출) + B 표준갱신 + restated(마감불변)
        │
[품질] IATF/SQ: 검사·부적합·시정·추적성·자체평가 증빙
```
