## PART A. 기준정보 구축 (운영 전 세팅)

### A-1. 제품·부품 등록
🖥️ `생산계획 > 마스터 데이터 > 사출 제품/부품`
✍️ 품목코드(default_code)·품명·유형(제조/소비)·단위(수지=kg, 부품=개)
- **완제품(FIN)**: 유형=제조. **사출품(INJ)**: 제조. **외주부품(OUT)**: 소비 + `is_outsourced`=True + `공급사`. **수지(RM)**: 소비, kg.
⚠️ 외주부품에 **is_outsourced 누락 시 생산량 정산(accrual)에서 빠집니다** — 반드시 체크.
📊 예: FIN-BPR-A(프론트범퍼ASSY), INJ-SHELL-A(범퍼쉘), OUT-FST-C(체결구), RM-PP-RESIN(수지).

### A-2. BOM (자재명세)
🖥️ 제품 폼 > BOM
✍️ 완제품 BOM = 사출품×수량 + 외주부품×수량. 사출품 BOM = 수지×**원단위 중량(kg)**.
📊 예: FIN-BPR-A ← INJ-SHELL-A×1 + OUT-FST-C×4 + OUT-CLP-D×6 / INJ-SHELL-A ← RM-PP-RESIN×3.2kg.
⚠️ 사출품 BOM의 수지 kg = **원단위 중량** — 이 값이 실제원가 "수량차이"와 SQ 1_5 대사의 기준.

### A-3. 설비·금형·능력(capability)
🖥️ `생산계획 > 마스터 데이터 > 사출기 / 금형 관리 / 사출기-금형 조합`
✍️ capability: 사출기+금형+`cycle_time(초)`+`cavity`+`불량률(%)`+`초기불량`.
▶️ capability 저장 시 브리지가 사출품 BOM에 **'사출성형' 공정** 자동 생성(표준 가공비 연결).
📊 예: MOLD-A@사출기-2500T cycle 55초 cavity 1 → 시간당 65개.

### A-4. 워크센터 시간당원가 (가공비 기준)
🖥️ `사출 현장 > 사출 설정 > 작업장 > 전체 작업장 관리`
✍️ `costs_hour` = 노무+설비+간접 배부 합산 요율.
📊 예: 사출기-2500T 80,000/h, 1300T 60,000/h, 조립라인 35,000/h.
⚠️ 미입력(0) 시 가공비=0 → 표준원가에 재료비만 잡힙니다.

### A-5. SILO(원재료 저장고)
🖥️ `사출 현장 > 사출 설정 > 작업장 > SILO 관리`
✍️ 사출기 연결·`reorder_point`(재발주점 kg)·`reorder_qty`·`reorder_partner_id`(공급사).
⚠️ reorder_point가 소요통보의 트리거 — 실제 소진 속도에 맞춰 설정.

### A-6. 단가 마스터
- **외주 계약단가(가단가)** 🖥️ `가단가/정단가 > 계약단가(가/정)` — ✍️ 품목+공급사+단가+유효시작+상태=**가단가**.
- **수지 톤단가** 🖥️ `사출 현장 > 사출 설정 > 작업장 > 원재료 계약 톤단가` — ✍️ 품목+공급사+톤당단가+유효기간.
- **고객 판매단가** 🖥️ `가단가/정단가 > 고객 판매단가(가/정)`.
📊 예: 체결구 500(가단가), 수지 1,200,000/톤(=1,200/kg).

### A-7. 표준원가 계산
🖥️ 제품 폼(사출품·완제품) ▶️ `원가 계산`(button_bom_cost) — 재료비(BOM×표준단가)+가공비(공정×costs_hour) roll-up.
⚠️ 순서 = 하위부터: 수지→사출품→완제품. 부품 표준단가 먼저 입력 후 계산.
📊 예: INJ-SHELL-A 5,062 / FIN-BPR-A 9,972.

## PART B. 일상 운영

### B-1. 생산계획 수립
🖥️ `생산계획 > 사출기 생산 계획`
- 수요를 사출기-금형 조합에 배정(시간당능력 최대·금형교체 최소·교대 타임라인).
🖥️ `생산계획 > 원재료 소요/재고` — 계획 대비 수지·부품 소요 확인.
📤 **계획 MO**(사출기별). 👤 생산관리.
⚠️ 배정은 현재 "시간당능력 최고 1대"에 몰아줌 — 부하분산·형체력·불량률 반영은 개선 백로그(사출계획_배정최적화_검토 참조).

### B-2. 사출 생산 (2단계 MO + PLC 실측)
🖥️ `사출 현장 > 생산관리 > MO > 오늘의 제조 주문서`
**흐름**: 계획 MO → 사출기가 1개 완성마다 PLC가 **`POST /api/plc/complete`**(bearer 인증) 호출:
✍️ PLC payload: `serial_number`(14자리)·`work_order_no`·`machine_no`·`final_result`(OK/NG)·**`weight`(실측중량 g)**.
▶️ 시스템 자동:
1. 단위 MO(시리얼) 완료 처리, `사출품 생산 기록`(injection.production.record) 생성.
2. **실측중량 기록** + `weight_is_measured`=True(payload weight 있을 때). 없으면 더미 3500 + False.
3. 중량 검사(quality.check) 자동 발행. `final_result` OK→pass/NG→fail → 양품/불량.
4. NG → `중량 검사 불합격`(quality.alert) + 8D 연계 가능.
5. 수지 SILO **자동 소비**(FIFO 로트).
🖥️ 조회: `기록 > 사출품 생산 기록 / 사출품 시리얼 추적 / 원재료 LOT 추적`.
👤 현장(PLC 자동) / 반장(불량 확인).
⚠️ **weight 미전송 시 실측중량이 더미(3500)** → 실제원가 재료 정밀도 안 나옴(커버리지 0으로 표시). PLC 송신부 확인.
📊 예: SHELL MO 100개 중 양품 100·불량 3, 실측중량 평균 ~3,200g.

### B-3. 조립·출하
- 조립 MO 완료 → 사출품+외주부품 소비 → **외주부품 생산량 정산(accrual)** 자동 발생.
📊 예: FIN-A 200개 → 체결구 800개·클립 1,200개 소비 → accrual(체결 500×800, 클립 175×1,200).
⚠️ 이 accrual이 월마감 매입계산서의 원천. 조립 완료 = 매입 확정 시점.

### B-4. 재고 부족 → 소요예상 통보
🖥️ `사출 현장 > 사출 설정 > 작업장 > 소요예상 통보`
- SILO 잔량 < reorder_point → 통보 자동/수동 생성(품목·공급사·상태 sent).
▶️ SILO 폼 `action_create_requirement_notice`(수동 트리거 가능).
📤 material.requirement.notice(협력사 통보). ⚠️ 강제 발주 아님 — "이만큼 필요 예상" 알림.
📊 예: 수지 515kg(재발주점 미만) → ㈜한국수지 통보(sent).

### B-5. 협력사 (발주·응답·입고)
🖥️ `Purchase > 외주 관리 > 협력사 간 발주 / 협력사 응답 / 협력사 재고`
- 협력사 포털(토큰): 협력사가 소요통보 확인·응답·납기 회신.
- **입고**: 외주부품 재고 반영 / 수지 SILO 재적재(`원재료 가상 입고` 또는 action_load_lots).
👤 구매/협력사.

## PART C. 월 마감 (정산)

### C-1. 부품 = 생산량 기준 매입 마감
🖥️ 정산 위저드(vendor.mrp.settlement.wizard)
✍️ `시작일`·`종료일`(예 2026-07-01~07-31)·`회사`·(선택)`공급사`.
▶️ `매입계산서 생성`(action_create_bills): 기간 내 미정산(draft) accrual → **공급사별 매입계산서(in_invoice) 초안** + accrual→billed.
- 단가 = 계약단가(가/정 유효) → 없으면 표준 폴백.
📤 매입계산서 초안(검토 후 전기). 👤 정산 담당 → 회계 승인.
📊 예: ㈜대한체결 575,000(체결 1,000×500 +VAT), ㈜미래클립 241,500(클립 1,200×175 +VAT).
⚠️ **전기는 회계 승인 후.** 재실행해도 billed는 재집계 안 됨(중복 방지).

### C-2. 원재료(수지) = 톤당 월정산
🖥️ `사출 현장 > 사출 설정 > 작업장 > 원재료 톤당 월정산`(raw.material.settlement)
✍️ 기간·수지·공급사.
▶️ ① `원가 계산`(action_compute): SILO 적재로그(injection.silo.load.log)를 적재일 기준 집계.
▶️ ② `확정`(action_confirm) → ③ `매입계산서 생성`(action_create_bills).
⚠️ 재실행/동시성 방어 내장(bills_created 플래그) — 동시에 눌러도 1장.

## PART D. 원가 관리 (표준 vs 실제)

### D-1. MO 실제원가 화면 읽는 법
🖥️ `실제원가(관리) > MO 실제원가`
▶️ `실제원가 재집계`(action_rebuild_all) — 완료 MO 원가 산출(멱등).
**컬럼 의미**:
| 컬럼 | 의미 |
|---|---|
| 표준원가(total_std) | BOM 기준선(불량0) |
| 실제원가(total_actual) | 실측/실단가 기반(frozen) |
| PLC커버리지% | 실측중량으로 잡힌 비율(100=완전 실측, 0=표준 대체) |
| 재료 가격차이 | (실제단가−표준단가)×수량 |
| 재료 수량차이 | (실측 원단위−표준 원단위)×표준단가 |
| 가공 능률차이 | (실제시간−표준시간)×요율 |
| 수율차이 | 불량손실(별도) |
| restated/소급차이 | 현재 단가이력 재계산본 / restated−frozen |
- **Pivot 뷰**(우상단): 행=품목, 열=기간, 값=표준/실제/차이 → 비교분석.
📊 예(실측 반영): INJ-SHELL-A 100개 표준 506,222 → 실제 461,670(-8.8%), 커버 100%, 능률 -44,552(작업 빠름=유리), 수율 15,187(불량 3).

### D-2. 차이 해석(경영)
- 음수(-)=유리(원가 절감), 양수(+)=불리. 드라이버별 조치:
  - 가격차이 → 구매/계약. 수량차이 → 원단위·성형. 능률차이 → 설비효율. 수율차이 → 품질.
- **대사 정합**: (실제−표준)=가격+수량+능률(잔차 0)이어야 정상. 안 맞으면 데이터 점검.
- 커버리지 낮은 품목 = 실측 부족 → **의사결정 전 데이터 확인 필수**.

### D-3. 원가 월마감 / SQ 1_5
🖥️ `실제원가(관리) > 실제원가 월마감` ▶️ 재집계 — 품목×월 표준/실제/차이/커버리지/**recon_ok**(정합등식).
🖥️ `실제원가(관리) > SQ 1_5 원단위 중량 대사` — 표준 원단위 vs 실측평균 편차%·신재대비수율·이상MO → IATF/SQ 증빙.

### D-4. 원가 정책 설정
🖥️ `설정 > 사출 원가정책`
✍️ **가공시간 소스**(작업지시 실측 우선[권장]/항상표준/실측만) · **재료 수량 소스**(수지PLC·나머지표준[권장]/전표준/실제소비) · **원단위 허용범위**(±15%).
⚠️ 작업지시 실측이 실운영에 안 들어오면 '항상표준' 또는 폴백(권장)으로 — 능률차이 왜곡 방지.

## PART E. 가단가 → 정단가 소급

### E-1. 정단가 확정
🖥️ `가단가/정단가 > 계약단가(가/정)`(매입) 또는 `고객 판매단가(가/정)`(매출) > 대상 행 열기
▶️ `정단가 확정` 버튼 → 위저드:
✍️ `정단가`(신규 단가)·`합의 근거`(합의서번호)·`표준원가도 갱신(B안)`(체크, 기본 on).
▶️ 확정 시:
1. 가단가 행 보관(archive) + 정단가 행 삽입 + 감사추적 링크.
2. **소급전표 초안** 자동 생성(아래).
3. (B안 체크 시) 부품 표준단가=정단가 + 완제품 표준원가 재계산.
👤 구매/영업 확정 → 회계 승인/전기.
📊 예: 체결구 가단가 500→정단가 560 확정.

### E-2. 소급전표 (마감 내장)
- **매입**: (정단가−가단가)×기청구수량 → 인상=추가청구(in_invoice)/인하=감액(in_refund) **초안**.
- **매출**: 발행 매출계산서 delta → 수정전표 초안(마진 restated=원가불변·판가소급).
⚠️ **초안만 자동, 전기는 승인.** 세무 수정계산서는 사유코드·기한 준수.
📊 예: 체결 500→560 → 소급 60,000(60×1,000). B안: FIN-A 표준 9,972→10,132. restated 소급차이 48,000, frozen 불변.

### E-3. 소급 취소·재실행 / 노출
- 소급전표 반려(button_cancel) 또는 삭제 → 낙인 해제 → 재실행 시 재발행(유실 방지).
- ⚠️ 청구 노출 있는 가단가 행은 직접 삭제 불가(정단가 확정 경유).
🖥️ `가단가/정단가 > 가단가 노출(매입)` — 가단가 청구 누계(정단가 확정 시 뒤집힐 규모).

## PART F. 품질경영 (IATF 16949 / 심사평가)
- **검사** 🖥️ IATF 16949 > 수입검사 / 공정·출하검사 / 레이아웃 검사 + 사출 현장 > 초중종물·중량 검사.
- **부적합·시정** 🖥️ 부적합/8D → 시정 조치 / 고객 불만 / 협력업체 품질 > SCAR.
- **계획·문서** 관리계획서·FMEA·컨트롤플랜·APQP/PPAP·MSA/SPC.
- **설비·금형·추적성** 설비 대장/TPM, 금형 대장/보전, 추적성 기록/리콜 시뮬레이션.
- **심사평가(SQ·IATF)** 🖥️ 평가서(자체평가) + 증빙 조회(운영데이터 자동 증빙) + 영역별 대시보드.
  ★ SQ/IATF = **우리가 기준에 맞음을 증빙**하는 시스템(협력사 평가가 목적 아님).
