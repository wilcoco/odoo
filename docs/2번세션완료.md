- 근태: hr_attendance 연동 월 집계(잔업/특근/특잔/심야/지각 자동분류, 주52h 경고)
  → 급여 입력 **자동 주입**(자동/수동 플래그로 갱신·보존 구분 — 결함 수정 완료 4326a6a)

- **수치는 전부 데이터**(요율마스터·세액표·파라미터) — 골격값에 "확정 필요" 표기

### ERP 생산계획 연동 (erp_plan_sync, 신규)
- 오라클 T_ZM_PLN2(기준일+D00~D12) → 스테이징(멱등) → 품번 매칭 → production.demand
- 실데이터 검증: 기준일 20260721, 1,796행 수신·재수신 멱등·수요 생성
- 프리픽스 필터로 양산품 노이즈 차단 → 보완 큐 = **신차종(BS계열) 미등록 품번 285종**
  (= 확정 BOM/품목 적재 우선순위 리스트)
- 자격증명은 시스템 파라미터(cams DB)에만 — 코드/git 없음. 일일 cron 기본 비활성

### 회계 보강
- 결재선 템플릿(모델/부서/금액 매칭 자동구성), 매출 세금계산서 승인번호 백필 매칭
- 통합 E2E 18/18: 품의→결재→청구→전기차단→전기, 근태→급여→**급여전표→원장→K-손익**
