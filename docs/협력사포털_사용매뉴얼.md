# 협력사 포털 사용 매뉴얼 (협력사 배포용)

이 매뉴얼은 ㈜에스콘 협력사 담당자분들을 위한 안내입니다. 포털에서 **발주 확인·회신, 납품 진행 보고, 이슈 제기**를 하실 수 있습니다.

---

## 1. 접속하기

1. 담당자로부터 받으신 **전용 링크**로 접속합니다:
   `https://portal.goescon.com/supplier/portal?token=회사별고유토큰`
2. 링크의 **토큰이 곧 로그인**입니다 — 별도 아이디/비밀번호가 없습니다.
   - ⚠️ 링크를 **외부에 공유하지 마세요** (링크 소지자는 귀사 발주 정보를 볼 수 있습니다)
   - 링크 분실·유출 시 즉시 당사 구매 담당자에게 연락 → 새 토큰 재발급
3. 접속하면 **대시보드**가 열립니다: 새 알림, 응답 대기 발주, 진행 중 납품 요약이 보입니다.

> 💡 즐겨찾기에 등록해두시면 편리합니다. PC·모바일 브라우저 모두 지원.

## 3. 가장 중요한 업무 — 발주 회신 (반드시 해주세요)

당사 발주는 회신을 받아야 확정됩니다. **새 발주 알림을 받으면 영업일 기준 1일 내 회신**을 부탁드립니다.

1. **발주 목록** → 해당 발주 클릭 (품목·수량·희망 납기 확인)
2. 하단 **[회신하기]**:
   - **전체 수락** — 수량·납기 그대로 가능할 때
   - **조건부 회신** — 일부 수량만 가능하거나 납기 조정이 필요할 때: 품목 줄마다 **가능 수량 / 가능 납기**를 입력
   - **메모**란에 사유·특이사항 기재 (예: "원자재 수급으로 3일 지연")
3. [제출] → 당사 구매 담당자가 검토 후 확정합니다.

> ⚠️ 회신 없이 방치된 발주는 당사 화면에 "미응답"으로 표시되어 독촉 연락이 갑니다. 수락이 어려워도 **조건부/불가 회신을 먼저** 주시는 것이 서로에게 좋습니다.

---

## 4. 납품 진행 보고 (진행 관리)

납품 건마다 단계 버튼으로 진행 상태를 알려주세요 — 당사 생산계획이 이 정보로 움직입니다.

```
[수주 확인] → 생산/출고 준비 착수 시
[출하]     → 물품이 귀사에서 출발할 때 (차량 출발 시점)
[완료]     → 당사 입고 확인 후 자동/수동 처리
```

**문제가 생기면 → [이슈 제기]**: 지연·수량 부족·품질 우려 등을 선택하고 내용을 적어 제출하면 당사 담당자에게 즉시 전달됩니다. **전화보다 먼저 이슈 제기를 남겨주시면** 기록이 남아 처리가 빠릅니다.

---

## 5. 소요 예상 알림에 대하여

당사 시스템은 원자재·부품 재고가 기준선 아래로 내려가면 **"소요 예상 통보"** 를 자동 발송합니다.
- 이것은 **확정 발주가 아니라 예고**입니다 — "곧 이만큼 필요할 것 같으니 준비해 주세요"라는 의미
- 준비 가능 여부·리드타임 특이사항이 있으면 미리 담당자에게 알려주시면 됩니다
- 실제 구매는 이후 **정식 발주(PO)** 로 발행되며, 그때 3번 절차로 회신해주세요

---

## 6. 대금 정산 안내 (참고)

당사는 부품 대금을 **발주-입고 단위가 아니라 "당사 생산에 실제 사용된 수량 × 계약단가"로 월 단위 정산**합니다.
- 월 마감 후 정산 내역(매입계산서)이 발행됩니다
- 계약단가가 변경(임시단가→확정단가)되면 **과거분 차액이 소급 정산**되어 별도 전표로 안내됩니다
- 정산 금액 문의는 당사 정산 담당자에게 연락 주세요

## 7. 자주 묻는 질문

**Q. 링크가 안 열려요 / "접근 권한 없음"이 떠요**
→ 토큰이 만료·변경됐을 수 있습니다. 구매 담당자에게 재발급을 요청하세요.

**Q. 발주 수량 일부만 공급 가능합니다**
→ [회신하기]에서 조건부 회신으로 품목별 가능 수량·납기를 적어 제출하세요. 임의로 부분 납품하지 마시고 반드시 먼저 회신해주세요.

**Q. 회신을 잘못 제출했어요**
→ 구매 담당자에게 연락 주시면 재회신 처리해 드립니다.

**Q. 납기를 이미 회신했는데 지연이 예상됩니다**
→ 진행 관리에서 **[이슈 제기]** 로 지연 사유·새 예정일을 등록해주세요.

**Q. 모바일에서도 되나요?**
→ 네, 브라우저로 동일하게 사용 가능합니다.
