## 먼저 — 검토의 성격

Codex 는 브리프의 SQ 범위를 넘어 **전체 ERP 운영준비도**(H01~H14)를 봤다. 실행한 것은
AST/XML 파싱, 병합 메뉴 보존 비교, **순수 함수 격리 재현**(Odoo ORM·DB 없이)이고,

그래서 판정은 "정적 추론으로는 맞다" 와 "실제로 뚫린다" 를 구분해서 했다.

**총평: 정확하다.** 제 영역 지적 8건 중 7건이 코드로 확인됐고, 오탐은 0건이다.

  그대로 n 개 전부로 계산되어 **값이 바뀌지 않는다.** 자동 주입분만 이후부터 달라진다.
- `iatf_work_environment` 1.3.1 / `iatf_mold` 1.2.1: **완료된 실적을 더 이상 고칠 수 없다.**
