## 4. 남은 추가개발 목록 (우선순위)
1. **원재료 톤당 정산 → 매입계산서 생성** — 현재 raw.material.settlement은 집계·확정까지만. 부품정산처럼 매입계산서(account.move)까지 연결해야 회계마감 완결. ★
2. **납품실패 알림 → 대체발주/긴급통보 액션** — 감지·경고는 완료. 후속 대처(대체 공급사 자동제안 등) 추가 여지.
3. **IATF 시정조치 자동연결 UX** — 부적합에서 '시정조치 생성' 버튼 기본값 채움(필수필드 많음).
4. **계약단가 마스터 운영** — vendor.part.price·material.ton.price 미설정 시 standard_price 폴백. 운영 전 입력 필수.
5. **사출 스케줄링 capability 마스터** — 실품번 적용 시 금형/사출기/능력 구축 필요(SIM은 구축 완료).

## 5. 결론
- **전 운영 사슬(생산계획→사출스케줄링→조립→불량/IATF→소요예상통보→납품(정상/실패)→생산량기준 마감→매입계산서) 작동 확인.**
- 이번에 **납품실패 감지·경고**를 신규 개발(핵심 gap 해소), **사출 스케줄링**을 SIM 품번까지 확장 검증.
- 회계마감은 **부품정산→매입계산서**까지 연결됨. **원재료 톤당 정산의 매입계산서 연결**이 남은 회계 완결 과제.
