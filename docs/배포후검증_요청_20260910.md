# 배포 후 검증 요청 — SQ 대응 8개 모듈

작성 2026-09-10 · 대상: 운영 서버 담당
**읽기 전용 SQL 5개. 서버를 변경하지 않습니다. 2분 내외.**

## 배경

9/9 회신의 `installed_modules_odoo18_20260909.txt` 에서 SQ 대응 8개 모듈이
**이미 목표 버전으로 설치돼 있음**을 확인했습니다. 별도 배포는 필요 없습니다.
(1판·2판 작업서와 배포 스크립트는 폐기했습니다. 경로·컨테이너명도 틀려 있었습니다.)

남은 것은 **업그레이드 때 마이그레이션이 제 일을 했는지** 확인입니다.
버전 번호가 올라간 것과 데이터가 제대로 옮겨진 것은 별개이고, 안 옮겨졌을 때의 증상은
배포 직후가 아니라 **담당자가 예비부품을 새로 등록하려는 순간**에야 나옵니다.

## 실행

```bash
docker exec postgresdb psql -U odoo -d odoo18 <<'SQL'
-- ① 잔재 컬럼 (둘 다 0 이어야 함)
select '① equipment_id 잔재' as chk, count(*) from information_schema.columns
 where table_name='iatf_equipment_spare' and column_name='equipment_id'
union all
select '① mtbf/availability 잔재', count(*) from information_schema.columns
 where table_name='iatf_equipment' and column_name in ('mtbf','availability_rate');

-- ② 예비부품 ↔ 적용표 (적용표 건수가 예비부품 중 설비연결 있던 건수와 같아야 함)
select '② 예비부품' as chk, count(*) from iatf_equipment_spare
union all
select '② 적용표(이관)', count(*) from iatf_spare_application;

-- ③ 점검 시트 개정차수 (0 이어야 함 — 미설정 시트 없음)
select '③ 개정차수 미설정 시트' as chk, count(*) from iatf_check_sheet where coalesce(revision,0)=0;

-- ④ 데모 데이터 없음 (전부 0 이어야 정상 — 가동 전이라 실적이 없는 게 맞음)
select '④ 분류' as chk, count(*) from iatf_spare_category
union all select '④ 금형점검', count(*) from iatf_mold_check
union all select '④ 점검실적', count(*) from iatf_check_record
union all select '④ 위험성평가', count(*) from iatf_safety_assessment;

-- ⑤ 신규 등록 가능한가 — 실제로 하나 넣어보고 롤백 (데이터 안 남김)
begin;
insert into iatf_equipment_spare (name, quantity_required, create_uid, create_date, write_uid, write_date)
values ('__verify_probe__', 1, 1, now(), 1, now());
select '⑤ 신규등록 probe' as chk, 'OK' as result;
rollback;
SQL
```

출력을 그대로 보내주시면 판독하겠습니다.

## 함께 여쭙는 것

- 회신에서 지적하신 **`supplier_portal_purchase` 디스크 1.3.1 / DB 1.3.0 불일치** — SQ 범위가 아니라
  회계·SCM 쪽 모듈입니다. 그쪽 담당과 `-u supplier_portal_purchase` 시점을 맞춰주십시오.
- **blue 마운트 경로 불일치**(`/mnt/iatf-plugins` vs `/mnt/iatf`)는 개발 쪽에서 compose 수정안을
  만들어 드리겠습니다. 다만 blue 컨테이너를 실제로 갱신하는 건 서버 쪽 작업입니다.
- **중립화 복제본** 공유가 가능하면, 개발 쪽 리허설을 실데이터로 할 수 있습니다.
