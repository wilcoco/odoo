## 세션 작업 규칙
1. 수요·정산·시리얼·결재처럼 "원장" 성격 데이터는 **만들지 말고 정본에 기록**한다.
2. 같은 모델에 두 모듈이 훅을 걸면 실행 순서·중복을 검토하고 이 파일에 기록한다.
3. 작업 단위별 브랜치 → PR. 다른 세션 활성 브랜치에 얹지 않는다.
4. 완료 전 검증: 원격 존재(ls-remote) + 테스트 그린 + (해당 시) 심볼 스캔.
