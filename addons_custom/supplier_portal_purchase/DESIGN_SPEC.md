# 외주 자동발주 및 협력사 포탈 시스템 설계서

> Odoo 18 Community 모듈 `supplier_portal_purchase`  
> 작성일: 2026-04-07

---

## 1. 시스템 개요

### 1.1 목적

사출 생산계획(`injection_planning`)에서 BOM 전개 시 발생하는 **외주 부품**을 식별하고,
해당 협력사에 **자동 발주서(PO)**를 생성하여 **협력사 포탈**을 통해 발주 내용을 전달하는 시스템.

### 1.2 범위

```
[injection_planning]     [supplier_portal_purchase]           [협력사]
       │                          │                              │
  생산계획 확정 ──────────► 외주품목 추출 ──────────────────────► 포탈 알림
       │                          │                              │
  BOM 전개 ───────────────► PO 자동 생성 ──────────────────────► 발주 확인
       │                          │                              │
                            납기 응답 ◄──────────────────────── 납기 회신
```

### 1.3 핵심 기능

| 구분 | 기능 | 설명 |
|------|------|------|
| **자동화** | 외주 품목 식별 | BOM 내 외주 부품 자동 추출 |
| **자동화** | PO 자동 생성 | 생산계획 확정 시 협력사별 발주서 생성 |
| **자동화** | 생산 영향 분석 | 협력사 응답이 생산에 미치는 영향 자동 분석 |
| **포탈** | 발주 조회/응답 | 협력사가 정형화된 폼으로 납기/수량 확정 |
| **포탈** | 실시간 알림 | 포탈 내 알림 배지 (이메일 대신) |
| **내부** | 승인/반려 워크플로우 | 구매담당자가 협력사 응답 검토/승인 |
| **연동** | 입고/재고/마감 | Odoo 표준 stock, account 연동 |

## 4. 비즈니스 로직

### 3.1 외주 품목 발주 생성 흐름

```python
# injection.planning.run 확장
def action_confirm_plan(self):
    """생산계획 확정 시 외주 발주 자동 생성"""
    super().action_confirm_plan()
    self._generate_outsource_purchase_orders()

def _generate_outsource_purchase_orders(self):
    """
    1. 계획 라인에서 외주 품목 필터링
    2. 협력사별로 그룹핑
    3. PO 생성 + PO Line 생성
    4. 포탈 알림 발송
    """
    outsource_lines = self.line_ids.filtered(
        lambda l: l.product_id.is_outsourced
    )
    
    # 협력사별 그룹핑
    partner_lines = defaultdict(list)
    for line in outsource_lines:
        partner = line.product_id.outsource_partner_id
        if partner:
            partner_lines[partner.id].append(line)
    
    # PO 생성
    for partner_id, lines in partner_lines.items():
        po = self._create_purchase_order(partner_id, lines)
        po._send_portal_notification()
```

### 3.2 납기 계산 로직

```python
def _compute_required_date(self, planning_line):
    """
    필요 납기일 = 생산 예정일 - 리드타임 - 버퍼
    
    예) 생산일: 4/15, 리드타임: 3일, 버퍼: 1일
        → 납기일: 4/11
    """
    production_date = planning_line.planned_date
    leadtime = planning_line.product_id.outsource_leadtime or 3
    buffer_days = self._get_config().outsource_buffer_days or 1
    
    return production_date - timedelta(days=leadtime + buffer_days)
```

### 3.3 협력사 응답 처리

```python
# 포탈 컨트롤러
class SupplierPortalController(http.Controller):
    
    @http.route('/supplier/po/<int:po_id>/confirm', auth='public', website=True)
    def confirm_po(self, po_id, token, **post):
        """협력사 납기 확정"""
        po = self._validate_access(po_id, token)
        
        for line_data in post.get('lines', []):
            line = po.order_line.browse(line_data['id'])
            line.write({
                'confirmed_qty': line_data['qty'],
                'confirmed_date': line_data['date'],
            })
        
        po.write({
            'supplier_confirmed': True,
            'supplier_confirmed_date': fields.Datetime.now(),
        })
        
        # 구매 담당자에게 알림
        po._notify_buyer_confirmed()
```

```python
import secrets

def _generate_portal_token(self):
    """32바이트 보안 토큰 생성"""
    return secrets.token_urlsafe(32)

def _validate_portal_access(self, po_id, token):
    """토큰 검증"""
    po = self.env['purchase.order'].sudo().browse(po_id)
    if not po.exists():
        raise AccessDenied("Invalid PO")
    if po.partner_id.supplier_portal_token != token:
        raise AccessDenied("Invalid token")
    return po
```

## 11. 테스트 시나리오

### 11.1 자동 발주 생성

```
Given: BOM에 외주 부품 A(협력사 X), B(협력사 Y) 포함
When: 생산계획 확정
Then: 협력사 X에 PO 1건 (품목 A)
      협력사 Y에 PO 1건 (품목 B) 생성
      각 협력사에 알림 이메일 발송
```

### 11.2 포탈 납기 확정

```
Given: 협력사 X가 포탈 접속
When: PO 상세에서 납기 확정 (수량 450, 납기 4/12)
Then: PO Line에 confirmed_qty=450, confirmed_date=4/12 저장
      구매 담당자에게 확정 알림
```

### 11.3 리마인더 발송

```
Given: PO 납기 D-2, 미확정 상태
When: 리마인더 cron 실행
Then: 협력사에 리마인더 이메일 발송
```

## 14. 용어 사전

| 용어 | 영문 | 설명 |
|------|------|------|
| 외주 | Outsource | 사내 생산하지 않고 외부 협력사에 발주 |
| PO | Purchase Order | 구매 발주서 |
| RFQ | Request for Quotation | 견적 요청서 |
| 리드타임 | Lead Time | 발주부터 입고까지 소요 기간 |
| ASN | Advanced Shipping Notice | 사전 출하 통보 |
| 포탈 상태 | Portal State | new/responded/approved/rejected/done |
| 생산 영향도 | Production Impact | 협력사 응답이 생산 일정에 미치는 영향 (🟢/🟡/🔴) |
