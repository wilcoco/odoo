# 회계 한국식 비유동자산 확장 (`account_kr_plus_patch_ncasset`)

오두 엔터프라이즈 **자산**(`account_asset`)을 회사 운영 방식에 맞추는 확장입니다.
`account_kr_plus_patch` 와 `account_asset` 이 모두 설치된 DB에서 **자동으로 함께 설치**됩니다(`auto_install`).

## 기능

### 비상각(평가형) 자산
토지처럼 감가상각을 하지 않고 필요할 때 평가하는 자산을 한 번에 설정합니다.
`비상각(평가형)`을 켜면 **감가상각 제외금액을 취득원가와 같게 유지**해 감가상각 대상금액이 0이 되고,
자산을 확인(진행)해도 감가상각 전표가 생기지 않습니다. 취득원가를 바꾸면 제외금액도 같이 따라갑니다.
가치 변동은 표준 마법사의 **재평가**로 반영합니다.

### 자산별 계정과목
자산 한 건마다 계정과목을 따로 두고 관리할 수 있습니다.

- 계정 코드는 **기준 계정 코드 + 자산 일련번호**입니다.
  예) 토지 기준 계정 `800003` → 1번 토지 `8000031`, 2번 토지 `8000032`
- 계정 유형·조정 여부·계정 태그를 **기준 계정에서 그대로 물려받습니다.**
  코드가 기준 계정으로 시작하므로, 코드 접두사로 매핑하는 재무제표(재무상태표(KR) 등)와
  회계 통계에서도 기준 계정과 같은 성격(예: 토지)으로 잡힙니다.
- 취득원가뿐 아니라 **계약 단계별 계정(계약금·중도금·잔금)**도 같은 규칙으로 만들 수 있습니다.
  예) 계약금 기준 계정 `803001` → `8030011`, `8030012`
- 같은 자산에 다시 실행해도 계정을 다시 만들지 않습니다(멱등).

기준 계정은 **회사 설정 › 자산별 계정 기준**에서 지정합니다
(자산·계약금·중도금·잔금 기준 계정, 재분류 저널).

### 재분류 전표(초안)
이미 한 계정에 쌓여 있는 잔액을 자산별 계정으로 옮기는 전표를 만들 수 있습니다.
**초안으로만 만들고 전기하지 않습니다.** 일자는 담당자가 정하고, 검증이 끝난 기간으로 소급하지 않도록
전표 채터에 주의 문구를 남깁니다. 전기는 사람이 확인한 뒤 직접 합니다.

## 모델
- `account.asset` (확장): `kr_non_depreciable`, `kr_asset_no`, `kr_account_ids`,
  `action_kr_create_accounts`, `action_kr_create_asset_account`, `action_kr_open_reclass_wizard`
- `account.asset.kr.account` (신규): 자산별 계정과목(구분·기준 계정·계정)
- `res.company` (확장): 자산·계약금·중도금·잔금 기준 계정, 자산 재분류 저널
- `account.asset.kr.reclass.wizard` (신규, 임시): 재분류 초안 전표 생성

## 주의
- 자산별 계정을 새로 만들면 원장 잔액은 그대로 기준 계정에 남습니다. 옮기려면 재분류 전표를 쓰고,
  **이미 검증이 끝난 분기로 소급하지 마세요.**
- 이관 기간에는 감가상각·재평가 전표를 오두가 만들면 이관 자료와 이중 계상됩니다.
  상각 대상 자산도 이관이 끝날 때까지는 비상각 또는 보류로 두세요.
