# 작업 기록: 작업명

작업 크기에 맞게 간결하게 작성한다. 해당 없는 항목은 `해당 없음`, 확인하지 않은 항목은 `미확인`으로 표시한다. 민감한 접속 정보·DB 내용은 넣지 않는다. 모르는 값과 승인·시험 결과를 만들어 채우지 않는다.

## 공유 이력

- handoff 요청/회신 링크:
- 다음 담당 / 남은 일:

후속 검증·배포 기록은 그 작업의 브랜치에 같은 양식으로 작성하고 원래 PR과 서로 연결한다. 운영 반영 후 결과는 진행 중인 배포 작업 기록 또는 접근 가능한 배포 실행 기록에 남기고 큐에서 참조한다. 이미 병합된 작업을 기록만 쓰려고 다시 열거나 문서 전용 브랜치를 만들지 않는다.
